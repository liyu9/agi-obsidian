# 13、AI应用产品的评估体系

## 13.1 传统非AI产品的做法 vs AI应用产品的做法：
1、传统非AI产品的做法：

举例：A/B test

（1）出题：某按钮的位置位于A，B；

（2）打分标准：看哪个位置的点击率(或者转化率)更高；

（3）参与考试的考生是一个应用；

（4）最终分数就是对A/B test的置信率的解读等。

2、AI应用产品的做法：

在LLM AI应用中，打分标准不像A/B test点击率(或转化率)一样确定。LLM的题目更像是陈述题（比如开放式问答）

**（1）定评估维度**

相关度：回答是否与主题相关。

正确度：是否包含错误内容。

完整度：是否完整包含了所有内容。

合规性：是否合规，涉及敏感词等

...(其他维度)

**（2） 定打分标准（MOS/用户满意度等）**

1-5分依次定分。

（3） **定好标准后进行判卷**

a）可以用大模型机器评分：把标准作为提示词，和评分对象同时发给高级大模型（比如GPT-4o）打分。

b）可以人工辅助评分： 业务专家对机器评分快速审核，直到给机器的标准能让ta打出和人类相近的分数。

## **13.3 （重要）一个知识问答中究竟涉及到哪些需要评估的环节？**
**1.** **【检索】：确保大语言模型接收到的是相关、正确、足够的信息**

（1）检索准确性

**评估指标**：

是否检索到了 **包含正确答案的文段**（召回率 Recall）

检索文段与用户问题的语义相关性（Precision / Semantic Similarity）

**常用方法**：

人工打分（relevant / irrelevant）

自动计算检索内容与标准答案的覆盖度（如 EM、F1）

（2）检索结果与生成内容的一致性

**评估模型是否“幻觉”**：

LLM 是否使用了文档中未提供的信息

LLM 回答内容是否忠实于已检索的内容（faithfulness）

**问题解决流程阶段（Reasoning + Tool Use）：让 AI 能正确判断是否调用工具，并使用正确工具+正确指令**

（1）是是否正确判断需要调用工具

（2）是否选择了正确的工具（Tool Routing）

（3）函数调用格式是否正确（Function Format）

（4）参数填充是否准确（Parameter Mapping）

**评估难点**：需要构建【对话上下文 + 正确函数调用】的评估对齐机制

**3.最终生成回答阶段（Generator）——是否生成了高质量、用户满意的自然语言答案**

（1）回答内容与标准答案的一致性（Correctness）

（2）用户满意度（Satisfaction）

| **模块** | **检查项** | **评估方式** |
| --- | --- | --- |
| 检索 | 是否召回包含答案的文段 | F1、召回率、人工打分 |
| 检索 | LLM 是否只基于检索内容作答 | 事实一致性评估 |
| 判断是否调用工具 | 判断逻辑正确性 | 规则+人工审核 |
| 工具选择 | 是否调用了正确 API | Tool name 对比 |
| 工具参数填写 | 参数是否正确映射 | 对照多轮对话与参数 |
| 工具指令格式 | 是否符合 Schema | JSON Schema 校验 |
| 工具调用结果 | 返回值是否有效 | API 返回码校验 |
| 回答内容 | 是否准确回答问题 | EM、人工对比、QA 样本 |
| 用户满意度 | 回答是否清晰、解决问题 | Survey / 评分 / CSAT |

**示例：**

（1） **（评估相对简单）**是否能从众多工具中选择到正确工具，if需要查询用户地址应该调用search， 而不是update。

（2） **（评估相对复杂，首先要构建大量的对话数据，其次这些对话数据要和函数调用对应起来，然后在评估的时候，需要对函数语言进行解析，提取出相应的参数内容，再和对话里的数据进行比对）**

需要将自然语言转换为正确的函数调用格式。if需要从多轮自然语言对话指令中提取出正确的参数值

**示例：参数提取与核查逻辑（值对比 + 是否来源于对话）**

## 13.5 文生图模型测评标准（superclue最新202504）
1、评测标注-以superclue最新标准为例：

![image](images/img_0493.png)

```JSON
1、图像质量
真实感: 评估图像的整体真实性和自然度，判断其“AI生成痕迹”是否明显，是否接近真实照片或人类创作的作品。
构图美感：评估图像的布局与构图是否符合艺术美学标准，包括元素的对称性、平衡感以及视觉吸引力。
细节处理：评估图像细节的精细度和形态结构的准确性，以及是否存在不自然的扭曲或畸变。
色彩表现力：评估图像在色彩搭配、饱和度、对比度等方面的表现是否自然且具有感染力。

2、图文一致性
主体匹配：评估图像中的主体是否与文本描述的关键特征（类型、外观、属性等）一致。
数量关系：评估图像中特定元素的数量是否与文本描述的要求精确一致。
空间关系：评估图像中各元素之间的相对位置、朝向、分布等空间关系是否符合文本描述。
语境还原：评估图像是否准确再现了文本描述的特定场景、氛围、情境或动作。

3、文字生成
文字准确性：评估图像中文字内容是否与文本描述一致，无拼写错误或语义偏差。
字形美观度：评估图像中的文字样式、字体和排版的美观性，包括文字的易读性、设计感以及视觉吸引力。
图文贴合度：评估图像中的文字与背景的融合程度，确保文字合理地嵌入场景，不突兀、不失真，与整体视觉风格和谐一致。

4、对话式生图（可选）
图像编辑：评估模型根据用户对话指令生成以及修改图像的能力。
图像融合：评估模型将多个图像或元素融合成一张新图的能力。

5、创作能力
意象表达：评估模型在图像生成过程中是否能够创造出富有象征意义或情感表达的视觉意象。
写实照片：评估模型生成图像的真实性和写实程度，检查图像是否逼真且具有照片般的细节和质感，以及图像整体美感。
动漫风格：评估模型是否能够生成符合动漫或卡通风格的图像，以及图像整体美感。
手绘艺术：评估模型是否能生成具有手绘质感（如素描、油彩、水墨等）的图像，以及图像整体美感。
概念设计：评估模型是否能创造出具有创意的概念艺术，以及图像整体美感。
```

**2、测评方法：**

通过构建专用测评集：

**1.评分方法：**采用超级大模型进行评价。结合评估流程、评估标准、评分规则，进行细粒度评估。尽量减少人为因素的干预，确保评分结果的客观性和一致性。

**2.人类一致性分析**

对自动化测评结果进行评估，与人类评价的一致性对比，并报告一致性表现。

*****逐项打分开始*****
我的思考与答案：用户要求评估一张AI生成的古董怀表表盘微距特写图片，重点关注细节处理。
1.  **分析Prompt**: Prompt要求非常具体：微距特写、古董怀表表盘、精致雕刻、细腻细节、陈旧感、微妙氧化色泽（铜绿感）、边缘细微裂纹、玻璃盖轻微划痕、精细压印的罗马数字（复古衬线字体、有磨损但清晰）、镂空花纹抛光黄铜指针（反光、投下阴影）、精细机刻雕纹（guilloché）表盘（微妙反光）。
2.  **分析图像**:    * 图像确实是古董怀表表盘的微距特写。    * 表壳边缘有精致的雕刻。    * 整体有陈旧感和细节。    * 表盘呈现明显的绿色氧化色泽（铜绿）。    * 边缘*没有*明显的裂纹，但有磨损感。    * *无法判断*是否有玻璃盖及其划痕，焦点在表盘和指针上，玻璃效果不明显。    * 罗马数字刻度存在，是立体的（似乎是镶嵌或凸起，而非“压印”），有磨损感，字体符合复古风格，清晰可辨。    * 指针精美，但*不是*明显的镂空花纹设计（更像是实体带些装饰），材质看起来更像*氧化*的铜或青铜，而非“抛光黄铜”，反光不强。指针确实投下了柔和阴影。    * 表盘表面有纹理，呈现出斑驳的氧化效果，但*不是*清晰的、几何性的“机刻雕纹”（guilloché）图案。

打分与评价开始：
1. 基于标准1的<细节清晰度>；图像的整体清晰度较好，特别是作为微距特写，表盘的纹理、指针的边缘、罗马数字的形态以及表壳的雕刻都展现了不错的清晰度和可辨识度，具有较好的真实感。基于标准1的得分，4分；
2. 基于标准2的<细节准确性>；图像在对象的整体形态（怀表）和基本构造上是准确的。但是，未能准确还原prompt中描述的多个特定细节，如指针应为镂空抛光黄铜但实际为氧化实心状，表盘应为机刻雕纹但实际为斑驳纹理，缺失了裂纹和玻璃划痕等元素。基于标准2的得分，3分；
