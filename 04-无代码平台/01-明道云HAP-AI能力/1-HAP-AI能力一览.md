# HAP 的 AI 能力一览 | 明道云

> 原文链接：https://help.mingdao.com/ai/

## 核心AI能力

### 1. 对话机器人
用户通过聊天方式进行多轮交互，机器人能够识别用户意图，对应用数据的增删改查和总结分析，驱动业务自动化。

### 2. 向量知识库
向量知识库是 HAP 平台内置的语义检索基础设施。它通过将工作表记录、附件及讨论消息进行"向量化"处理，使 AI Agent 和工作流能够基于语义理解（而非简单的关键词匹配）精准获取相关知识，实现"意思相近即可搜到"的智能化体验。

### 3. AI智能搭建
- **智能生成工作表**：AI根据输入的描述，自动生成工作表，可自动生成图标、字段和布局样式
- **生成示例数据**：AI生成工作表示例数据，方便搭建者测试和演示
- **智能填写表单**：AI智能解析输入内容和上传的图片附件，并自动填写到表单字段
- **自定义字段控件**：通过与AI对话的方式，让AI自动写代码来生成自定义字段控件

### 4. AI Agent节点
工作流的 AI Agent 节点能够根据输入内容自动分析、推理并进行工具执行（对数据查询、新增、修改、调用API或封装业务流程）

### 5. AI动作
AI 动作是记录详情页进入场景对话的入口。点击任一 AI 动作卡片后，即可开启围绕当前记录的多轮对话。系统自动注入记录字段、讨论、日志等上下文，并按卡片配置的提示词、模型与工具持续输出结果。

### 6. AIGC能力
借助 AIGC 能力辅助客户进行创作，提升工作效率。包含 AI 生成文本、AI 生成数据对象节点。

### 7. 知识库检索节点
知识库检索节点通过多模式检索（语义/关键词/混合）从跨应用的多个知识库中提取高相关性内容，并输出包含文本片段、来源及得分的数组，以便后续用于 AI 问答、数据填充或流程分支自动化。

### 8. AI代码生成
工作流中的代码块节点，通过集成AI能力，可以根据您输入的功能需求描述自动生成一段代码(JS和Python都支持)，生成的代码符合代码块规范要求，可以直接可用。

### 9. AI翻译
基于大模型自然语言处理技术，调试后的AI翻译功能提供一键翻译，轻松高效地处理所有应用文本，使您的应用在面向多语言协作场景时，也能轻松应对。

### 10. MCP Server
助力 AI 编程，选择密钥生成 MCP Server 配置，将下方 JSON 配置添加到 IDE 的 MCP 配置文件中，当 API 文档有更新时，Server也会同步更新。

### 11. HAP for VSCode
HAP for VSCode 是 HAP 平台的官方 VS Code 扩展，将整个视图插件的开发、调试、提交、发布流程集成在一个侧边栏面板中，让你无需离开编辑器就能完成所有操作。

### 12. Dify集成
在 Dify 中，用户可以利用 HAP 提供的内置工具搭建HAP应用助手，可以基于应用实时数据进行问答。
