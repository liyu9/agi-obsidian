## 1. 神经网络与深度学习

### 1.1 神经元的数学模型

```
输入₁ × 权重₁ + 输入₂ × 权重₂ + ... + 偏置 → 激活函数 → 输出
```

- **输入**：来自上一层神经元的信号
- **权重**：每个输入信号的强度系数
- **偏置**：调整神经元激活的难易程度
- **激活函数**：引入非线性，决定神经元是否被激活
- **输出**：传递给下一层神经元的信号

### 1.2 三种激活函数对比

| 激活函数 | 公式 | 输出范围 | 优点 | 缺点 |
|----------|------|----------|------|------|
| **Sigmoid** | S(x)=1/(1+e⁻ˣ) | (0, 1) | 平滑、可导、输出可解释为概率 | 梯度饱和（两端梯度接近0） |
| **Tanh** | tanh(x) | (-1, 1) | 零中心化 | 仍有梯度饱和问题 |
| **ReLU** | max(0, x) | [0, +∞) | 计算简单、缓解梯度消失 | 负半轴梯度为0（神经元死亡） |

> **ReLU是当前最常用的激活函数**，因其简单高效且有效缓解了梯度消失问题

### 1.3 多层感知器（MLP）

**三层结构**：
```
输入层 → 隐藏层 → 输出层
```

- **输入层**：接收原始数据特征
- **隐藏层**：进行特征变换和提取（可以有多个隐藏层）
- **输出层**：输出最终预测结果

### 1.4 深度网络 vs 宽度网络

| 类型 | 说明 | 优势 |
|------|------|------|
| **深度网络** | 隐藏层层数多 | 逐层提取更抽象的特征，表达能力更强 |
| **宽度网络** | 单层神经元数量多 | 同一层提取更多特征 |

> **深度学习的核心在于"深"**，通过多层非线性变换，逐层提取更高层、更抽象的特征

### 1.5 端到端训练

- **定义**：从原始输入直接到最终输出的训练方式，中间过程全部在模型内部自动完成
- **特点**：黑盒模型——不需要人工设计中间特征，模型自动学习特征表示

**机器学习 vs 深度学习对比**：

| 维度 | 机器学习 | 深度学习 |
|------|----------|----------|
| 特征提取 | 人工设计特征工程 | 模型自动学习特征 |
| 可解释性 | 较强（步骤清晰可解释） | 较弱（黑盒模型） |
| 数据量需求 | 相对较少 | 大量数据 |
| 计算资源需求 | 较低 | 较高（需要GPU） |
| 适用场景 | 结构化数据、小样本 | 非结构化数据（图像/文本/语音） |

## 2. 卷积神经网络（CNN）

### 2.1 为什么需要CNN——全连接层的参数爆炸

以一张1000×1000像素的RGB图像为例：
- 输入层神经元数量：1000×1000×3 = 3,000,000
- 如果隐藏层有1000个神经元
- 全连接层参数数量：3,000,000 × 1000 = **30亿**（10⁸级别）

> **全连接的参数量过大，导致训练困难、容易过拟合**。CNN通过局部感受野和权值共享大幅减少参数量

### 2.2 CNN减少参数量的三大策略

| 策略 | 说明 | 效果 |
|------|------|------|
| **局部感受野** | 每个神经元只连接输入图像的局部区域 | 大幅减少连接数 |
| **权值共享** | 同一卷积核在整个图像上滑动，共享权重 | 进一步减少参数量 |
| **池化（Pooling）** | 下采样，降低特征图尺寸 | 降低维度，减少计算量 |

### 2.3 RGB三通道

- 彩色图像由**红（R）、绿（G）、蓝（B）**三个通道组成
- 每个通道是一个二维矩阵，表示该颜色的强度
- CNN分别对三个通道进行卷积运算

### 2.4 卷积运算

**卷积操作**：用一个小的卷积核（如3×3）在输入图像上滑动，逐元素相乘后求和

**示例**：
- 输入图像：6×6
- 卷积核：3×3
- 输出特征图：4×4（6-3+1=4）

### 2.5 池化（Pooling）

- **作用**：对特征图进行下采样，降低维度
- **常见类型**：最大池化（Max Pooling）
- **示例**：2×2池化——在2×2区域内取最大值作为输出

### 2.6 CNN的完整结构流程

```
数据规则化 → 卷积 → ReLU激活 → 池化 → （重复多次） → 全连接 → Softmax → 分类
```

**各步骤说明**：

| 步骤 | 作用 |
|------|------|
| **数据规则化** | 将输入数据统一到相同尺寸和范围 |
| **卷积** | 提取局部特征（边缘、纹理等） |
| **ReLU激活** | 引入非线性 |
| **池化** | 下采样，降低维度 |
| **全连接** | 将高维特征映射到分类空间 |
| **Softmax** | 将输出转为概率分布 |
| **分类** | 取概率最高的类别作为结果 |

**卷积层 → 池化层的循环**：通常重复多次，逐层提取从低层（边缘、纹理）到高层（形状、物体）的特征

## 3. 循环神经网络（RNN）

### 3.1 RNN的核心特点

- **适用场景**：序列数据（文本、语音、时间序列）
- **核心机制**：循环结构，隐藏层的输出不仅传递到下一层，还会传递到**同一层的下一个时间步**
- **记忆能力**：可以记住之前的信息，捕捉序列中的依赖关系

### 3.2 RNN的结构示意

```
          输出₁       输出₂       输出₃
           ↑           ↑           ↑
... → 隐藏层 → 隐藏层 → 隐藏层 → ...
           ↑           ↑           ↑
        输入₁       输入₂       输入₃
```

- 每个时间步的隐藏层同时接收**当前输入**和**上一步的隐藏状态**
- 信息在时间维度上传递，形成"记忆"

## 总结

| 核心概念 | 关键要点 |
|----------|----------|
| 神经元模型 | 输入×权重+偏置→激活函数→输出 |
| 激活函数 | Sigmoid（概率输出）、Tanh（零中心）、ReLU（当前最常用） |
| 多层感知器 | 输入层+隐藏层+输出层的基本结构 |
| 端到端训练 | 黑盒模型，自动学习特征 |
| CNN三策略 | 局部感受野、权值共享、池化 |
| 卷积运算 | 卷积核在图像上滑动，逐元素相乘求和 |
| 池化 | 下采样降低维度，常取最大值 |
| CNN流程 | 规则化→卷积→激活→池化→全连接→Softmax→分类 |
| RNN | 循环结构，适合序列数据，具有记忆能力 |
| 机器学习vs深度学习 | 人工特征vs自动特征，可解释vs黑盒 |
