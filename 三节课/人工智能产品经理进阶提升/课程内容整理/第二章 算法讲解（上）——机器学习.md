## 1. 机器学习基本概述

### 1.1 AI的三大基石

| 基石 | 说明 | 核心要点 |
|------|------|----------|
| **数据** | 模型训练的基础材料 | Garbage in, garbage out |
| **算力** | 计算能力 | 决定训练速度和可行性 |
| **算法** | 模型设计方法 | 决定学习效果 |

### 1.2 CPU vs GPU

| 维度 | CPU | GPU |
|------|-----|-----|
| 类比 | 大学生 | 小学生 |
| 特点 | 单个处理单元能力强 | 大量处理单元并行工作 |
| 适用场景 | 复杂逻辑运算 | 大规模并行计算（矩阵运算） |
| AI相关性 | 不擅长大量重复计算 | 非常适合神经网络训练 |

### 1.3 三种学习方式

#### 监督学习

- **定义**：使用已标注的数据进行训练，学习输入到输出的映射
- **数据要求**：需要大量已标注数据
- **典型任务**：分类、回归、排序

#### 无监督学习

- **定义**：使用未标注的数据进行训练，让模型自主发现数据中的结构和模式
- **典型任务**：聚类、降维
- **代表算法**：KNN（K近邻）

#### 弱监督学习（强化学习）

- **定义**：通过与环境交互获得奖励信号来学习
- **特点**：不是直接给出正确答案，而是通过试错和奖惩机制学习
- **典型应用**：AlphaGo、游戏AI

### 1.4 损失函数

> **损失函数**：衡量模型预测值与真实值之间差异的函数

**核心思想**：
- 模型预测值（ŷ）与真实值（y）之间的差异越小越好
- 目标是找到使损失函数最小化的模型参数

### 1.5 梯度下降

> **梯度下降**：通过沿着损失函数下降最快的方向（负梯度方向）更新参数，逐步逼近最优解

**两个关键因素**：

| 因素 | 说明 | 问题 |
|------|------|------|
| **方向** | 往哪个方向走（梯度方向） | 方向错了则无法到达最优点 |
| **步长（学习率）** | 每次走多大一步 | 步长太大：可能越过最优点；步长太小：收敛速度慢 |

### 1.6 机器学习通用表达式

```
输入数据 → 特征提取 → 模型（F） → 输出预测 → 损失计算 → 参数更新（梯度下降）
                         ↑______________________________↓
```

## 2. 算法解释

### 2.1 三大任务类型

| 任务类型 | 说明 | 示例 |
|----------|------|------|
| **预测** | 预测连续值 | 房价预测、销量预测 |
| **分类** | 将数据分到离散类别 | 猫狗识别、垃圾邮件过滤 |
| **排序** | 对项目按相关性排序 | 搜索结果排序、推荐排序 |

### 2.2 线性回归

#### 一元线性回归

**公式**：Y = AX + B

- **Y**：预测值（因变量）
- **X**：特征值（自变量）
- **A**：斜率（权重）
- **B**：截距（偏置）

#### 多元线性回归

**公式**：Y = A₁X₁ + A₂X₂ + ... + AₙXₙ + B

- 多个特征共同影响预测结果
- 每个特征有对应的权重

### 2.3 逻辑斯谛回归

> **本质**：将线性回归的输出通过Sigmoid函数映射到0-1之间，用于分类问题

**Sigmoid函数**：

```
S(x) = 1 / (1 + e⁻ˣ)
```

- 输出范围：0到1之间
- 输出值表示属于某一类的概率
- 通常以0.5为分类阈值

**核心流程**：
1. 线性回归计算得到连续值
2. Sigmoid函数将连续值转为0-1的概率
3. 根据概率值进行分类判断

### 2.4 KNN（K近邻）无监督聚类

**核心思想**：物以类聚，人以群分

**算法步骤**：
1. 选择K值（邻居数量）
2. 计算待分类样本与所有训练样本的距离
3. 找出K个最近的邻居
4. 根据K个邻居的类别进行投票，确定待分类样本的类别

**特点**：
- 迭代稳定
- 无需训练过程（懒惰学习）
- 计算量与样本量成正比

### 2.5 决策树ID3算法

**核心概念**：信息增益

> **信息熵**：衡量信息不确定性的指标。熵越大，不确定性越大

**ID3算法**：
- 选择信息增益最大的特征作为分裂节点
- 递归地构建决策树

**信息熵公式**：
```
H = -Σ p(i) × log(p(i))
```

其中p(i)是第i类样本出现的概率

### 2.6 随机森林

**核心思想**：集成学习——多个弱分类器组合成强分类器

**构建过程**：
1. 从原始数据集中随机抽取多个子集（Bootstrap采样）
2. 对每个子集训练一棵决策树
3. 多棵决策树共同投票决定最终分类结果

**优势**：
- 抗过拟合能力强
- 对缺失数据不敏感
- 能处理高维数据

## 3. 模型的评价指标

### 3.1 混淆矩阵

```
                实际为正例         实际为负例
预测为正例        TP（真正例）       FP（假正例）
预测为负例        FN（假负例）       TN（真负例）
```

### 3.2 核心指标

| 指标 | 公式 | 说明 |
|------|------|------|
| **精确率（Precision）** | TP / (TP + FP) | 预测为正例中实际为正例的比例，即"查准率" |
| **召回率（Recall）** | TP / (TP + FN) | 实际为正例中预测为正例的比例，即"查全率" |
| **准确率（Accuracy）** | (TP + TN) / (TP + FN + FP + TN) | 所有预测正确的比例 |
| **F1值** | 2 × (P × R) / (P + R) | 精确率和召回率的调和平均数 |

### 3.3 残差、MAE、MSE

| 指标 | 公式 | 说明 |
|------|------|------|
| **残差** | y - ŷ | 真实值与预测值的差 |
| **MAE（平均绝对误差）** | (1/n) × Σ|y - ŷ| | 残差的绝对值的平均值 |
| **MSE（均方误差）** | (1/n) × Σ(y - ŷ)² | 残差的平方的平均值 |

> **MSE优于MAE的原因**：MSE可导，便于梯度下降优化

### 3.4 ROC曲线与AUC

| 概念 | 说明 |
|------|------|
| **ROC曲线** | 以假正率（FPR）为横轴、真正率（TPR）为纵轴的曲线 |
| **AUC** | ROC曲线下的面积 |

**AUC值评价**：

| AUC范围 | 评价 |
|----------|------|
| 0.5 | 无价值（随机猜测） |
| 0.7-0.85 | 一般可用 |
| **0.85-0.95** | **优秀** |
| 0.95以上 | 极高精度（需警惕过拟合） |

**科研工作的指标偏好**：强调**精确率**（因为科研追求准确）
**医学筛查的指标偏好**：强调**召回率**（因为不能漏掉病人）

## 总结

| 核心概念 | 关键要点 |
|----------|----------|
| 三大基石 | 数据、算力、算法缺一不可 |
| CPU vs GPU | 大学生（复杂逻辑）vs 小学生（并行计算） |
| 学习方式 | 监督（有标注）、无监督（无标注）、强化学习（试错） |
| 梯度下降 | 方向（梯度）+ 步长（学习率）是关键 |
| 线性回归 | Y=AX+B，预测连续值 |
| 逻辑斯谛回归 | Sigmoid函数将连续量转为0-1概率 |
| 决策树ID3 | 信息增益最大化的特征优先分裂 |
| 随机森林 | 多棵决策树集成投票 |
| KNN | 物以类聚，无需训练 |
| 精确率vs召回率 | 科研看重精确率，医学筛查看重召回率 |
| ROC/AUC | AUC 0.85-0.95为优秀模型 |
| 可用性原则 | AI商业化不需要99.9%，可用即可 |
