## 第一章：认知基础——AI是什么

**一句话总结**：AI的本质是**提高信息产生的效率**，而互联网是提高信息传递的效率。

**核心框架**：
- **AI四层架构**：运算智能 → 感知智能 → 认知智能 → 创造智能
- **AI三大基石**：数据（食材）+ 算力（火候）+ 算法（烹饪水平）
- **AI产品定义**：模拟人类完成信息生成的系统

**关键金句**：
> 互联网解决信息从哪里来到哪里去，AI解决信息如何产生

---

## 第二章：算法基础（上）——机器学习

**一句话总结**：机器学习是通过数据学习输入到输出的映射关系，核心是**找到损失函数的最小值**。

**技术图谱**：

| 算法 | 类型 | 核心思想 | 适用场景 |
|------|------|----------|----------|
| 线性回归 | 监督学习/回归 | Y=AX+B拟合数据 | 预测连续值（房价、销量） |
| 逻辑斯谛回归 | 监督学习/分类 | Sigmoid函数将连续值转为概率 | 二分类（是/否判断） |
| 决策树ID3 | 监督学习/分类 | 信息增益最大化逐步分裂 | 可解释性强的分类 |
| 随机森林 | 集成学习 | 多棵决策树投票 | 抗过拟合、高维数据 |
| KNN | 无监督/聚类 | 物以类聚 | 无需训练的聚类任务 |

**关键指标**：
- **精确率（Precision）**：查准率——预测为正例中实际为正的比例
- **召回率（Recall）**：查全率——实际为正例中预测为正的比例
- **F1值**：精确率和召回率的调和平均数
- **AUC**：ROC曲线下面积，0.85-0.95为优秀

**关键金句**：
> 50%提升到90%只需3天，90%提升到99%需要1年

---

## 第三章：算法基础（下）——深度学习

**一句话总结**：深度学习通过多层神经网络自动学习特征，是一个**端到端的黑盒模型**。

**核心机制**：
- **神经元模型**：输入×权重+偏置→激活函数→输出
- **激活函数**：ReLU（最常用）、Sigmoid、Tanh
- **CNN三策略**：局部感受野 + 权值共享 + 池化（大幅减少参数量）
- **CNN流程**：规则化→卷积→ReLU→池化→全连接→Softmax→分类
- **RNN**：循环结构，适合序列数据

**关键金句**：
> 机器学习是可解释的白盒，深度学习是自动学习的黑盒

## 第四章：产品搭建方法论

**一句话总结**：AI产品开发相比互联网产品多出了**技术预研**和**模型开发**两条并行线。

**五个阶段**：
```
产品定位 → 需求分析 → 技术预研 → 模型开发 → 运营
                          ↓           ↓
                      产品研发    模型开发（双分支）
```

**三维度评估框架**：
```
项目是否适合做AI？
    ├── 数据维度：可获取？质量高？存量够？可闭环？
    ├── 问题维度：可解释？容错？复杂度？鲁棒？
    └── 商业维度：有价值？痛点真？ROI合理？
```

**关键金句**：
> 场景大于逻辑——用户使用产品的环境比产品逻辑更重要

---

## 第五章：数据治理

**一句话总结**：数据比算法更重要——**Garbage in, garbage out**。

**做菜五步法**：
```
引入（认识数据重要性）
  → 试吃（认识数据结构和类型）
    → 买菜（数据收集——公开数据集/爬虫/购买）
      → 洗菜（数据治理——清洗/消歧/标注）
        → 切菜（特征学习——One-hot → Word Embedding）
```

**核心概念**：
- **结构化数据**：系统产生的规则表格数据
- **非结构化数据**：图像（CV）、文本（NLP）、语音
- **标注四角色**：PM + 算法工程师 + 专家 + 标注人员
- **数据安全**：数据安全法已颁布，泄露数据违法

**关键金句**：
> AI的上限由数据的上限决定

## 第六章：项目管理

**一句话总结**：AI产品经理需要输出四类文档，遵循"十分之一原则"定价。

**四类文档**：

| 文档 | 用途 |
|------|------|
| PRD | 产品功能定义 |
| 技术预研文档 | 业务技术化方案 |
| 标注手册 | 数据标注规范 |
| 测试文档 | 模型效果评估 |

**十分之一原则**：
> AI产品定价 = 节省的人工成本 ÷ 10

## 第七章：案例——分子图像识别

**一句话总结**：分子图像识别 = **目标检测定位（Mask R-CNN） + OCR识别 + 马尔科夫逻辑网络推理**。

**核心洞察**：
- 工业语言三特点：科学性、行业性、通用性
- 新药研发：12年周期、32-36亿美元投入
- AI产品经理需要将"识别化学分子"转化为CV+OCR的技术问题

---

## 第八章：案例——动态知识图谱

**一句话总结**：基于动态知识图谱的心血管疾病全周期管理 = **CDSS + 智能问答 + 知识图谱**。

**核心洞察**：
- 三级覆盖：院前（预防）→ 院中（诊疗）→ 院后（随访）
- 关系型数据库（检索取回型）vs 图数据库（推送推荐型）
- 问答技术演进：填槽式 → KBQA
- 四级数据来源：指南→共识→文献→说明书
