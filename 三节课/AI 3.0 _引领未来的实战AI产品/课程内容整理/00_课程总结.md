## 三、核心知识点总结

### 3.1 人工智能基础

| 知识点 | 核心内容 |
|-------|---------|
| 定义 | 交叉学科，对人的能力和意识进行模仿和超越 |
| AIGC分层 | 芯片层→云服务层→OPS层→根基大模型层→工具层→应用层 |
| AI分类 | 强人工智能（AGI）、中人工智能、弱人工智能 |
| 三大学派 | 符号派（专家系统）、连接派（神经网络）、行为派（机器人） |
| 三要素 | 数据 + 算法 + 算力 |

### 3.2 大模型核心知识

| 知识点 | 核心内容 |
|-------|---------|
| Transformer架构 | Encoder+Decoder，可处理CV、NLP、强化学习、语音、翻译、图数据 |
| GPT系列 | Decoder架构，无监督预训练，擅长文本生成 |
| BERT系列 | Encoder架构，遮蔽语言建模，擅长分类任务 |
| 训练流程 | 数据收集→Token化→Base Model→SFT→RM→RL |
| 压缩优化 | 网络剪枝、分层结构、参数共享、低精度计算 |

### 3.3 AIGC工具矩阵

| 类型 | 代表工具 | 功能 |
|------|---------|------|
| 文本生成 | ChatGPT、Claude、Bard、文心一言、讯飞星火 | 写作、问答、内容生成 |
| 图像生成 | MidJourney、Stable Diffusion | AI插画、图片生成 |
| 人脸处理 | InsideFace | 人脸替换、换脸 |
| 视频制作 | Runway | 文生图、文生视频、图生视频 |
| PPT生成 | Tome | Idea转幻灯片 |
| 数字人 | D-ID | AI真人口播视频 |

### 3.4 AI产品经理能力模型

| 能力层级 | 具体能力 |
|---------|---------|
| L0入门 | 科幻知识、机器人三定律、图灵测试 |
| L1入门 | 机器学习、神经网络、深度学习、知识图谱 |
| L2深入 | 正则表达式、图搜索、增量学习、对话系统 |
| L3专业 | CNN、RNN、文本分析、语义分析 |
| L4专家 |马尔科夫链、集成学习、迁移学习 |
| L5大师 | VC理论、博弈论、流形学习 |
| L6权威 | 量子计算、泛函分析、认知科学 |

**AIGC入门必会：** Prompt、AI编程、API调用、Embedding、框架、Fine-Tuning

### 3.5 AI产品分类

| 类型 | 说明 | 适合人群 |
|------|------|---------|
| 加AI（软件） | 挖掘需求+技术选型+产品开发 | 软件背景 |
| 加AI（软硬件） | 额外BOM规划+硬件设计 | 硬件兴趣者 |
| AI加（行业） | 现有AI+行业解决方案 | 行业专家 |
| AI加（消费） | 公司AI核心算法+C端应用 | 消费品背景 |
| 纯AI（基站） | 底层算法、数据、算力 | 技术背景 |

## 四、实战方法论

### 4.1 加AI产品三阶段

```
阶段一：项目启动
├── 人：团队构建（算法/工程/数据）
├── 钱：预算规划
└── 物：AI技术选择（自研/开源/外包）

阶段二：项目研发
├── 深度理解业务Knowhow
├── 数据预处理
└── 构建AI商业模型

阶段三：项目上线
├── 算力测试
├── 推理能力测试
└── 运营反馈迭代
```

### 4.2 软硬件协同产品流程

```
调研市场方向 → 定义市场需求 → 挖掘需求 → Feature List设计
    ↓
软件设计 → 开发测试 → 产品验证
硬件BOM规划 → 外观ID设计 → 工厂洽谈 → 开模试机
    ↓
软硬件联调 → 小批量生产 → 可靠性测试 → 认证 → 上市
```

### 4.3 数字人技术方案

| 类型 | 技术方案 | 周期 | 数据流 | 适用场景 |
|------|---------|------|--------|---------|
| 超写实1:1 | 720度灯光球+3D建模 | 数月 | 非常大 | 大品牌 |
| Avatar | 特征抓取+渲染 | 较短 | 中等 | 中小品牌 |
| AI渲染2D | 10张图+AI | 极短 | 较小 | 中小卖家 |

### 4.4 新零售AI入手方法

| 方法 | 适用场景 | 核心工具 |
|------|---------|---------|
| 冷启动 | 无历史数据 | 经验规则设计 |
| 数据驱动 | 有历史数据 | 多维分析 |
| RFM模型 | 用户分层 | 距离分析 |
| 相关性分析 | 商品推荐 | 啤酒尿布法则 |
| 智能推荐 | 精准营销 | 协同过滤 |
