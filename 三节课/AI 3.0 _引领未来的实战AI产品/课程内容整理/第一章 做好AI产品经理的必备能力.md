## 一、什么是人工智能

### 1. 人工智能的定义

人工智能是一个交叉学科，本质是对人的能力和意识进行模仿和超越。它既包含计算机科学、心理学、控制学、脑科学等多个学科。

人工智能对人的能力、人的意识的模仿，甚至是超越：
- 视觉感知：人脸识别
- 语言交流：自然语言处理
- 推理和问题求解
- 协同控制

### 2. 人工智能应用案例

#### 今日头条写稿机器人

| 项目 | 人工写稿 | AI写稿 |
|------|---------|--------|
| 素材采集 | 需要采集大量素材 | 自动采集 |
| 选题 | 需要人工选题 | 自动选题 |
| 时间 | 约2小时/篇 | 约2秒/篇 |

#### 智能驾驶

传统驾驶会受到驾驶员情绪影响，而无人驾驶：
- 自动识别路线
- 辅助驾驶
- 高精度地图
- 无情绪波动

```

├────────────────────────────────────┤
```

### 4. 实战案例：淘宝拍照识图

**用户流程：** 拿起手机 → 打开淘宝拍照 → 云端计算 → 推荐相似商品

**技术实现：**
1. 数据采集：用户拍照、行为数据、交易数据、社交数据、传感器数据
2. 算法处理：机器视觉、滤波、特征提取算法
3. 推荐算法：协同过滤、矩阵相似度计算
4. 算力支撑：CPU+GPU计算

### 5. 实战案例：美团即时零售智能推荐

**场景：** 5年以上用户收到智能餐厅推荐

**技术流程：**
1. 数据输入：用户检索文本或图片、5年评论数据、商户编号、评分
2. 算法处理：文本情感分析、机器学习、深度学习、NLP、Transformer架构
3. 结果输出：个性化餐厅推荐

### 7. AI产品岗位建议

**对于想转行做AI产品的应届生或5年内经验者：**
- 从应用层入手是最佳选择
- 不需要很深的技术背景
- 需要懂行业、有行业兴趣

**对于创业者和投资者：**
- 基础层门槛高，但可以"先走窄门"
- 技术层需要谨慎评估
- 应用层机会最多

## 五、未来AI产品经理能力模型

### 1. AI产品经理工作职责

统一闭环流程：
```
业务Knowhow → 需求挖掘 → 数据处理 → AI建模 → 云计算/算力 → 沟通拉通
```

### 2. 案例：钢铁厂炼钢炉温度监测

**需求挖掘：**
- 问题：炼钢炉周边臂温不一致
- 解决：部署温度传感器采集数据
- 数据标注：与有经验的老师傅合作
- AI建模：深度学习决策分类算法
- 算力：数千至上万个传感器同时采集

### 3. AI入门能力模型（左侧图）

- AI3.0技术理解
- AI业务能力
- AI数据知识
- AI运营营销能力

### 4. AI深度学习技术（右侧图）

- 知识表示
- 专家系统
- 支持向量机（SVM）
- NLP自然语言处理
- 干神经网络
- 计算机视觉
- CNN卷积神经网络
- RNN循环神经网络
- Word2Vector
- Embedding嵌入
- 深度学习

### 5. AI产品经理核心能力

| 能力项 | 具体内容 |
|-------|---------|
| Prompt能力 | 大语言模型生成原理、高质量Prompt编写、COT思维链 |
| AI编程能力 | GitHub Copilot、CodeWhisperer、MetaGPT等 |
| API调用能力 | 自然语言连接一切 |
| Embedding能力 | Token化计算、向量化处理 |

| 备案能力 | 算法备案（新增要求） |

### 6. AI产品经理分类

| 类型 | 特点 | 适合人群 |
|------|------|---------|
| AI产品经理（软件型） | 场景需求挖掘、技术选型、产品开发 | 软件背景从业者 |
| AI产品经理（软硬件协同型） | 额外需要BOM规划、硬件外观设计、开模 | 有硬件兴趣者 |
| 行业型AI产品经理 | AI+行业融合 | 行业专家转型 |
| 消费型AI产品经理 | 零售型AI产品开发 | 消费品背景 |
| 纯AI产品经理（基站型） | 底层算法、数据、算力 | 技术背景深厚者 |

### 7. 如何成为AI3.0产品经理

**关键步骤：**
1. 打基础、练内功
2. 找到好的导师建立长期陪跑关系
3. 找适合的落地场景
4. 干起来！

**两周成为行业专家的方法：**
1. 快速构建自己的知识结构
2. 学会检索（工具检索、人检索）
3. 知识分层（区域、难易、学科）

**供应链熟悉建议：**
- 硬件方向：去深圳考察
- 算法方向：去上海考察（天数智芯、壁仞科技等）
