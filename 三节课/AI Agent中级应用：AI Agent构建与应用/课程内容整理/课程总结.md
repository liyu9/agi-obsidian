## 二、核心概念

### 2.1 什么是AI Agent

**定义：** 在大模型时代，让你无痛构建起一个懂你的App。

**核心价值：**
- 让企业运用更具意义和价值
- 让AI具备长期记忆能力
- 打造专属的专业特长生
- 一个人就是一支队伍

### 2.2 知识库

**定义：** 能够提供个性化知识输入，方便智能体检索，避免全网搜索造成的信息偏颇。

**知识库的意义：**
```
通用大模型 → 企业专业小模型
泛化知识   → 私域知识
通用回答   → 精准专业回答
```

## 三、核心方法论

### 3.1 四步法创建知识库

| 步骤 | 名称 | 核心内容 |
|------|------|----------|
| 第一步 | 问AI拿框架 | 了解工作内容的全貌（维度、流程、阶段） |
| 第二步 | 问AI拿目标 | 了解工作产出物（文档形式、格式要求） |
| 第三步 | 问AI拿标准 | 了解产出物特征，设置前置条件 |
| 第四步 | 调优反馈拿结果 | 细化要求，优化补充细节 |

**效果：** 通过四步法至少可以搞定工作当中60%到80%的工作。

### 3.2 三级六步法创建AI Agent

```
┌─────────────────────────────────────────────┐
│           三级六步法                         │
├─────────────────────────────────────────────┤
│  第一级：准备知识库                          │
│         ↓                                    │
│  第二级：创建智能体                          │
│         ↓                                    │
│  第三级：应用智能体                          │
└─────────────────────────────────────────────┘
```

### 3.3 简历评分智能体业务流程

```
岗位职责说明书 → 模拟简历 → 智能评分 → 面试问题设计 → 角色扮演模拟
```

## 四、工具对比

### 4.1 智谱AI vs 讯飞星火

| 维度 | 智谱AI | 讯飞星火 |
|------|--------|----------|
| 知识库回调显示 | ✅ 支持 | ❌ 不支持 |
| 调试效果 | ✅ 好 | 一般 |
| 知识库呈现效率 | ✅ 高 | 一般 |
| 工作流创建 | 一般 | ✅ 更优秀 |
| 整体评价 | **首选** | 备选/补充 |

**建议：** 根据需求选择合适的工具，可两者结合使用。

### 4.2 知识库支持格式

| 类别 | 格式 |
|------|------|
| Office文档 | Word、Excel、PPT |
| PDF文档 | PDF、扫描文件 |
| 图片 | JPG、PNG |
| 多媒体 | 音频、视频 |
| 电子书 | 多种格式 |

## 五、典型案例

### 5.1 简历筛选智能体

**功能：** 根据岗位说明书对简历进行智能评分

**流程：**
1. 上传岗位说明书到知识库
2. 让AI模拟候选人简历
3. AI进行差异化评分
4. 设计面试问题
5. 角色扮演模拟面试

### 5.2 智能营销助手

**功能：** 根据客户需求推荐产品并生成营销物料

**案例：** 中国移动新业务推荐助手
- 业务推荐
- 套餐查询（表格形式）
- 用户画像分析
- 个性化产品推荐
- 营销话术撰写
- 配图生成

### 5.3 企业应用案例

| 场景 | 智能体名称 | 核心功能 |
|------|------------|----------|
| 党务 | 党建助手 | 达标评分、标准查询 |
| 培训 | 继续教育达人 | 证书推荐、路径规划 |
| 人事 | 简历评分大师 | 智能筛选、差异化评分 |
| 财务 | 薪酬助手 | 核算方法、数据查询 |
| 采购 | 招投标管理 | 规范查询、注意事项 |
| 销售 | 智能营销员 | 产品推荐、话术生成 |

## 六、关键配置要点

### 6.1 提示词配置

**重要性：** 影响智能体运行好坏的关键因素

**优化方法：** 使用AI工具（如Kimi提示词专家）优化提示词

### 6.2 知识库回答设置

| 场景 | 配置方式 |
|------|----------|
| 回答需要谨慎 | 关闭联网，开启"仅从知识库回答" |
| 希望知识库优先再联网 | 开启联网能力 |

### 6.3 温度设置

| 参数 | 说明 |
|------|------|
| 温度值 | 控制输出随机性 |
| 值越大 | 随机性越高 |
| 值越小 | 输出越稳定 |

## 七、重要原则

### 7.1 数据安全原则

> ⚠️ **重要提醒：在使用知识库时，请千万注意数据安全！**

| 注意事项 | 说明 |
|----------|------|
| 不要上传真实业务数据 | 防止企业机密泄露 |
| 做好数据脱敏 | 脱敏后再上传 |
| 注意隐私保护 | 个人信息要加密或脱敏 |

### 7.2 实践原则

> **建议：先完成后完美，逐步去做迭代。**

| 实践方式 | 说明 |
|----------|------|
| 聚焦业务痛点 | 从具体问题切入 |
| 针灸型案例 | 一个一个解决问题 |
| 逐步扩大 | 从小场景到大范围 |

### 7.3 角色转变

| 传统角色 | AI时代角色 |
|----------|------------|
| 单一任务操作工 | 管理者 |
| 执行者 | 监督检查者 |
| 人工操作 | AI员工协同 |

## 九、课后练习

### 练习任务

创建一个和你工作相关的智能体，**需要包含知识库**。

### 完成步骤

1. **完成智能体基本配置**
   - 名称、简介
   - 提示词编写
   - 界面组件设置
   - 知识库上传

2. **发布智能体**
   - 生成分享链接
   - 选择发布模式（私密/分享/公开）

3. **测试验证**
   - 智能问答测试
   - 验证知识库读取
   - 检查回答准确性
