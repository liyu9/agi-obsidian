# 第二节 创建简历评分大师（上）

## 课程导入

同学们好，接下来我们学习三级六步法创建AI Agent智能体。

### 三级六步法概述

| 级别 | 内容 | 说明 |
|------|------|------|
| **第一级** | 准备知识库 | 上传企业文档 |
| **第二级** | 创建智能体 | 配置并发布 |
| **第三级** | 应用智能体 | 智能问答测试 |

**AI Agent的实质：** 在大模型时代，让你无痛构建起一个懂你的App。

---

## 一、AI Agent应用场景

顺着业务流程继续往下走，让AI帮你进行简历的智能筛选。

**构建目标：** 创建一个选材助手，让它对提供的简历进行智能打分。

---

## 二、智能体创建与配置

### 2.1 进入智能体中心

打开智谱AI平台，在**智能体中心**中点击"创建智能体"。

### 2.2 查看已有智能体

可以查看已创建的各类型智能体，包括：
- 创建时间
- 使用情况
- 对话轮数
- 热度

可以点击右侧小铅笔按钮进行编辑或删除。

### 2.3 创建新的智能体

**示例配置：简历筛选大师**

```
一句话描述：
可以通过用户提供的简历情况，结合知识库中的岗位职责说明书，
对用户提供的简历进行智能评分，同时给出评分结果并说明理由。
```

---

## 三、智能体配置详解

### 3.1 基本信息配置

| 配置项 | 说明 |
|--------|------|
| 头像 | 可点击让AI自动生成新头像 |
| 名称 | 智能体的名称 |
| 简介 | 简单描述智能体功能 |

**配置示例：**

- **名称：** 简历评分大师
- **简介：** 你专注于用户提供的简历和岗位职责说明书进行智能评分
- **角色：** 高效筛选简历，给出评分的理由
- **能力：** 123（具体能力列表）

### 3.2 提示词配置（关键）

提示词配置是影响智能体运行好坏的关键。

智谱AI提供多种配置模式：

| 模式 | 适用场景 |
|------|----------|
| 工具类 | 功能性智能体 |
| 游戏类 | 娱乐类智能体 |
| 角色类 | 角色扮演类智能体 |
| 画图类 | 图像生成类智能体 |

### 3.3 提示词优化技巧

**使用AI工具优化提示词：**

1. 打开Kimi的"提示词专家"
2. 将智谱AI生成的默认配置信息复制过来
3. 让AI帮你优化成更专业的提示词

**优化示例：**

```
你是一个专业的简历评分师。你的背景是：用户需要对候选人的简历
进行智能评分，以确定其是否符合特定岗位的要求。用户将提供候选人
的简历和岗位职责说明书作为评分依据。
```

## 四、界面定制

### 4.1 对话模式

有两种模式可选：

| 模式 | 说明 |
|------|------|
| 普通对话 | 标准的头像+对话样式 |
| 自定义UI | 可自主添加组件 |

### 4.2 自定义UI组件

支持多种组件类型：

| 组件类型 | 用途 |
|----------|------|
| 单行文本 | 简短输入 |
| 多行文本 | 详细描述 |
| 文本段落 | 长文本输入 |
| 分类 | 类别选择 |
| 下拉选项 | 预设选项 |
| 附件上传 | 文件上传 |

**示例：添加下拉选项**

```
标题：请选择需要分析的岗位
选项：
- AI智能办公专家
- HR总监
- 产品经理
- 拓展选项（默认选择为"其他"）
```

### 4.3 提示词结构配置

点击选择的内容会自动拼接成对应的提示词：

```
前面是固定的文本字符串
后面是变量（你刚刚下拉选择的内容）
```

**示例：**

```
请你告诉我这个岗位的岗位职责说明书中的具体招聘要求是什么。
```

## 五、对话配置

### 5.1 开场白

设置用户首次进入时的问候语和介绍。

### 5.2 预置问题

用户不知道该如何提问时，提供预设的引导性问题。

### 5.3 下一步问题建议

开启后，AI会自动联想和扩充用户下一步可能想问的问题。

**核心价值：** 解决"用AI最难的是什么？最难的是提问"的问题。

## 六、能力配置

### 6.1 插件功能

通过智能体自动调用外部插件来实现复杂的功能：

| 功能类型 | 说明 |
|----------|------|
| 自建插件 | 通过API接口连接公司数据库 |
| 插件市场 | 官方提供的工具（如思维导图、流程图、PPT生成等） |

### 6.2 案例：高德地图插件

**智慧出行助手案例：**

**需求背景：** 拜访广州市三个客户（增城区玉湖街道、黄埔区大沙地、番禺大学城），早上六点抵达广州南站，如何规划路线？

**实现方式：**
1. 在智能体中调用高德地图插件
2. 使用三个工具：获取经纬度、地址返回、路径规划

**插件工具：**
- 获取经纬度
- 地址返回
- 坐标之间做规划路径

**结果：** AI自动规划出最佳访问路径：
1. 广州南站 → 增城区（打车，时间和费用）
2. 增城区 → 黄埔区（地铁，时间和费用）
3. 黄埔区 → 番禺大学城（最后结束点，可直接上高铁离开）

**实际应用场景：** 平时拜访ABC三个不同客户时，通过高德插件+智谱AI智能体，扩大应用场景，提高效率。

## 七、本节要点总结

### 智能体创建流程

```
┌─────────────────────────────────────────────────────────┐
│              创建AI Agent智能体                         │
├─────────────────────────────────────────────────────────┤
│  1. 进入智能体中心 → 创建智能体                         │
│  2. 配置基本信息（头像、名称、简介）                     │
│  3. 编写提示词（影响运行好坏的关键）                     │
│  4. 自定义UI组件（根据需要添加）                        │
│  5. 设置对话配置（开场白、预置问题、下一步建议）         │
│  6. 配置能力（插件、外部接口）                         │
│  7. 发布智能体                                          │
└─────────────────────────────────────────────────────────┘
```

### 关键提示

1. **提示词是关键：** 影响智能体运行好坏的核心因素
2. **善用AI优化工具：** 如Kimi的"提示词专家"
3. **灵活添加组件：** 根据业务需求定制界面
4. **插件扩展能力：** 可连接企业数据库、外部API
