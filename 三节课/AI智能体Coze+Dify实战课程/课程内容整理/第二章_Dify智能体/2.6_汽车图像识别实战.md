# 汽车图像识别实战

## 一、项目需求

通过上传汽车图片，自动识别车型、品牌、参数等信息

## 二、工作流创建

### 创建流程
1. 控制台 → 创建空白应用
2. 选择"创建工作流"
3. 输入应用名称（汽车图像识别）
4. 点击创建

## 三、工作流配置

### 架构
```
开始（上传图片）→ LLM（图像理解）→ 结束（输出结果）
```

## 四、节点配置详解

### 1. 开始节点
- 添加字段：image
- 字段类型：单文件
- 显示名称：image
- 上传类型：图片
- 上传方式：本地上传
- 设置为必填

### 2. LLM节点
#### 模型选择
- 需要选择支持图像识别的模型
- 推荐：通义千问视觉模型 / 火山方舟视觉模型

#### 视觉配置
- 开启视觉功能
- 输入图片：将image变量与视觉输入关联
- 接收图像内容进行理解

#### 提示词配置
输入图像识别指令，让模型分析图片内容并输出车辆信息

### 3. 结束节点
- 设置输出变量
- 接收LLM的分析结果
- 输出车辆识别信息

## 五、图像识别功能

### 识别内容
- 车辆型号
- 品牌
- 参数配置
- 生产年份
- 动力系统
- 其他特征

### 示例输出
```
车型：小米SU7
参数：搭载前后双电机四驱系统
特点：高性能纯电动轿车
生产年份：2024
```

## 六、火山方舟模型接入

### 创建推理接入点
1. 火山方舟 → 在线推理
2. 创建推理接入点
3. 添加视觉模型（如Qwen-VL）
4. 获取接入点ID和模型名称

### Dify配置
1. 模型名称：填入火山方舟的模型名称
2. API Key：填入火山方舟API Key
3. Endpoint ID：填入接入点ID
4. 选择LLM类型

## 七、测试运行

### 测试步骤
1. 上传本地汽车图片
2. 点击运行
3. 查看识别结果

### 验证效果
检查返回的车辆信息是否准确
