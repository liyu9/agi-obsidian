# Ollama本地部署

## 一、Ollama概述

Ollama是开源工具，用于在本地计算机快速部署和运行大型语言模型，让用户无需依赖云端服务即可运行各种AI模型。

## 二、为什么需要Ollama

### 传统方式
调用云端大模型API，需要付费

### 本地部署优势
- 使用本地GPU服务器
- 无需持续付费
- 数据本地处理
- 可运行开源模型

## 三、服务器配置要求

| 资源 | 最低要求 | 推荐配置 |
|------|----------|----------|
| GPU | 支持CUDA | 高性能显卡 |
| CPU | 2核 | 多核处理器 |
| 内存 | 4GB | 8GB以上 |
| 硬盘 | 50GB | 更大容量 |

## 四、安装部署

### Docker安装Ollama
```bash
docker run -d ollama/ollama
```

### 进入容器
```bash
docker exec -it <容器ID> /bin/bash
```

## 五、常用命令

| 命令 | 功能 |
|------|------|
| `ollama serve` | 启动Ollama服务 |
| `ollama create` | 创建模型 |
| `ollama show` | 查看模型信息 |
| `ollama run` | 下载并运行模型 |
| `ollama push` | 推送到仓库 |
| `ollama pull` | 从仓库拉取模型 |
| `ollama list` | 查看本地模型 |
| `ollama ps` | 查看运行中的模型 |
| `ollama cp` | 复制模型 |
| `ollama rm` | 删除模型 |

## 六、模型运行

### 下载并运行模型
```bash
ollama run deepseek-r1:7b
```

### 模型大小说明
- 功能越强大的模型，存储越大
- 需要足够硬盘、GPU、CPU、内存支持
- 服务器配置低会导致响应慢

### 本地对话测试
运行模型后可直接在终端与AI对话
