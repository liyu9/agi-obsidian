# Dify接入大模型

## 一、支持接入的模型

### 主要模型供应商
| 供应商 | 说明 |
|--------|------|
| DeepSeek | 深度求索大模型 |
| 豆包 | 字节跳动大模型 |
| 通义千问 | 阿里云大模型 |
| Ollama | 本地模型 |
| 火山方舟 | 字节火山引擎 |

## 二、接入配置步骤

### 1. 安装模型供应商
- 设置 → 模型提供商
- 选择要安装的供应商
- 点击安装

### 2. 配置API Key
每个供应商都需要配置API凭证

#### DeepSeek配置
1. 访问DeepSeek官网
2. API开放平台 → API Key管理
3. 创建API Key
4. 复制到Dify配置

#### 通义千问配置
- 使用阿里云百炼平台
- 百炼控制台 → 密钥管理
- 创建API Key并配置

#### 火山方舟配置
1. 访问火山方舟控制台
2. 创建AI Key
3. 配置区域（如华北二北京）
4. 获取模型名称

## 三、Ollama本地模型接入

### 服务器端准备
1. Docker安装Ollama
2. 拉取模型（如DeepSeek）
```bash
docker exec -it ollama ollama pull deepseek-r1:7b
```

### Dify端配置
1. 安装Ollama供应商
2. 添加模型
   - 模型名称：deepseek-r1:7b
   - 基础URL：http://服务器IP:11434
   - 模型类型：LLM对话

### 验证连接
- Dify会自动调用Ollama运行模型
- 可在Ollama容器内通过`ollama ps`查看运行状态
