# 法律咨询智能体实战

## 一、应用类型选择

### Dify空白应用类型
| 类型 | 说明 |
|------|------|
| 聊天助手 | 构建LLM对话机器人 |
| Agent | 具备推理与工具调用能力 |
| 工作流 | 自动化任务编排 |
| 文本生成 | AI文本生成任务 |

## 二、创建法律咨询应用

### 创建流程
1. 控制台 → 创建空白应用
2. 选择应用类型（聊天助手）
3. 输入名称和描述
4. 点击创建

## 三、核心配置

### 1. 提示词配置
- 可手动编写
- 可使用AI生成功能

#### 生成方法
1. 输入简单指令
2. 选择模型（如DeepSeek）
3. 生成完整提示词
4. 应用到配置

### 2. 模型选择
- 推荐使用DeepSeek等推理能力强的模型

### 3. 变量配置
- 定义用户输入变量
- 设置必填/非必填
- 配置变量类型

## 四、知识库集成（可选）

### 支持的文件类型
- 文本文件
- 表格文件
- PDF文档
- Word文档
- 更多格式...

### 添加知识库
1. 在应用中添加知识库模块
2. 上传文档文件
3. 系统自动处理

## 五、测试与发布

### 测试对话
- 在调试栏输入问题
- 查看回答效果
- 验证功能是否正常

### 示例测试
**问题**：离职是否需要提前一个月申请？

**预期回答**：提供详细的辞职相关法律知识

### 发布应用
1. 点击发布
2. 获取应用链接
3. 分享给用户使用

## 六、费用与限制

### 模型调用
- 使用API需要付费
- 按实际调用量计费

### 使用建议
- 测试阶段使用免费额度
- 正式使用前做好预算规划
