# AI智能体Coze+Dify实战课程总结

## 一、课程概述

本课程系统讲解了两个主流AI智能体开发平台：**Coze（扣子）** 和 **Dify**，通过17个实战项目帮助学员掌握智能体开发的核心技能。

---

## 二、Coze智能体开发（11个项目）

### 核心概念

#### 智能体定义
通过配置工作流，让AI自动执行完成特定任务的应用

#### 三种模式对比

| 模式 | 比喻 | 适用场景 | 构建方式 |
|------|------|----------|----------|
| 对话流 | 剧本演绎 | 智能客服、咨询问答 | 可视化拖拽 |
| 工作流 | 流水线机械臂 | 自动化任务执行 | 可视化拖拽 |
| 自主规划模式 | AI大脑 | 复杂问题求解 | 提供目标指令 |

### 平台核心功能

#### 1. 插件系统
- 使用官方插件
- 调用第三方API
- 自定义开发插件（Python）

#### 2. 知识库功能
- 上传文档建立知识库
- 支持RAG检索增强生成
- 企业私有问题解答

#### 3. 模型支持
- 豆包、通义千问、DeepSeek等
- 多模态能力（图像理解、生成）

### 实战项目汇总

| 项目 | 核心技能 | 主要功能 |
|------|----------|----------|
| 疾病诊断智能体 | 基础配置、人设编写 | 智能问诊 |
| 智能换脸 | 图像处理节点 | 人脸替换 |
| 小红书评论拉取 | API调用、代码块 | 数据采集与分析 |
| 插件开发 | Python编程 | 自定义工具 |
| 智能出题 | 多分支选择、知识库 | 自动出题 |
| 新闻推送 | 数据处理、大模型整理 | 新闻聚合 |
| 图文生成 | 图像生成、画板编辑 | 内容创作 |
| 智能客服 | 意图识别、多知识库 | 专业问答 |
| 私有化部署 | 服务器配置 | 自主可控部署 |

### 工作流核心节点

```
┌─────────────────────────────────────────┐
│            节点类型                      │
├─────────────────────────────────────────┤
│ 大模型：内容生成、对话、推理             │
│ 插件：扩展功能、第三方集成               │
│ 代码块：数据处理、格式转换               │
│ 知识库：RAG检索、内容查询               │
│ 选择器：条件分支、流程控制               │
│ 循环：批量处理、遍历数据                │
│ 变量聚合：多路径输出整合                │
│ 意图识别：智能判断、自动分流             │
└─────────────────────────────────────────┘
```

## 三、Dify智能体开发（6个项目）

### 平台特点

| 特点 | 说明 |
|------|------|
| 开源可控 | 完全开源，支持私有化部署 |
| 面向开发者 | 更灵活的控制权 |
| 企业友好 | 适合企业级应用开发 |

### 与Coze对比

| 维度 | Dify | Coze |
|------|------|------|
| 定位 | 开发者/企业 | 普通用户 |
| 插件生态 | 需自行开发 | 丰富现成插件 |
| 易用性 | 较复杂 | 简单易上手 |

### 核心技能

#### 1. Ollama本地部署
- Docker安装运行
- 本地模型管理
- 无API费用优势

#### 2. 多模型接入
- DeepSeek
- 通义千问
- 豆包/火山方舟
- Ollama本地模型

#### 3. 应用类型
- 聊天助手
- Agent（工具调用）
- 工作流
- 文本生成

### 实战项目汇总

| 项目 | 核心技能 | 主要功能 |
|------|----------|----------|
| Dify部署 | Docker安装 | 平台搭建 |
| Ollama部署 | 本地模型 | 离线运行 |
| 模型接入 | API配置 | 多模型集成 |
| 法律咨询 | 提示词配置 | 专业问答 |
| 汽车图像识别 | 视觉模型 | 图像分析 |
