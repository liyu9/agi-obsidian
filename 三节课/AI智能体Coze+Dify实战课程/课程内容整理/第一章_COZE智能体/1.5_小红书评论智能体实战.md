# 小红书评论智能体实战

## 一、项目需求

1. 拉取小红书评论
2. 通过大模型判断评论情感（好评/中评/差评）
3. 将评论内容、用户名、评价写入飞书表格

## 二、工作流架构

```
开始 → 小红书评论拉取 → 循环 → 评价分析(大模型) → 整理数据(代码) → 插入数据(飞书) → 结束
```

## 三、关键节点配置

### 1. 小红书评论拉取
- 使用官方"小红书"插件
- 配置参数：
  - Cookie（登录获取）
  - 笔记URL
  - 评论总数
- 在开始节点配置string和number类型变量

### 2. 获取Cookie方法
1. 登录小红书
2. 右键 → 检查 → Network
3. 刷新页面
4. 找到cookie字段，复制完整内容

### 3. 循环节点
- 用于遍历每条评论
- 依次执行后续节点

### 4. 评价分析（大模型）
- 输入：评论内容
- 系统提示词：扮演语言分析专家，判断好评/中评/差评
- 限制：只输出三种评价之一

### 5. 整理数据（代码块）
- 获取变量：
  - 评论内容
  - 用户名
  - 评价结果
- 按飞书表格格式构建输出对象

### 6. 插入飞书表格
- 使用"飞书多维表格"插件
- 配置app_token（表格链接）
- 字段格式：key-value形式

## 四、飞书表格配置

### 创建表格
1. 登录飞书
2. 创建多维表格
3. 修改字段名称（必须与代码中一致）：
   - 用户评论
   - 评价分析
   - 用户名

### 字段类型
全部设置为"文本"类型

### 授权操作
首次使用需授权飞书多维表格

## 五、调试技巧

### 常见问题排查
1. **获取数据为空**：检查循环节点选择的字段是否正确（应选最外层字段）
2. **写入失败**：检查字段名称和类型是否匹配
3. **评价不准确**：优化系统提示词

### 数据查看
- 通过各节点的"输出"功能查看数据
- 使用"预览"功能查看大模型返回结果
