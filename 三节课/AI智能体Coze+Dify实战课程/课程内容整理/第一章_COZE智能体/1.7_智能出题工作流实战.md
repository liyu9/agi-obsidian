# 智能出题工作流实战

## 一、项目需求

根据用户输入的内容（文件/图片/手动输入/知识库）自动生成考试题目

### 出题类型
- 选择题（10道）
- 判断题（10道）
- 填空题（10道）
- 简答题（10道）

## 二、工作流架构

```
开始 
  ↓
┌─────────────────────────────────────┐
│ 选择器（判断输入类型）               │
├──────────────┬──────────────┬──────┤
│ 手动输入     │ 文件读取     │ 图片 │
└──────────────┴──────────────┴──────┘
        ↓            ↓           ↓
    内容处理 ←── 内容处理 ←── 内容处理
        ↓            ↓           ↓
    变量聚合 ←── 变量聚合 ←── 变量聚合
        ↓            ↓           ↓
    生成文档（DOC） → 结束
```

## 三、四种输入方式

### 1. 手动输入
- 配置string类型变量
- 直接输入出题内容

### 2. 文件输入
- 使用"文件读取"插件
- 支持上传DOC文件
- 在开始节点配置file类型变量

### 3. 图片输入
- 使用"图片理解"插件
- 上传图片自动识别内容
- 配置image类型变量

### 4. 知识库输入
- 创建知识库上传文档
- 使用"知识库检索"节点
- 大模型根据检索结果出题

## 四、核心节点配置

### 选择器（条件分支）
- 判断各输入是否为空
- 只执行有值的分支
- 实现多路径选择

### 大模型节点
- 系统提示词：扮演出题专家
- 输入：获取的内容变量
- 输出：生成的题目

### 变量聚合
- 获取各分支的输出
- 选择有值的变量传给后续节点
- 解决多路径输出问题

### 生成文档
- 使用"生成文档"插件
- 格式：DOC/PDF/HTML/MD
- 输入：大模型生成的题目

## 五、知识库创建

### 上传知识库
1. 资源库 → 知识库 → 添加
2. 选择文档类型（文本/表格/图片）
3. 上传本地文档
4. 使用智能标注或人工标注

### 知识库检索配置
- 搜索策略：混合（语义+全文）
- 最大召回数量：返回段落数
- 最小匹配度：筛选阈值

## 六、图片标注说明

| 标注方式 | 说明 |
|----------|------|
| 智能标注 | AI自动分析图片内容生成描述 |
| 人工标注 | 手动输入图片关键字和描述 |

### 智能标注优势
- 自动理解图片内容
- 提供详细描述信息
- 提高用户问题匹配度
