# Coze平台介绍

## 一、智能体概念

### 什么是智能体
智能体是通过配置工作流，让工作流完成特定任务的AI应用。

### 生活化比喻
- **洗衣服智能体**：放衣服 → 加洗衣液 → 配置洗涤方式 → 设置时间
- **炒菜智能体**：洗锅 → 放油 → 放青菜

智能体就是将一系列步骤配置成工作流，让AI自动执行完成。

---

## 二、Coze核心特点

| 特点 | 说明 |
|------|------|
| 低代码开发 | 无需编写复杂代码，通过拖拽配置工作流 |
| 插件功能 | 集成外部工具和能力，支持知识库、第三方API、自定义代码插件 |
| 知识库功能 | 上传文档让大模型学习，通过RAG（检索增强生成）回答企业私有问题 |
| 强大模型支持 | 支持豆包、DeepSeek、通义千问等多种模型 |
| 灵活发布部署 | 可发布到Coze平台、飞书、微信公众号、小程序，支持API集成和独立网页 |

---

## 三、知识库核心价值

### 应用场景
当企业有内部知识（如员工规则、业务手册）时，大模型本身不知道这些内容。

### 解决方案
通过知识库功能，让大模型搜索学习知识库内容后回答用户问题，实现RAG（检索增强生成）。
