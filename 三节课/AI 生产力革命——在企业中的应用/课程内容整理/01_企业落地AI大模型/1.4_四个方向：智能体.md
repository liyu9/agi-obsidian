# 1.4 四个方向：智能体

## 一、智能体概念

### 1. 发展阶段的定义

OpenAI创始人提出的AI五个发展阶段中，第三个阶段是智能体阶段（L3）。

### 2. 智能体的本质

**智能体（Agent）** = 可以代理用户采取行动的人工智能代理

### 3. 智能体与智能驾驶的类比

```
智能驾驶 = 传感器（感知） + 大模型（思考） + 执行器（代理）
              ↓                    ↓              ↓
智能体     = 数据采集（感知）  + 大模型（思考） + 执行动作（代理）
```

### 4. Agent核心架构

```
┌─────────────────────────────────────┐
│           Agent架构                  │
├─────────────────────────────────────┤
│                                     │
│     代理（Agent）                     │
│         ↓                            │
│   ┌─────────────────────────┐       │
│   │  记忆（Memory）          │       │
│   │  - 长期记忆              │       │
│   │  - 短期记忆              │       │
│   └─────────────────────────┘       │
│         ↓                            │
│   ┌─────────────────────────┐       │
│   │  工具（Tools）           │       │
│   │  - 搜索                  │       │
│   │  - 天气                  │       │
│   │  - 日历                  │       │
│   │  - 其他API               │       │
│   └─────────────────────────┘       │
│         ↓                            │
│   ┌─────────────────────────┐       │
│   │  计划（Plan）            │       │
│   │  计划不同任务             │       │
│   └─────────────────────────┘       │
│         ↓                            │
│   ┌─────────────────────────┐       │
│   │  执行（Execute）         │       │
│   │  执行一系列动作           │       │
│   └─────────────────────────┘       │
│                                     │
└─────────────────────────────────────┘
```

### 5. 大模型 vs 智能体

| 维度 | 大模型 | 智能体 |
|------|--------|--------|
| **核心能力** | 思考和理解 | 感知和执行 |
| **比喻** | 大脑 | 手+脚+工具 |
| **功能** | 训练到推理 | 采集+代理 |

## 二、智能体工作流

### 1. 工作流架构

```
┌──────────────────────────────────────┐
│           工作流（中间层）             │
├──────────────────────────────────────┤
│                                      │
│   任务输入                            │
│       ↓                              │
│   ┌──────────────────────────┐       │
│   │  层级递进的工作流          │       │
│   │  ↓                        │       │
│   │  执行特定动作              │       │
│   │  ↓                        │       │
│   │  调用特定能力              │       │
│   └──────────────────────────┘       │
│       ↓                              │
│   交付成果                            │
│                                      │
└──────────────────────────────────────┘
```

### 2. 工作流示例

典型的工作流：
- 调用两次大模型
- 在不同路径做意图判断
- 实现两个分支
- 最终汇总交付成果

## 四、智能体开发平台推荐

### 1. Coze（字节跳动）

**特点**：
- 支持字节旗下多个App
- 海量模板可用
- 有商店可付费调用
- 基于豆包大模型
- 使用简单

**模板分类**：
- 营销创作
- 信息处理
- 聊天陪伴
- 零售提效
- 学习教育
- 客服

### 2. 元气（腾讯）

**特点**：
- 与元宝一套系统
- 支持多模态
- 兼容公众号、微信、企业微信
- 知识库可授权调用公众号信息
- 快速完成知识库建设

**发布渠道**：
- 微信客服
- 公众号
- 订阅号
- 企业微信
- 小程序

### 3. Dify（开源）

**特点**：
- 开源平台
- 创始人曾在腾讯工作
- 支持Co/Coding平台
- 多云平台使用
- 开源模型一键云端部署

### 4. 腾讯AI开发套件

**功能**：
- 配置化搭建AI Agent
- 开发者托管和扩展
- 基于MCP协议

**客户端支持**：
- 小程序
- 公众号
- 企业微信
- Web端

**开发方式**：
- SEK内嵌方式
- HDM API调用

**效率**：5分钟内完成Agent搭建，快速发布

## 五、智能体开发流程

无论使用哪个平台，开发逻辑基本相同：

```
1. 知识库建设
   ↓
2. API调用能力配置
   ↓
3. 插件集成
   ↓
4. 工作流建设
   ↓
5. 测试和发布
```

## 六、学习要点

> - 智能体 = 大脑（思考）+ 手脚（执行）+ 工具
> - Agent架构：记忆 + 工具 + 计划 + 执行
> - 覆盖9大部门37个典型场景
> - 三大开发平台：Coze（元气）、Dify、腾讯AI套件
> - 开发逻辑：知识库 → 工作流 → 插件 → 测试发布
