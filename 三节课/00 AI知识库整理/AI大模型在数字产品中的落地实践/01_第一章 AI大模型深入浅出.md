# 第一章 AI大模型深入浅出

## 开场语

各位同学大家好，欢迎来到第一章AI大模型深入浅出。我们的目标是从第一性视角来理解AI，站在非技术的视角帮助大家理解AI的本质和特性。

## 第一节 AI的本质与学习阻碍

### AI与人工智能的核心定义

**国际标准化组织（ISO）定义**：人工智能是一个领域，要为一组给定的人类定义的目标来生成输出，从而构建一套相应的工程系统。

**IBM定义**：人工智能是让计算机和机器能够模拟人类的智能以及解决问题的能力。

核心结论：**AI不复杂，它就是模拟人类智能的技术。** 任何一个技术或术语，只不过是在描述它模拟人类智能的方式与方法或技巧。

### 大模型的定义

**IBM对大语言模型的定义**：基于海量数据来训练模型，让它们能够理解和生成自然语言以及其他类型的内容，执行各种各样的任务。

**中国人工智能学会定义**：大语言模型通过在海量数据上进行大规模训练，学习到大量语言知识和世界知识，并通过指令微调、人类对齐等关键技术，拥有了**面向多任务的通用求解能力**。

核心差异：大模型和其他专用模型的区别在于它具备**通用能力**——可以创作、分类、分析、编程等一系列事情。

### 学习AI的阻碍分析

| 阻碍 | 原因 | 本课程的解法 |
|------|------|-------------|
| 技术材料太多，术语复杂 | 看到的是神经网络、微调、蒸馏、注意力机制等 | 用智能视角替代技术视角 |
| 与产品经理熟悉的需求方案视角不同 | 技术上远离产品经理的经验范围 | 放松心态，技术不是AI的门槛 |

> **金句**：技术绝对不是学习AI的门槛。只要你能够理解AI背后的逻辑，我们其实可以快速转身成为一个懂AI的产品经理。

## 第二节 智能视角理解AI大模型

### AI发展的本质——模拟人类智能

AI就是用机器来模拟人的智能。人类通过人类大脑（碳基生物），拥有感知、认知、决策、沟通、执行、创作、情感等智能。

人工智能（硅基智能）用芯片来模拟智能。AI发展路径映射到人的成长路径：

| AI发展阶段 | 智能水平类比 | 核心机制 |
|-----------|-------------|---------|
| 专家系统 | 幼儿园小孩 | 基于规则（看到A就执行B） |
| 机器学习（统计方法） | 小学一二年级 | 基于向量计算，处理多维度数据 |
| 神经网络/深度学习 | 专业级识别能力（保安） | 模拟人脑物理结构，GPU算力驱动 |
| 大模型 | 本科应届生 | 规模法则（Scaling Law），智能涌现 |

### 规模法则（Scaling Law）
当模型规模变得足够大的时候，效果会突然变得很好，智能就会涌现出来。就像从昆虫的脑子→导盲犬的脑子→人的脑子，到人的脑子时智慧就涌现了，能完成的任务突然扩大了很多倍。

### 当下大模型的真实水平——本科应届生水平

- **会什么**：理解复杂概念，掌握大量知识
- **不会什么**：缺乏上下文理解，缺乏弦外之音理解，缺乏场景感知
- **意味着什么**：需要"辅导"它，给它更全面更明确的指示

#### 典型对比案例

| 场景 | 普通提示词效果 | 优质提示词效果 |
|------|--------------|--------------|
| 审合同 | 泛泛而谈 | 指定立场、关注点、格式后，输出高质量的要点分析 |
| 写爆款文章 | 写不出爆点 | 告诉它爆款文章的特征（标题技巧、结构、平台要求），就能产出 |
| 写晋升PPT | 写成工作总结 | 告诉它晋升标准、公司偏好，就能呈现符合要求的内容 |

### AI对工作模式的影响

**效能提升数据**：
- 科研领域：熟练使用AI工具的研究员，效能比不擅长的**高2-3倍**
- 研发领域：熟练使用AI工具的工程师，效率是别人的**4-5倍**

**岗位重构预期**：
- 设计团队：从几十人的设计团队 → 一个懂AI的设计师 + 一套海报/素材生成系统
- 软件开发团队：从全职能团队（需求、前端、后端、测试、运维）→ 产品经理 + AI协同高级研发工程师 + 编程智能体 + 自动化运维

> **金句**：能够熟练使用AI工具的人，他的效能就会远超不能使用AI工具的人。

### 从"数字鸿沟"到"智能鸿沟"
数字化时代有"数字鸿沟"——能连接互联网、用信息化系统的先进人群掌握了更多信息、更高效的系统。未来这一鸿沟会迅速转变为"智能鸿沟"——用AI和不用AI的能力差距会越来越大，最终带来收益差距的越来越大。

### 模型的构成——算法 vs 模型

**算法** = 空白的大脑（如拉布拉多的脑子 vs 哈士奇的脑子）
**模型** = 算法 + 训练数据 = 经过学习的脑子

同样的算法（同品种的狗），不同的训练数据（喂养方式不同），产出不同的模型。即便脑子不那么好的哈士奇，只要训练数据足够多，也可能比常年在家的拉布拉多表现更好。

### 模型的学习与优化——类比人类学习

```
人类学习：学 → 练 → 考 → 用
模型训练：数据收集 → 训练 → 评估 → 应用 → 反馈 → 迭代
```

**案例：一个中文系应届生成长为新媒体编辑**
1. **1.0版本**：教科书和经典读物训练出来的，写文章太正经
2. **监督学习**：老板标记"这篇文章不行"→ 模型开始避免类似的写法
3. **正向数据学习**：阅读爆款文章，学习标题技巧（悬念、反差、留白）
4. **评估与迭代**：主管评估 → 实际测试 → 再优化，最终10篇里有7篇达标

### AI大模型应用的架构形态

```
┌─────────────────────────────────────────────────────────┐
│                    场景层（无新场景）                      │
│  营销管理 | 问答 | 审核 | 创意 | 人事服务 | 日程          │
├─────────────────────────────────────────────────────────┤
│                    能力层（新解法）                        │
│  AI能力：文本生成 | 智能搜索 | 音频创作 | 视频创作 | 编程  │
├─────────────────────────────────────────────────────────┤
│                  基础层（AI大模型能力）                     │
│  大语言模型 | 多模态模型 | 向量模型 | 扩散模型             │
└─────────────────────────────────────────────────────────┘
```

核心变化：**场景还是老场景，但解决方案发生了翻天覆地的变化。**
- 编辑工具：从排版、检查错字 → 直接生成内容
- 搜索：从返给网页让人自己归纳 → 直接给出答案
- 编程：从IDE辅助编码 → AI直接编程

### 未来大模型应用的三个发展路径

1. **模型算法和算力提升**：更好的模型、更强的算力、AGI最终会出来
2. **应用场景持续扩展渗透**：覆盖更多行业和领域，积累更多数据
3. **智能融合**：物联网、机器人、自动化的融合，智能掌握更多数据和控制能力
