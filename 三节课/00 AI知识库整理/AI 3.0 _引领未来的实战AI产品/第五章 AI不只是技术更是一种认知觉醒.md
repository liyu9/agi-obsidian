## 二、AI思维方法论

### 1. 彼得·德鲁克名言

> "动荡时代的最大风险，不是动荡本身，而是企图以昨天的逻辑来应对动荡。"

**解读：**
- 不能用10-20年前PC互联网的思维做今天的AI
- 不能用10年前移动互联网的思维做AI投资、创业、产品

### 2. 三大思维方法

#### 思维一：互盘思维

| 步骤 | 说明 |
|------|------|
| 1 | 记录老师/专家的精彩观点 |
| 2 | 思考与自己的认知有何不同 |
| 3 | 在互盘中拉近与专家的距离 |

**目的：** 在互盘过程中提升自己

#### 思维二：结构化思维

```
整体问题
    ↓
分层分类化解
    ↓
逐个解决
    ↓
总结汇报
```

**应用场景：**
- 投资人分配任务时
- 创业合作伙伴安排工作时
- 老板分配工作时

#### 思维三：批判性思维

**案例：** 索马里国家分析

| 表面现象 | 深层思考 |
|---------|---------|
| 平民要么饿死 | 社会经济结构问题 |
| 要么做海盗 | 生存压力下的选择 |
| → 批判性思考 | 理解复杂问题的多维角度 |

**作用：** 获得新的认知维度提升

| 方向 | 内容 |

### 4. 数据态度维度

**核心关系：Data for AI ↔ AI for Data**

```
┌─────────────────────────────────────────────────────────────┐
│                    数据价值链                                │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  传感器/设备采集数据                                         │
│  ├── 手机                                                   │
│  ├── 网页                                                   │
│  ├── 汽车                                                   │
│  ├── 摄像头                                                  │
│  └── 各类IoT设备                                            │
│                                                             │
│  数据类型                                                    │
│  ├── 结构化数据                                             │
│  └── 非结构化数据（大部分）                                  │
│                                                             │
│  数据处理                                                    │
│  ├── 收集                                                   │
│  └── 处理（变成训练级/验证级/测试级）                        │
│                                                             │
│  AI建模                                                    │
│  └── Data for AI（数据为AI服务）                            │
│                                                             │
│  数据变现                                                    │
│  └── AI for Data（AI使数据变现）                            │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 5. 数据采集的重要性

**案例：** 字节跳动用户研究组

- 用户研究组接近几千人
- 不仅是算法设计
- 主要工作：**数据采集**
  - 语音数据
  - 图像数据
  - 视频数据
  - 移动数据
  - 行动数据
  - 基站数据
  - 网页爬虫数据

**核心观点：数据是越多越好，多多益善**

### 6. 数据建模流程

```
数据采集
    ↓
非结构化 → 结构化
    ↓
文本挖掘 + NLP + 机器学习 + 深度学习
    ↓
用户画像 + 物品画像
    ↓
精准推荐/营销
    ↓
数据变现
```

## 四、AI 3.0产品定义

### 1. AI 3.0产品三要素

| 要素 | 说明 |
|------|------|
| 庞大数据 | 大规模训练和推理数据 |
| 强大深度学习算法 | Transformer等先进架构 |
| 强大算力 | GPU集群/云计算 |

### 2. 广义AI 3.0产品

即使不完全具备三要素，只要具备某一典型特征，也可视为广义AI 3.0产品：
- 纯粹大数据产品
- 纯粹算法产品
- 纯粹算力产品
