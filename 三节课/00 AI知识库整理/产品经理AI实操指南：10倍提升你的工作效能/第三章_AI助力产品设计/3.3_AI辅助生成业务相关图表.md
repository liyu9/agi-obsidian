# 3.3 AI辅助生成业务相关图表

> 同学们好，下面我们进入第三节的课程。第三节的任务是借助AI帮我们生成业务相关图表，包括产品的架构图和业务流程图。产品需求文档里对于复杂的业务需求，如果能配有清晰的脑图和流程图，就能让团队成员和利益相关者更直观的去理解需求。

## 一、课程目标

### 1.1 任务目标

- 输出产品的**功能架构图**
- 输出产品的**业务流程图**

### 1.2 核心价值

- 让团队成员更直观的去理解需求
- 快速让他们看懂产品结构和业务流程
- 快速的让他们去进行落地

## 二、功能架构图制作

### 2.1 前提条件

画图的前提是**自己先要理解各个产品功能组成部分之间的关系**，图表工具更多的是帮你做信息的呈现。

### 2.2 软件架构四层结构

产品功能逻辑关系推荐使用软件设计的经典四层结构：

| 层级 | 别名 | 说明 |
|------|------|------|
| 第一层：用户界面层 | 表现层 | 代表用户能看到什么功能，如何从这些功能进行交互 |
| 第二层：应用层 | 业务逻辑层 | 说明应用的操作方法 |
| 第三层：服务层 | 业务逻辑层 | 包含支持应用操作的具体执行规则，有哪些服务和组件 |
| 第四层：数据层 | 持久化层/数据库层 | 存储用户数据、行为数据和系统操作日志 |

### 2.3 让AI帮你设计架构

**提示词模板**：
> 假设你是一名资深的产品总监。现在我需要你帮我画出一个产品的功能架构图。用软件架构设计的四层结构思路去进行设计。应该包含哪些内容。

### 2.4 ChatGPT输出的四层结构

**ChatGPT输出的四层结构**：

| 层级 | 子节点 |
|------|--------|
| **表现层（用户界面层）** | - 主界面（输入源内容）<br>- 摘要展示界面<br>- 文案生成界面<br>- 设置界面<br>- 反馈界面 |
| **业务逻辑层（应用层）** | - 摘要提取功能<br>- 文案生成引擎<br>- 用户管理<br>- 社交媒体集成（分享功能） |
| **持久化层（数据访问层）** | - 数据记录<br>- API接口调用 |
| **数据库层（数据底层）** | - 用户数据<br>- 资讯和文案数据<br>- 用户操作日志数据 |

## 三、思维导图制作

### 3.1 工具一：Chat Mind

**产品介绍**：
ChatMind是国内开发者团队推出的AI思维导图工具，于2023年6月5日被工具类的垂直领域公司XMind收购。

**功能特点**：
- 笔记日程安排
- 项目管理
- 头脑风暴
- 产品框架的输出
- 快速总结和分析
- 持续提供创意灵感

**使用方法**：
1. 在输入框上传文档
2. 写出提示词
3. 按照文档格式生成思维导图
4. 可用对话方式调整格式

### 3.2 工具二：百度文库AI助手

**功能**：同样支持思维导图生成

**使用方法**：
1. 打开百度文库首页
2. 选择"AI生成思维导图"
3. 选择上传文档生成思维导图
4. 点击查看并编辑

### 3.3 思维导图数据准备格式

Word文档格式示例：
```
一、表示层
  1. 主界面
  2. 摘要展示界面
  3. 文案生成界面
  4. 设置界面
  5. 反馈界面

二、业务逻辑层
  1. 摘要提取功能
  2. 文案生成引擎
  3. 用户管理
  4. 社交媒体集成

三、持久化层
  1. 数据记录
  2. API接口调用

四、数据库层
  1. 用户数据
  2. 资讯和文案数据
  3. 用户操作日志数据
```

## 四、业务流程图制作

### 4.1 第一步：梳理业务流程

用文字把想要画的流程图先表达出来。

**案例流程**（资讯助手浏览器插件）：
1. 安装浏览器插件
2. 启动插件
3. 判断登录状态
   - **已登录**：加载历史参数配置
   - **未登录**：使用默认参数配置
4. 访问网页
5. 唤醒插件
6. 点击按钮执行操作
   - **点击总结按钮**：生成摘要内容
   - **点击朋友圈按钮**：生成朋友圈文案

### 4.2 工具一：妙办画板

**产品介绍**：
妙办画板是专业级的办公画图工具，上线了AI功能后，就可以通过自然语言对话的方式来快速的生成想要的流程图了。

**功能特点**：
- 流程图
- 产品流程图
- 思维导图
- 项目管理
- 组织架构图
- 分析模型
- 产品原型图
- 团队实时协作

**使用方法**：
1. 进入妙办画板工作台
2. 点击"新建空白画板"
3. 点击"AI助手"唤醒对话框
4. 输入流程图描述提示词
5. 发送指令生成流程图
6. 可通过拖拽进行微调

### 4.3 工具二：PMAI

**功能**：流程图生成

**优缺点对比**：

| 工具 | 优点 | 缺点 |
|------|------|------|
| 妙办画板 | 支持直接拖拽修改，图形美观 | - |
| PMAI | 一站式生成 | 图形不够美观，修改不便 |

> **建议**：专业的工具做专业的事情，建议用妙办画板借助AI来帮你快速生成流程图。

## 六、核心要点总结

### 6.1 关键工具清单

| 图表类型 | 推荐工具 | 核心特点 |
|---------|---------|---------|
| 思维导图 | ChatMind | AI驱动，可上传文档生成 |
| 思维导图 | 百度文库 | 集成在文档工具中 |
| 流程图 | 妙办画板 | 专业画图+AI，支持拖拽修改 |
| 流程图 | PMAI | 可与PRD生成一站式完成 |

### 6.2 成功关键点

1. **思路清晰是前提**：图画的好不好取决于你的思路是不是清晰
2. **重点在于业务逻辑**：重点还在于梳理你的业务逻辑
3. **人机协作**：借助工具来辅助灵感输出，二者结合才能发挥最大的价值

> "流程图和脑图的绘制工具再叠加AI能力就可以极大的降低我们生成图像的操作难度。"
