# 4.3 AI辅助构建项目知识库

> 同学们，第三节的课程我会教你如何利用AI技术来辅助构建项目知识库，从而提高知识管理效率。

## 一、课程目标

### AI在知识库构建中的核心能力

- **支持文档构建**：把项目的相关文档、数据和经验构建成系统化和易于检索的知识库
- **对话式获取信息**：可以直接通过对话的方式获取想要的信息
- **快速问题定位**：帮助团队成员快速定位问题，避免每次都去找产品经理

### 任务目标

**核心目标**：把之前立项时写的各种文档都交给AI，让AI学习这些私有数据，定制一个专属于自己、专属于这个项目的对话大模型产品

**最终效果**：让AI成为"数字项目助理"，项目有关的所有问题都可以让它给出答案

## 二、工具推荐

### 推荐的两款工具

#### 工具一：GPTs（ChatGPT的定制版本）

**定义**：
GPTs可以理解成是ChatGPT的定制版本，允许你根据自己的需求和偏好构建适用于特定用途或业务场景的定制化模型。

**应用场景**：
- 自动化客服
- 生成专业的内容
- 各种细分领域的商业场景
- 解决企业的具体问题

#### 工具二：ChatFast（国内平替产品）

**定义**：
ChatFast是由百姓网旗下的百姓AI研发的一款企业级AI知识服务和内容生产工具。

**功能**：
- 可通过角色设定和训练素材生成定制版的助理机器人
- 支持发布到各类终端，给企业和团队提供知识服务
- 被认为是GPTs的国内平替产品
- 支持基于企业知识库训练自建模型，打造企业专属的AI数字助理

### 工具选择建议

> **如果你用不了GPTs，ChatFast也是个很好的选择。**

## 三、GPTs知识库配置

### 创建方法

有两种创建方法：

| 方法 | 说明 | 推荐度 |
|------|------|--------|
| 对话方式 | 一步一步让GPT帮你完成创建 | ⭐⭐ |
| 填写关键信息 | 自己填写name、description、instructions等 | ⭐⭐⭐⭐⭐ |

**推荐**：第二种方法，确定性更高，你知道在哪个环节填写哪类信息

### 配置参数

| 参数 | 说明 |
|------|------|
| Name | GPTs的名字 |
| Description | GPTs的描述（给用户看的介绍） |
| Instructions | 提示词（核心指令） |
| Conversation Starters | 对话示例（引导语） |
| Knowledge | **最关键**：上传项目资料作为知识库 |

### 配置示例

#### 1. Name配置

**示例**：`资讯助手项目助理`

你可以把它当成一个助理去向他提问，让它给你回复有关项目的所有相关信息。

#### 2. Description配置

**示例**：`资讯助手项目助理`——它的目的是根据资讯助手的项目资料来回答项目问题，总结项目信息。

#### 3. Instructions配置

**提示词示例**：

```
你需要让它解析所有上传的项目文档里的信息，同时根据所有提交文档里的内容，为我们的项目组成员解答涉及到该项目的问题。所有的回答都要从文档里面去收集给出答案，并且用第一人称视角去表达，把自己当做项目的项目经理来回答。如果没有办法找到答案，那就让它如实的说出来，不要自己去编。
```

#### 4. Conversation Starters配置

**作用**：当新用户首次打开这个GPTs时，可以给他展示一些默认的问题，引导用户提问。

**示例问题**：
- 这个项目是什么？
- 为什么要做这个项目？
- 时间排期计划是什么？
- 咱们的目标是什么？

可以设定多个（默认四个即可）

#### 5. Knowledge配置（最关键）

**上传内容**：
- 之前生成的详细的产品需求文档（PRD）
- 之前生成的项目的计划草案

**效果**：让GPTs学习这些私有数据，从而能够回答项目相关问题

### 高级功能配置

| 功能 | 说明 | 建议 |
|------|------|------|
| Web Browsing | 网页浏览（当无法回答时上网找资料） | 企业私有用不建议开启 |
| DALL·E | 图像生成 | 可选 |
| Code Interpreter | 代码解释器 | 企业私有用不需要 |

**不建议开启Web Browsing的原因**：
- 更多的是企业私有用
- 不希望它在上网找资料来"污染"给出的信息
- 毕竟是作为私有数据，还是相对保守一点

### 应用图标设置

**作用**：每个GPTs就是一个独立应用，应用得有图标

**设置方式**：
- 选择上传照片作为图标
- 或使用图像生成工具让AI帮你生成

**图标生成**：会根据你的所有提示词和输入的资料去理解，生成匹配的logo图

### 测试预览

**预览功能**：
- 右侧会实时展示GPTs的信息
- 可以一边完成参数设置，一边直接测试效果
- 如果有偏差就继续修改左侧的参数，直到达成预期

**测试示例**：

**问题1**：`这个项目是什么？要做什么样的产品？`

**AI回答**：
```
这个产品目的是什么，它可以用什么样的一个功能，面向的用户，产品的愿景目标，产品开发接大于先进的自然语言处理技术。是这个项目是什么，要做一款什么样的产品。
```

**问题2**：`项目目标是什么？`

**AI回答**：
```
目标如下（非常清楚的去读取了我上传的资料里边的信息，并且可以去呈现出来）
```

### 发布设置

**发布选项**：

| 选项 | 说明 |
|------|------|
| 公开 | 在GPTs商店里可以搜到 |
| 私有-仅自己 | 只有自己可以用 |
| 私有-链接 | 拥有链接的人可以用（推荐） |

**操作**：选择"只有拥有链接的人"，然后点击确认

**效果**：可以把生成的链接发给团队成员，让他访问这个资讯助手，并且跟他直接进行对话，来回答项目的问题

## 四、ChatFast知识库配置

### 配置界面

ChatFast的配置页面会更丰富一些，核心参数和GPTs类似。

**核心配置项**：

| 配置项 | 说明 |
|--------|------|
| 基础信息 | 名称、描述等 |
| 知识库上传 | 文档上传 |
| 角色简介 | 设定AI的角色身份 |
| 默认欢迎语 | 首次访问时的引导语 |

**特点**：左侧完成配置后，右侧会实时展示测试界面，可以直接在里面完成功能测试

### ChatFast简介

**官网定位**：
- 可以基于AI帮你轻松定制问答机器人
- 或者企业专属的机器人
- 你只用上传学习素材和提示词，便可以获得独特的超强能力的专属物理机器人

**应用场景**：

| 场景 | 说明 |
|------|------|
| 智能客服 | 自动化回答用户问题 |
| 创投经理 | 专业领域咨询 |
| 微信群聊咨询师 | 社群管理 |
| 公众号分身 | 内容运营 |
| VP顾问 | 高管助理 |
| 英语外教 | 教育培训 |

**实现原理**：

```
知识库资料 → 传输给大模型 → 大模型优化训练 → 输出智能问答机器人
```

**功能优势**：
- 上传文档
- 角色设定
- 多终端发布
- 提供各项解决方案

### ChatFast配置流程

#### 第一步：进入工作台

点击右上角进入工作台，直接点击"创建机器人"

#### 第二步：选择类型

**可选类型**：
- 内部知识库（推荐）
- 快速定制
- 其他类型

**选择**：内部知识库

#### 第三步：角色设定

**角色定义**：
- 角色名称：咨询助手
- 身份：内部知识库以数字助理身份存在
- 能力：解析上传的文档信息

**提示词示例**：
```
解析上传的项目文档信息，作为资讯助手的数字助理身份存在。
```

**说话风格**：
- 简洁明了
- 注重事实和逻辑
- 以提供准确的信息为主

#### 第四步：询问策略

**默认设置**：
- 回答用户问题后进一步引导以满足用户需求
- 作为资讯助手的数字助理，表达身份
- 以知识库中的资料为基准，准确回答问题

#### 第五步：录入文档

**上传文件**：
- 资讯助手项目计划
- 资讯助手产品需求文档

**功能**：
- 文档学习和解析
- 可以录入现成的Q&A
- 支持输入文本、抓取网页、刷取公众号等

### ChatFast高级设置

**可配置项**：

| 设置项 | 说明 |
|--------|------|
| 模型和文档段落索引 | 精确配置 |
| 回复长度 | 控制回答详细程度 |
| 上下文 | 管理对话上下文 |
| 相关性 | 文档相关性配置 |

**相关性设置**：
- 如果觉得AI回答有点"自作主张"时
- 可以强制要求完全按照文档的信息来回复
- 还可以配置回复的多样性，是否要让它有一些自己的展开

### ChatFast发布与管理

**发布设置**：
- 配置页面展示
- 配置机器人名称、头像、角色简介
- 文档来源
- 是否要有修正
- 添加菜单栏等

**知识库管理**：
- 可以直接录入文本
- 抓取网页内容
- 刷取公众号内容

**第三方发布**：
- 可以发布到各个第三方平台
- 可以查看提交给同事的使用数据

**分享方式**：直接分享给好友或团队成员使用

## 五、知识库迭代优化

### AI回复缺失时的处理

**场景**：AI给你的回复有缺失，需要补充更多信息

**AI反馈示例**：
```
可能需要参考项目计划表或者是项目管理工具中的详细安排。提供更多信息，以便于我能够提供更准确的回答。
```

**处理方式**：
1. 根据AI的要求重新上传新的资料到知识库
2. 让AI有进一步的资料去学习完善回答内容
3. 这样循环往复，逐渐让知识库的助理变得足够强大

### 知识库演进路径

```
初始构建 → 发现不足 → 补充资料 → 再次训练 → 持续优化 → 强大助理
```

**核心理念**：知识库是不断迭代完善的，不是一次性到位的

## 六、课程总结

### 核心知识点

**借助GPTs和ChatFast构建私有知识库的过程**：

1. **选择合适的工具**（GPTs或ChatFast）
2. **配置知识库参数**（角色、提示词、知识库等）
3. **上传项目文档**（产品需求文档、项目计划等）
4. **测试和调整**（确保回答符合预期）
5. **发布给团队**（设置访问权限）
6. **持续迭代优化**（根据使用反馈补充资料）

### AI赋能价值

**最终效果**：
- 实现让AI帮我们回答项目组成员的问题
- 为项目的成功开发和团队协作提供有力的支持
- 构建一个高效智能的私有知识库

> **有了这样的定制机器人，我们就可以实现让AI帮我们回答项目组成员的问题，为项目的成功开发和团队协作提供有力的支持。**
