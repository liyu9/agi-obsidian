# 第二章 洞察力篇

## 第一节 行业研究

### 一、为什么要做行业研究

#### 1.1 核心观点：时事造英雄

**案例分析：K12行业与柯达胶卷**

**K12行业案例**：
- 2021年前K12是在线教育最火热的赛道
- 双减政策出台后，行业基本被淘汰
- 即使是最优秀的产品经理也无法在衰退行业中做出英雄级产品

**柯达胶卷案例**：
- 巅峰时期占据全球市场2/3份额
- 发明了世界上第一台数码相机
- 因管理层对数字化趋势认知不足，错失转型机遇
- 最终被佳能、索尼、尼康等品牌超越

**关键结论**：
> 选择比努力更重要。打败一个公司的常常不是竞争对手，而是时代改变了。

#### 1.2 行业研究对职场人的价值

| 价值维度 | 具体收益 |
|----------|----------|
| **职业发展** | 预见职业发展机会，了解行业天花板 |
| **工作能力** | 提供战略视角，更好理解自身工作 |
| **面试成功** | 快速了解目标行业，提升offer概率 |

**面试技巧**：
> 面试心仪公司前，做一份行业分析报告，面试时直接展示，体现专业度和诚意。

### 二、行业研究五步法

```
┌────────────────────────────────────┐
│         行业研究五步法              │
├────────────────────────────────────┤
│  1. 确定目的                        │
│     明确分析目标和预期结果            │
├────────────────────────────────────┤
│  2. 资料收集                        │
│     一手/二手信息采集                │
├────────────────────────────────────┤
│  3. 结构化分析                      │
│     多维度深入分析                   │
├────────────────────────────────────┤
│  4. 内容呈现                        │
│     PPT制作与汇报                    │
├────────────────────────────────────┤
│  5. 分析复盘                        │
│     回顾总结，形成方法论              │
└────────────────────────────────────┘
```

#### 2.1 第一步：确定目的

**核心原则**：在所有事情做之前，先把目的定出来

**常见目的**：
- 分析某行业发展趋势，制定产品发展方向
- 评估市场机会，辅助投资决策
- 了解竞争对手，制定竞争策略

#### 2.2 第二步：资料收集

**信息类型对比**：

| 类型 | 来源 | 特点 | 适用场景 |
|------|------|------|----------|
| **一手信息** | 实地调研、专家访谈 | 实时性强，成本高 | 深度研究 |
| **二手信息** | 第三方报告、年报、媒体 | 获取便捷，足够使用 | 日常分析 |

**常用信息渠道**：

| 渠道类型 | 代表平台 |
|----------|----------|
| 咨询机构 | 艾瑞、36氪研究院 |
| 企业年报 | 上市公司财报 |
| 官方统计 | 国家统计局、行业白皮书 |
| 研究中心 | BAT研究院 |
| 媒体平台 | 36氪、虎嗅 |

**AI搜索工具推荐**：

| 工具 | 类型 | 特点 |
|------|------|------|
| **Perplexity** | 海外AI搜索 | 对话式搜索，月活近千万 |
| **秘塔AI搜索** | 国内AI搜索 | 无广告，精准匹配 |

**工具对比**：

| 维度 | Perplexity | 秘塔AI搜索 |
|------|-------------|-------------|
| 语言 | 英文为主 | 中文优化 |
| 体验 | 专业搜索模式 | 步骤展示清晰 |
| 附加功能 | 基础报告 | 可直接生成PPT大纲 |

#### 2.3 第三步：结构化分析

**PEST分析框架**：

| 维度 | 内容 |
|------|------|
| **P** Political | 产业政策、法规 |
| **E** Economic | 经济周期、趋势 |
| **S** Social | 社会文化变化 |
| **T** Technological | 技术发展 |

**行业分析五维度**：

| 维度 | 核心问题 |
|------|----------|
| 市场规模与趋势 | 市场空间有多大？增长趋势如何？ |
| 行业阶段 | 处于哪个发展阶段？ |
| 行业价值链 | 上下游有哪些玩家？如何分润？ |
| 竞争格局 | 主要竞争者是谁？市场份额如何？ |
| 波特五力 | 新进入者、替代品、供应商、客户、现有竞争 |

**行业生命周期阶段**：

```
技术萌芽期 → 摸索成长期 → 上升红利期 → 应用爆发期 → 增长泡沫期 → 成熟工具期
    ↑                                                              ↓
 量子技术                                                    AI技术
```

#### 2.4 第四步：内容呈现

**产品经理PPT制作原则**：

| 原则 | 说明 |
|------|------|
| 字不如表 | 能用表格就不用大段文字 |
| 表不如图 | 核心数据用图表可视化 |
| 数据有出处 | 所有数据标注来源 |
| 每页有结论 | 每页要有明确的论点 |
| 总分总结构 | 先总结，再展开，再总结 |

#### 2.5 第五步：分析复盘

**复盘三问**：

1. **继续做什么**：哪些有效的方法需要保持？
2. **开始做什么**：发现的新机会点？
3. **停止做什么**：哪些无效做法需要摒弃？

### 三、AI辅助行业研究

#### 3.1 资料收集阶段

**使用场景**：批量研报分析

**使用场景**：生成分析大纲

**工具**：秘塔AI搜索（可直接生成PPT大纲）

**输出效果**：
- 发展趋势
- 现状分析
- 核心要素
- 应用场景
- 未来展望与挑战

### 四、本节要点总结

#### 核心框架

```
行业研究五步法
├── 1. 确定目的 → 明确分析目标
├── 2. 资料收集 → AI搜索 + 研报分析
```

## 第二节 市场研究

### 一、行业与市场的区别

#### 1.1 核心定义

| 概念 | 定义 | 关注点 |
|------|------|--------|
| **行业** | 生产相同或相似产品/服务的公司集合 | 公司和产品 |
| **市场** | 消费者及其需求构成 | 买方和需求 |

**经典案例：10元咖啡事件**

| 维度 | 具体内容 |
|------|----------|
| 涉及的行业 | 食品饮料行业、零售行业、品牌营销 |
| 涉及的市场 | 饮料市场、零售市场 |

#### 1.2 行业研究vs市场研究

| 对比维度 | 市场研究 | 行业研究 |
|----------|----------|----------|
| **焦点** | 消费者行为、需求偏好、购买习惯 | 行业架构、竞争格局、发展趋势 |
| **目的** | 识别目标市场，评估需求量 | 分析行业健康状况，预测发展趋势 |
| **视角** | 微观 | 宏观 |
| **应用** | 产品开发、运营营销策略 | 战略决策、业务发展方向 |

**关键认知**：
> 一个行业可能包括多个市场，一个市场也可能涉及多个行业。

### 二、为什么要做市场研究

#### 2.1 产品决策的两条路径

| 路径 | 描述 | 结果 |
|------|------|------|
| 路径一 | "我们有这个技术，所以做个产品" | 技术导向，容易脱离市场 |
| 路径二 | "市场有这个需求，我们有能力满足" | 市场导向，更容易成功 |

#### 2.2 核心观点

> **对于绝大多数人或者公司来说，市场是产品的关键，而技术不是。**

**反面案例**：
> 不做市场调研做产品，就像开饭店不问客人吃什么菜就直接上菜。

### 三、AI辅助市场研究流程

#### 3.1 整体流程框架

```
┌────────────────────────────────────┐
│        市场研究六步法               │
├────────────────────────────────────┤
│  1. 定义问题                        │
│     明确调研核心问题                 │
├────────────────────────────────────┤
│  2. 准备实施                        │
│     制定调研计划                     │
├────────────────────────────────────┤
│  3. 执行调研                        │
│     问卷发放与数据收集               │
├────────────────────────────────────┤
│  4. 数据分析                        │
│     AI辅助数据分析                  │
├────────────────────────────────────┤
│  5. 分析决策                        │
│     得出结论，指导行动               │
├────────────────────────────────────┤
│  6. 回顾复盘                        │
│     总结经验，形成方法论             │
└────────────────────────────────────┘
```

#### 3.2 第一步：定义问题

**案例背景**：新能源汽车价格敏感度调研

**核心问题**：
> 在当前市场价格竞争加剧的背景下，消费者在选择新能源汽车时，价格因素的重要性有多大？

#### 3.3 第二步：准备实施 - 5W2H方法

| 要素 | 问题 |
|------|------|
| **What** | 需要解决什么问题/任务是什么？ |
| **Why** | 为什么要解决这个问题？ |
| **Who** | 谁来负责？涉及哪些人？ |
| **When** | 什么时候？时间限制？ |
| **Where** | 在哪里？地点/环境？ |
| **How** | 如何执行？ |
| **How much** | 需要多少成本/资源？ |

**AI辅助提示词**：
```
【背景】
你是一名专业的产品经理，正在做一份市场调研计划。

【任务】
计划核心：在当前市场竞争加剧的背景下，
消费者在选择新能源汽车时，价格因素的重要性有多大？

【输出】
请根据5W2H分析法帮我拆解本次调研计划，
产出一份调研计划大纲。

【风格】资深产品经理
【语气】专业
【受众】市场调研团队
```

#### 3.4 第三步：问卷设计

**问卷设计原则**：

| 原则 | 说明 | 反面案例 |
|------|------|----------|
| 避免诱导 | 描述中立，不误导用户 | 直接问"是否体验过小米SU7" |
| 通俗易懂 | 避免专业术语 | 用"智能驾驶"而非"ADAS" |
| 避免复杂句式 | 不用双重否定、长难句 | "您赞不赞成不允许自带酒水的规定" |
| 提供拒绝选项 | 给用户出口 | 不喜欢新能源车的选项 |
| 选项量化 | 使用李克特量表 | 用"1-5分"而非"不满意到满意" |
| 避免敏感问题 | 不涉及隐私 | 不直接问收入、犯罪记录 |
| 避免含糊表述 | 具体量化 | 用"每周几次"而非"偶尔" |
| 避免双重问题 | 一个问题问一件事 | 分开问价格和品质 |
| 数量适宜 | 控制在10分钟内 | 精简问题数量 |
| 顺序合理 | 先易后难 | 先问能接受的，再问敏感的 |

**问卷问题类型**：

| 类型 | 特点 | 适用场景 |
|------|------|----------|
| 开放式 | 用户自由回答 | 收集详细观点 |
| 封闭式 | 选择固定选项 | 量化分析 |
| 混合式 | 选+自填 | 灵活收集 |

**李克特量表示例**：

```
您对新能源汽车价格的态度是：
□ 非常不认可 □ 不认可 □ 一般 □ 认可 □ 非常认可
```

**AI辅助提示词**：
```
【背景】
你是一名专业的产品经理，正在设计一份新能源汽车价格敏感度的调研问卷。

【要求】
1. 遵循问卷设计原则
2. 问题至少15道
3. 使用李克特量表
4. 提供拒绝选项

【受众】接受问卷调研的C端用户
```

#### 3.5 第四步：数据收集与分析

**样本选择原则**：
> 需要让被访问者的样本具有代表性

**AI模拟数据生成**：
```
【提示词】
请你扮演100个不同年龄、不同职业的目标用户，
填写这次调研问卷，并将填写结果生成Excel文档。
尽量填写更真实的情况。
```

**AI数据分析**：
```
【提示词】
请帮我分析Excel中的数据，得出相应结论。
```

## 第三节 用户研究

### 一、用户研究的核心价值

#### 1.1 什么是用户研究

**定义**：在产品发展全生命周期里，根据不同阶段研究不同用户群体的行为特点与底层机制，给出专业的洞见与可行的建议。

**核心价值**：
- 洞察用户需求
- 挖掘产品痛点
- 指引产品方向
- 提升产品价值

#### 1.2 用户研究思考框架

| 思考维度 | 具体问题 |
|----------|----------|
| 目标用户 | 用户是谁？ |
| 生活状态 | 用户的生活状态如何？ |
| 使用场景 | 产品的使用场景是什么？ |
| 价值需求 | 在这种场景下，用户想满足什么价值？ |
| 恐惧点 | 用户的担忧是什么？ |
| 现有选择 | 用户目前的替代方案是什么？为什么？ |
| 感知评价 | 用户对本品和竞品的感知如何？ |
| 使用习惯 | 用户习惯的使用流程和认知偏好是什么？ |

#### 1.3 产品阶段与用户研究

| 产品阶段 | 研究重点 | 常用方法 |
|----------|----------|----------|
| **0（概念期）** | 理解基本需求和行为模式 | 行业分析、竞品分析、用户画像、场景分析 |
| **0.5（验证期）** | 理解用户偏好（态度、认知、情感） | 认知走查、问卷调研、用户访谈、可用性测试 |
| **1（成长期）** | 了解用户体验、行为与认知需求 | 体验度调研、NPS调查、行为数据分析 |

### 二、AI辅助用户画像

#### 2.1 用户画像的价值

**定义**：通过集合真实用户典型需求与特征的虚拟角色，帮助团队理解用户的真实需求与使用场景。

**核心作用**：
- 始终围绕典型用户的核心诉求进行设计开发
- 增进团队对用户需求的理解与共情
- 建立统一的用户期望和认知
- 作为设计决策的基准

#### 2.2 用户画像搭建三步法

```
┌────────────────────────────────────┐
│      用户画像搭建三步法              │
├────────────────────────────────────┤
│  1. 描                              │
│     明确目标，选定群体               │
├────────────────────────────────────┤
│  2. 聊                              │
│     招募并访谈目标用户               │
├────────────────────────────────────┤
│  3. 抽象                            │
│     模式识别，建立用户画像           │
└────────────────────────────────────┘
```

**第一步：描**

| 要素 | 内容 |
|------|------|
| 画像目标 | 预期价值、关注的用户行为 |
| 目标人群 | 通过行业分析、竞品分析、数据分析或外部招募 |

**第二步：聊**

| 访谈环节 | 内容 |
|----------|------|
| 暖场 | 让用户放松，回答更真实 |
| 基本生活 | 理解用户背景和生活方式 |
| 产品接触历程 | 使用动机、初期期望、初步反馈 |
| 使用场景 | 频率、环境、设备 |
| 体验与评价 | 真实反馈，发现改进机会 |
| 意见建议 | 指导产品优化方向 |

**第三步：抽象**

| 子步骤 | 说明 |
|--------|------|
| **人群聚类** | 分析用户数据，识别共性和差异（如年轻用户偏好晚上使用，年长用户偏好早晨） |
| **找到目标人群** | 选取典型用户样本，构建详细用户故事 |
| **检查客观性** | 确认画像是否得到团队共识，是否基于普遍现象，是否能帮助改进产品 |

#### 2.3 AI辅助用户画像实操

**AI辅助访谈提纲生成**：
```
【提示词】
你是一名B站的资深产品经理，正在做关于吃播类标签的用户画像。

【预期价值】
结合真实用户数据与标签画像，定性解释数据表现，定位后期产品优化方向。

【最关注的用户行为】
看吃播时都是在什么场景下看的。

【访谈提纲】
请根据以上信息，帮我生成一份B站吃播用户画像的访谈脚本。

【风格】资深产品经理
【受众】用户访谈主持人
```

**AI模拟用户访谈**：
```
【提示词】
请你扮演30个不同年龄、不同职业的目标用户接受本次访谈。
将访谈结果生成Excel文档供下载使用。

```

**AI抽象用户画像**：

```
【提示词】
根据30份访谈脚本，按照抽象原则（人群聚类、目标人群、客观性检查），

【要求】
包含：姓名、年龄、职业、婚姻状态、爱好、使用特征、群体规模、
核心需求、关键行为、对标竞品、人物素描等。
```

### 三、AI辅助定量体验评估法

#### 3.1 什么是定量体验评估法

**定义**：使用数据和统计工具来衡量产品、功能或策略性能的方法。

**核心价值**：
- 收集真实用户的体验感知评价
- 量化反映产品体验水平
- 帮助产品提升体验与决策竞争力

**优点**：
- 调研取样范围广
- 降低调研者偏差
- 可定期对比
- 多维度交叉分析

**缺点**：
- 问卷编写有专业性要求（可用AI解决）
- 目标群体对结果影响大

#### 3.2 满意度调查

**李克特5级量表**：
```
非常不满意 → 不满意 → 一般 → 满意 → 非常满意
```

**满意度公式**：
```
满意度 = (非常满意 + 满意) / 样本量 × 100%
```

**设计要点**：
- 筛选使用过产品的用户
- 解释专业名词
- 提供"不清楚"选项
- 可设计多级满意度指标体系

**AI辅助提示词**：
```
【背景】
你是一名电商平台的产品经理，正在对用户下单的黄金流程
通过定量体验评估法做满意度调查。

【要求】
使用满意度调查表格，包含以下页面：
- 打开APP进入
- 搜索内容
- 产品详情页
- 购物车
- 结算页
- 支付页面

【受众】电商平台C端用户
```

#### 3.3 NPS净推荐值调查

**定义**：衡量客户忠诚度和总体满意度的工具（弗雷德·赖克·赫尔德提出）

**打分规则**：
```
0 ─────────────────────────────── 10
不推荐                      强烈推荐

推荐者：9-10分
中立者：7-8分
贬损者：0-6分
```

**计算公式**：
```
NPS = (推荐者数 / 样本数) × 100% - (贬损者数 / 样本数) × 100%
```

**解读标准**：

| NPS值 | 含义 |
|--------|------|
| 50+ | 优秀 |
| 30-50 | 良好 |
| 0-30 | 一般 |
| <0 | 需要改进 |

**AI辅助NPS分析**：
```
【提示词】
请计算这份数据的NPS值。
```

### 四、本节要点总结

#### 核心框架

```
用户研究体系
├── 核心价值：洞察需求、挖掘痛点、指引方向
├── 用户画像三步法：描 → 聊 → 抽象
└── 定量体验评估法：满意度 + NPS
```

#### 关键工具

| 场景 | AI辅助方法 |
|------|------------|
| 访谈提纲 | COSTAR框架生成 |
| 数据模拟 | 大模型扮演用户 |
| 画像抽象 | 结构化分析输出 |
| 满意度调研 | 表格生成+数据分析 |
| NPS计算 | 自动计算+建议输出 |

#### 关键认知

> **用户画像帮助团队始终围绕典型用户的核心诉求进行设计开发。**

## 第四节 竞品分析

### 一、竞品分析的核心价值

#### 1.1 竞品分析的场景

**类比思考**：开餐厅前考虑
- 应该是什么定位？卖什么菜？
- 吸引什么客人？与别家有什么差别？
- 客流大的餐厅为什么做得好？
- 快倒闭的餐厅为什么没有客源？

#### 1.2 竞品分析的价值

| 价值维度 | 具体体现 |
|----------|----------|
| 洞察用户需求 | 把握市场趋势，确定产品方向 |
| 制定产品策略 | 提升竞争力，寻找差异化优势 |
| 优化产品体验 | 避免同质化，提升用户满意度 |
| 提升个人能力 | 专业技能提升 |

#### 1.3 竞品分析经典案例

**案例一：海外即时配送业务**

**背景**：
- 类似美团外卖/饿了么
- 在澳大利亚做本地即时配送
- 面临合规性、盈利模式、市场定位等不确定性

**通过竞品分析（MenuLog）获得**：
1. 市场需求和竞争态势
2. 合规性与劳工标准处理方式
3. 商家和骑手的需求洞察

**成果**：快速跑通MVP，从0到1

**案例二：短视频行业发展**

**用户需求洞察**：
- 内容多样化需求（搞笑、美食、旅行、知识等）
- 互动需求（点赞、评论、分享）

**市场趋势把握**：
- 移动互联网发展
- 短视频特点：快速、直观、易消费
- 改变用户内容消费习惯

**案例三：小米汽车定价策略**

**竞品分析**：
- 分析市场各价位竞争格局
- 发现用户对车机性能和人机交互的重视
- 价格敏感性

**策略**：
- 21.59万-29.99万定价
- 覆盖中等收入群体
- 延续高性价比品牌调性
- 悬念营销吸引关注

**案例四：拼多多差异化竞争**

**背景**：淘宝京东主导一线城市，竞争激烈

**差异化打法**：

| 策略 | 说明 |
|------|------|
| 社交电商 | 拼团模式，降低C端和B端成本 |
| 农产品直供 | 从农田到消费者，新鲜优惠 |
| 价格优势 | 优化供应链，提高性价比 |

**案例五：B站登录交互设计**

**设计细节**：登录注册输入密码时，漫画人物捂住眼睛

**设计原理**：心理暗示作用，让用户感觉隐私被保护，产生安全感

### 二、竞品分析专业方法

#### 2.1 波特五力分析

| 五力 | 核心问题 |
|------|----------|
| **同业竞争强度** | 现有企业之间竞争有多激烈？ |
| **潜在进入者威胁** | 新进入者会带来多大压力？进入壁垒是什么？ |
| **替代品威胁** | 其他产品/服务替代的可能性多大？ |
| **供应商议价能力** | 供应商能对企业施加多大影响？ |
| **客户议价能力** | 客户能对企业施加多大影响？ |

**AI辅助提示词**：
```
【背景】
你是一名在澳大利亚做本地即时配送业务的产品经理。

【任务】
请根据波特五力分析法，分析当前市场的竞争策略。
分析目标竞品包括Uber Eats、MenuLog等。

【受众】投资人（验证业务可行性）
```

#### 2.2 SWOT分析

| 维度 | 说明 |
|------|------|
| **S** Strengths | 内部优势 |
| **W** Weaknesses | 内部劣势 |
| **O** Opportunities | 外部机会 |
| **T** Threats | 外部威胁 |

#### 2.3 波特竞争三要素

| 策略 | 说明 |
|------|------|
| 总成本领先 | 通过规模效应降低成本 |
| 高度差异化 | 提供独特价值 |
| 专门聚焦 | 专注细分市场 |

#### 2.4 竞品分析四象限

```
           服务相同
              ↑
              │
    潜在竞争  │  高度竞争
              │
用户相同 ─────┼─────── 用户不同
              │
    不构成竞争│  存在竞争
              │
              ↓
           服务不同
```

**小米SU7竞品定位**：
- 服务相同：Model 3、极氪007等智能电车
- 服务不同：传统油车（宝马、法拉利）

#### 2.5 九维分析法

| 维度 | 内容 |
|------|------|
| 市场趋势 | 行业发展方向 |
| 业内现状 | 当前市场状况 |
| 企业愿景 | 战略目标 |
| 产品定位 | 市场定位 |
| 发展战略 | 长期规划 |
| 目标用户 | 用户群体 |
| 市场数据 | 份额、增长等 |
| 核心功能 | 主要功能 |
| 交互设计 | 用户体验 |
| 产品优缺点 | 优势劣势 |
| 运营推广策略 | 营销方式 |

**AI辅助提示词**：
```
【背景】
你是一名在澳大利亚做本地即时配送业务的产品经理，
正在使用九维分析法做竞品分析。

【任务】
以MenuLog、Uber Eats等为研究目标，
使用九维分析法进行分析。
需要联网搜索最新信息。

【输出格式】
表格形式
```

#### 2.6 五层分析法

| 层级 | 关注内容 | 适用分析 |
|------|----------|----------|
| **战略层** | 企业愿景、产品定位 | 发展方向 |
| **范围层** | 功能范围、业务流程 | 做什么 |
| **结构层** | 信息架构、功能架构 | 怎么组织 |
| **框架层** | 交互设计、页面跳转 | 怎么操作 |
| **表现层** | 视觉设计、布局排版 | 看起来怎样 |

**注意**：五层法中框架层和表现层需要亲身体验产品，AI暂时无法替代。

### 三、实战案例：海外即时配送竞品分析

#### 3.1 分析流程

```
1. 波特五力分析 → 确定竞争策略
2. SWOT分析 → 了解自身优劣势
3. 波特三要素 → 确定竞争方向
4. 竞品四象限 → 找到目标竞品
5. 九维/五层分析 → 深度研究
```

#### 3.2 AI辅助要点

| 分析维度 | AI辅助效果 | 局限性 |
|----------|------------|--------|
| 波特五力 | 快速给出策略建议 | 需结合实际调整 |
| SWOT | 分析优劣势机会威胁 | 需人工验证 |
| 九维分析 | 高效获取结构化信息 | 需深度验证 |
| 五层分析 | 战略层、范围层有效 | 交互层需人工体验 |
