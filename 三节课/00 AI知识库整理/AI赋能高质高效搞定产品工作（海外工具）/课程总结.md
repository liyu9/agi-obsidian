# 课程总结：AI赋能高质高效搞定产品工作

## 课程概述

### 课程背景

本课程由张文静主讲，作者是某上市公司数字化业务产品负责人，同时在做海外本地生活创业项目。2024年初被评为人人都是产品经理平台年度专栏优秀作家。课程核心目标是帮助产品经理掌握AI工具，提升工作效率和综合能力。

## 核心概念体系

### 一、产品经理三大核心能力

| 能力 | 定义 | 核心价值 |
|------|------|----------|
| **洞察力** | 分析商业和客户，找到机会点 | 把握市场方向 |
| **产品力** | 把方案呈现出来的能力 | 输出完整PRD |
| **结果力** | 推进产品达到或超过预期 | 以终为始拿结果 |

### 二、提示词框架体系

#### 基础框架：Somebody to do Something

| 要素 | 说明 | 示例 |
|------|------|------|
| Somebody | 角色设定 | "你是资深产品经理" |
| to do | 任务目标 | "请写需求文档" |
| Something | 场景描述 | "正在开发电商拼团功能" |

#### 进阶框架：COSTAR

| 要素 | 说明 | 示例 |
|------|------|------|
| **C** Context | 背景信息 | 业务背景、团队情况 |
| **O** Objective | 任务目标 | 具体要完成什么 |
| **S** Style | 写作风格 | 资深产品经理风格 |
| **T** Tone | 语气 | 专业、正式 |
| **A** Audience | 受众 | 开发团队 |
| **R** Response | 响应格式 | PRD格式、表格形式 |

### 第二章：洞察力篇

#### 核心方法论

| 研究类型 | 核心方法 | AI辅助工具 |
|----------|----------|------------|
| 行业研究 | 五步法 | Perplexity、秘塔AI搜索、Kimi |
| 市场研究 | 5W2H+问卷设计 | 大模型辅助分析 |
| 用户研究 | 用户画像+定量评估 | 访谈提纲生成、数据模拟 |
| 竞品分析 | 波特五力+SWOT+九维/五层 | 结构化分析 |

#### 核心框架

**行业研究五步法**：
```
确定目的 → 资料收集 → 结构化分析 → 内容呈现 → 分析复盘
```

**用户画像三步法**：
```
描（明确目标） → 聊（访谈用户） → 抽象（建立画像）
```

**竞品分析体系**：
```
波特五力 → SWOT分析 → 波特三要素 → 竞品四象限 → 九维/五层分析
```

#### 核心观点

> **时事造英雄，选择比努力重要。**

> **市场是产品的关键，技术不是。**

---

### 第三章：产品力篇

#### 产品设计体系

| 阶段 | 产出物 | AI辅助 |
|------|--------|--------|
| 产品规划 | PPT大纲、路线图 | WPSAI、豆包 |
| 流程设计 | 功能列表、流程图 | ChatGPT、ProcessOn |
| 结构设计 | 功能结构图、信息结构图 | 大模型+Mapify |
| 原型设计 | 高保真原型 | 即时AI（参考） |
| PRD撰写 | 完整需求文档 | PMAI |

#### 产品规划四步法

```
┌─────────────────────────────────────┐
│  1. 目标分析 → 用户需求、市场空间、SWOT  │
│  2. 做什么   → 产品定位、蓝图、路线图    │
│  3. 怎么做   → MVP、计划、资源          │
│  4. 结论     → 市场/用户/我们有的       │
└─────────────────────────────────────┘
```

#### 核心观点

> **产品经理输出的PRD和PPT都是你对外的表达方式。** 要让别人看到你逻辑清晰、思维缜密。

---

### 第四章：结果力篇

#### 数据分析四步法

```
┌─────────────────────────────────────┐
│  1. 摸清业务模式 → 区分B2B/B2C/B2B2C   │
│  2. 结构化盘点商品 → 找爆品和机会点      │
│  3. 用户分层   → 二八法则找核心用户      │
│  4. 历史活动复盘 → 人货场关系分析        │
└─────────────────────────────────────┘
```

#### 产品运营体系

| 运营类型 | 核心内容 | 精细化运营方法 |
|----------|----------|----------------|
| 用户运营 | 维护满意度、分析行为 | CRM系统、用户分群 |
| 内容运营 | 内容策略、内容管理 | 推荐算法、排序优化 |
| 活动运营 | 营销活动、推广活动 | 生命周期分析、策略迭代 |

#### 时间管理体系

```
┌─────────────────────────────────────┐
│      时间管理三件事                   │
├─────────────────────────────────────┤
│  能力管理 → 找规律，变标准，固化      │
│  精力管理 → 时间块，Buffer Days       │
│  时间管理 → 聚焦当下，工具辅助         │
└─────────────────────────────────────┘
```

#### 核心观点

> **产品经理不为公司拿结果，公司就把你结果。**

> **AI落地的最后一公里是人机交互。**
