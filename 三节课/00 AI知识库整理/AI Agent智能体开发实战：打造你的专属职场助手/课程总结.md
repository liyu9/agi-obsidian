## 四、数据库核心知识

### 4.1 数据库组成

| 层级 | 说明 | 示例 |
|------|------|------|
| RDBMS | 数据库管理系统 | MySQL、Oracle |

### 4.2 SQL语言分类

| 类型 | 指令 | 功能 |
|------|------|------|
| DDL（定义语言） | CREATE、ALTER、DROP | 创建、修改、删除对象 |

| 类型 | 用途 | 示例 |

## 五、工作流核心技能

### 5.1 工作流组成

```
┌────────────────────────────────────────────────────────────┐
│                      工作流结构                            │
├────────────────────────────────────────────────────────────┤
│                                                            │
│    ┌─────────┐                                             │
│    │ 开始节点 │ ──→ 输入变量（文件、文本等）                    │
│    └─────────┘                                             │
│           │                                                 │
│           ▼                                                 │
│    ┌───────────────────────────────────────┐              │
│    │              功能节点                    │              │
│    │  • 插件（读取文件、创建文档）            │              │
│    │  • 大模型（文本处理、报告生成）          │              │
│    │  • 数据库（增删改查）                   │              │
│    │  • 批处理（批量处理）                   │              │
│    │  • 循环（多次执行）                     │              │
│    └───────────────────────────────────────┘              │
│           │                                                 │
│           ▼                                                 │
│    ┌─────────┐                                             │
│    │ 结束节点 │ ──→ 输出变量（结果、文件链接）                  │
│    └─────────┘                                             │
│                                                            │
└────────────────────────────────────────────────────────────┘
```

### 5.2 何时使用工作流

| 条件 | 说明 |
|------|------|
| ✅ 多个组件组合 | 既要插件、又要数据库、又要大模型 |
| ✅ 流程固定 | 必须按指定顺序执行 |
| ✅ 批量处理 | 处理多个文件 |
| ❌ 简单对话 | 单一功能不需要工作流 |

### 5.3 批处理配置

| 参数 | 说明 | 建议 |
|------|------|------|
| 并行数量 | 同时处理的任务数 | ≤5或≤10 |
| 循环次数上限 | 最大处理数量 | 默认100 |

### 5.4 循环体使用

**适用场景**：
- 用户输入多个分析需求
- 每个需求需要独立处理
- 需要避免结果混淆

**循环体组成**：
- 循环控制器
- 循环体（包含处理节点）

## 七、常见问题与解决方案

### 7.1 问题排查表

| 问题 | 可能原因 | 解决方案 |
|------|----------|----------|
| SQL执行失败 | 代码不纯净，含注释符号 | 重新生成纯净代码 |
| 分析结果不准确 | 大模型幻觉 | 使用更稳定的模型或循环处理 |
| 无法识别字段 | 字段名含中文 | 明确告知表名和字段名 |
| 数据重复 | 未删除旧数据 | 添加删除数据节点 |

### 7.2 优化建议

1. **大模型选择**：DeepSeek V3在代码生成方面通常更稳定
2. **数据清空**：批量处理前先清空数据库
3. **变量传递**：确保节点间变量正确引用
4. **代码纯净**：要求生成纯净代码，避免多余符号
