# 课程导读

> 三节课的同学你好，我是高山，你也可以叫我船长。今天这门课我们要聊的是AI产品经理入门。作为一门方法论的课程为了让讲解的内容更接地气，我们以搭建智能客服机器人为例来讲解AI产品经理的能力要求和工作流程。

## 一、讲师介绍

- **姓名**：高山（船长）
- **现任职位**：网易智慧企业事业部的资深产品经理
- **专业背景**：研究生阶段学习启发式人工智能算法
- **工作年限**：六年AI相关产品经验
- **主要作品**：
  - 智能客服机器人
  - 智能语音机器人
  - 智能收益管理系统等多个方向

> 在智能客服这个方向，既做过SaaS的智能客服系统，也做过深入业务场景的大客户定制智能客服系统，对NLP领域有比较深入的了解。

## 二、课程学习收获

| 目标人群 | 课程收获 |
|---------|---------|
| 想成为AI产品经理的人 | 了解AI产品经理的能力模型和工作方法论 |
| AI方向研发/算法工程师 | 了解如何与产品经理配合，让技术价值最大化 |
| AI产品经理的业务方 | 了解如何高效提出AI需求 |
| AI训练师 | 了解如何让自己的工作更有价值、更有效率 |
| 非客服方向的AI产品 | 了解客服方向产品的基础架构和算法能力 |
| 客服方向的AI产品经理 | 启发思路，总结自己的方法论 |
| 老板 | 了解AI是如何给产品赋能的 |
