# 第一章 AI产品经理的能力要求

## 一、AI产品的两大类型

根据产品是否以AI技术为核心驱动，AI产品分为两大类型：

### 1. AI赋能型产品

**定义**：在各行各业使用人工智能技术提升原有业务场景某一环节的效率或体验的产品。

**行业应用案例**：

| 行业 | AI应用场景 |
|------|------------|
| 保险行业 | 智能保顾 |
| 在线教育 | AI老师 |
| 游戏 | AI角色提升游戏体验 |
| 医疗 | 电子病历 |
| 媒体 | AI主播 |
| 法院 | 智能案件检索、智能文本审阅工具 |
| 农业 | 基于机器视觉的虫害/土壤缺陷诊断 |

> 随着深度学习、机器学习、有监督学习、无监督学习等人工智能技术的普及，以及产业互联网的发展，各行各业都在尝试使用AI技术提升原有业务流程的效率。

### 2. AI技术型产品

**市面上最常见的三类产品**：

#### （1）底层通用算法平台

#### （2）提供PaaS化产品能力

**代表企业**：
- 科大讯飞：提供ASR（语音转文本）、TTS（文本转语音）等能力
- 阿里巴巴：提供各类AI能力接口

#### （3）AI应用型产品（最常见）

**核心特点**：围绕某一方面技术（如智能语音、NLP、机器视觉）搭建产品架构

**典型产品**：
- 智能客服机器人
- 智能语音机器人
- 智能安防

### 3. NLP技术的四大应用方向

以自然语言处理技术为例，核心应用方向包括：

```
NLP四大应用方向
├── 对话机器人
├── 阅读理解
├── 智能搜索
└── 机器翻译
```

> 本次课程用来举例的智能客服机器人就属于对话机器人的一种。

## 二、AI产品经理的能力要求

### 1. 核心能力概览

| 能力维度 | 核心要求 |
|---------|---------|
| 业务洞察 | 能够洞察业务场景诉求 |
| 交互体验 | 能够分析人机交互体验 |
| 技术边界 | 了解AI技术的应用边界 |
| 价值平衡 | 持续平衡用户价值和商业价值 |

### 2. 能力详解

#### （1）洞察业务场景诉求

**核心要求**：分析不同业务场景下AI能解决哪些问题、不能解决哪些问题。

**思考维度**：
- 哪个环节可以标准化，用AI技术提升效率
- 机器人能解决问题的边界在哪里
- 如何拓展机器人的应用边界以适应业务趋势变化

> 以智能客服机器人为例，不论在电商行业、在线教育行业，或企业内部的SSC场景，信息咨询的环节，每个业务场景里机器人能解决问题的边界在哪里，是每一个AI产品经理需要持续思考的问题。

**案例应用场景**：
- 电商行业
- 在线教育行业
- 企业内部SSC场景
- 信息咨询环节

#### （2）分析人机交互体验

**核心差异**：AI产品与功能性产品用户体验的洞察方式不同

**关键场景**：人机交互过程中，算法每一轮返回的结果是否符合用户预期

> 产品经理体察用户体验的核心场景就是对话。对话的过程就是用户与机器人进行交互的过程，每一轮对话机器人回复的答案是否是符合用户的预期，就是最核心的一个人机交互场景。

**工作方法**：
- 经常去看对话日志
- 分析如何提升机器人的智能感和问题解决能力

**用户体验分析案例**：

用户问了一个问题，机器人给予一个答案，用户就离开了，用户没有给差评，也没再次进线咨询。但这个问题很有可能机器人给到的并不是最优答案，可能原因包括：
- 语义识别就错了
- 当前场景应该进入多轮应答会更好
- 应该根据用户订单信息或个人标签进行千人千面回复

#### （3）了解AI技术应用边界

**两个层次的要求**：

**第一层**：了解当前行业最核心算法技术解决问题的边界

**第二层**：持续关注该领域算法技术的突破和头部公司的创新

> 以智能客服机器人为例，需要持续关注Abram、Morson或Nuance等公司的新产品或新突破，分析这些突破对机器人对话管理哪个环节有帮助。

**技术边界认知案例**：

> 有一个场景在语音对话场景，大家都在探索根据说话人的语音语调进行访客的情绪识别。但是作为AI产品经理，你应该知道在业内这个场景的识别效果并不好。

#### （4）平衡用户价值与商业价值

**核心挑战**：AI产品更多应用在To B领域

**关键问题**：
- 机器人是否只能提供降低人力成本的价值
- 还有没有其他价值

**平衡艺术**：

> 有时候回答正确，并不代表给用户提供了一个更好的服务。成本减下来的前提是你提供的服务用户是不得不使用的。到底你做的机器人给用户的感受是他得到机器人的服务比人工的服务更优质、更精准，还是用户当前根本找不到人工服务，不得不來使用你的机器人服务？

**商业价值思考**：
- 技术突破给用户带来什么价值
- 商业价值是否是企业认可的
- 投入产出比是否合理

## 三、智能客服机器人介绍

### 1. 为什么选择智能客服机器人作为案例

**核心原因**：在自然语言处理领域，目前商业化落地最成熟的应用场景就是智能客服机器人。

### 2. 智能客服机器人类型

| 类型 | 特征 | 案例 |
|------|------|------|
| **智能语音机器人** | 声音相对机械，不像正常人在对话 | 电话推销、通知提醒 |
| **文本机器人** | 在线客服页面的人机对话 | 京东/淘宝在线客服 |

### 3. 核心技术原理

**核心流程**：
```
用户提问 → 自然语言处理 → 语义分析 → 判断用户意图 → 匹配答案 → 回复用户
```

## 四、本章学习要点

### 核心总结

1. **AI产品分类**：AI赋能型 vs AI技术型
2. **NLP四大应用**：对话机器人、阅读理解、智能搜索、机器翻译
3. **四大核心能力**：业务洞察、交互体验、技术边界、价值平衡
4. **智能客服机器人**：NLP商业化最成熟的应用场景

### 关键术语

- **AI赋能型产品**：使用AI技术提升原有业务场景效率的产品
- **AI技术型产品**：以AI技术为核心驱动的产品
- **NLP**：自然语言处理技术
- **PaaS**：平台即服务
- **SSC**：共享服务中心

### 思考方向

- 如何判断一个场景是否适合用AI技术
- AI产品经理与传统产品经理的能力差异
- 如何平衡技术可行性与业务价值
