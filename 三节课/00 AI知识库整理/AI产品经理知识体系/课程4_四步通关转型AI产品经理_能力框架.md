# 课程4：四步通关，转型AI产品经理 — 能力框架

## 来源
四步通关，转型AI产品经理 > 第一至六章

## AI产品经理分类及转型建议

| 类型 | 特点 | 是否适合转型 |
|------|------|-------------|
| AI模型/AI平台类产品经理 | 关注前沿技术，需对基座模型深度理解 | ❌ 不适合 |
| AI软硬件结合产品经理 | 需要强技术+硬件背景 | ❌ 不适合 |
| AI应用产品经理 | 对技术要求不高，对行业经验、商业逻辑要求高 | ✅ 适合 |

## AI应用产品经理核心要求

```
         ┌──────────────────────┐
         │   AI应用产品经理      │
         ├──────────────────────┤
         │  1. 行业经验 ── 懂业务场景  │
         │  2. 商业逻辑 ── 懂商业价值  │
         │  3. 产品运营 ── 懂产品运营  │
         │  4. 技术应用 ── 了解技术边界  │
         └──────────────────────┘
```

## 转型四步法

| 步骤 | 内容 | 能力要求 |
|------|------|---------|
| 第1步：寻找高价值场景 | 发现AI可解决的业务痛点 | 业务洞察力、行业认知 |
| 第2步：设计AI产品 | 将场景转化为产品方案 | AI产品设计能力、技术理解 |
| 第3步：迭代AI产品 | 基于数据反馈持续优化 | 数据分析、模型评估 |
| 第4步：开展AI产品运营 | 推动产品落地和增长 | 产品运营、市场推广 |

## B端是AI应用的沃土

| 原因 | 说明 |
|------|------|
| 数据资源丰富 | 显性化数字知识+隐性知识 |
| 重复性流程多 | 适合AI自动化 |
| 付费意愿强 | 显著降低人工成本 |

## 职场竞争关键能力

- **懂业务场景**：能发现AI能解决的真正痛点
- **懂用户需求**：能设计满足用户期望的产品
- **了解技术**：知道AI能做什么、不能做什么
- **创新意识**：能将技术潜力转化为真正的产品价值
