# 课程6：AI大模型在数字产品中的落地实践 — 能力框架

## 来源
AI大模型在数字产品中的落地实践 > 第三章 AI大模型产品研发流程与能力要求

## AI大模型时代产品经理能力分层

| 层级 | 核心要求 | 具体能力 |
|------|---------|---------|
| 初级 | 工具使用+AI应用 | 熟练使用AI工具、理解模型特性、将模型应用在工作中 |
| 中级 | 流程再造+架构设计+POC | AI能力整合推动流程优化、架构升级、概念验证 |
| 高级/总监 | 技术趋势把握+组织变革 | 把握技术趋势、做出正确决策、推动组织变革 |

## AI大模型对产品研发各阶段的影响

| 研发阶段 | 传统模式 | AI时代新要求 |
|---------|---------|-------------|
| 规划 | 业务+产品视角 | 增加技术视角——做技术前瞻和展望 |
| 需求分析 | 洞察需求、分析场景 | 角色可能被解构甚至消失 |
| 产品设计 | 流程+功能+交互 | 增加AI能力融合 |
| 研发 | 功能/流程/界面研发 | 协同模型研发，协调两种不同研发模式 |
| 交付运营 | 让客户会用能用 | 设计匹配AI特性的交付流程和运营指标 |

## AI大模型产品研发流程

```
传统流程：规划 → 需求 → 设计 → 研发 → 交付 → 运营 → 迭代
                                              ↓
AI时代新增：技术展望（在规划阶段）
                                              ↓
   流程变化：需求分析角色重构 → 设计融合AI能力
   → 研发协同模型+工程 → 交付关注组织变化
   → 运营关注模型反馈 → 迭代数据+模型驱动
```

## 产品迭代的三重驱动力

| 驱动力 | 描述 | 案例 |
|-------|------|------|
| 场景扩展 | 原来不能做的场景现在可以做 | 智能营销从管理到内容生产 |
| 模型能力提升 | 功能不变但模型有提升 | 引入RAG或微调让回答更准确 |
| 数据积累 | 更多优质数据推动模型优化 | 智能驾驶里程越多能力越好 |
