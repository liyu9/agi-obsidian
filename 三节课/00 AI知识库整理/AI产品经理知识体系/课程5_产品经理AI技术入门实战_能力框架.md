# 课程5：产品经理AI技术入门实战 — 能力框架

## 来源
产品经理AI技术入门实战 > 先导课、第一至十四章

## 课程核心目标
- 不是变成算法专家，而是能和技术团队顺畅协作
- 能设计出有AI能力的业务流程

## AI产品经理最核心的三种能力

```
1. 能够看懂问题背后的AI任务的结构
2. 能够想清楚：场景拆解 + 流程规划 + 能力对接
3. 知道Prompt怎么写得准、Chain怎么搭得稳
```

## Agent搭建六步法

| 步骤 | 内容 | 产品经理职责 |
|------|------|-------------|
| 第1步：确定输入数据类型 | 文本/图像/语音 | 判断是否需要识别结构、有无语义模糊 |
| 第2步：数据转换处理 | Embedding/ASR/图像分类 | 输入是否需要提前标准化处理 |
| 第3步：选择模型能力 | 大模型/检索增强/分类模型 | 判断用不用大模型、考虑成本 |
| 第4步：控制输出 | Prompt模板+微调 | 写Prompt示例、定义输入输出格式、兜底策略 |
| 第5步：对接服务 | API对接模型服务 | 沟通接口结构、确认调用频率和延迟 |
| 第6步：构建Agent | 大模型+Prompt+RAG+Memory+工具 | 设计工作链路和反馈机制 |

## AI项目规划五步法

| 步骤 | 内容 | 目标产物 |
|------|------|---------|
| 第1步：任务拆解 | 把模糊需求翻译成可执行的步骤 | 任务流程草图、AI职责矩阵 |
| 第2步：模型选型 | 根据任务选择合适的模型 | 模型能力对比表+选型决策逻辑 |
| 第3步：输入设计 | Prompt任务指令系统 | Prompt模块化结构 |
| 第4步：RAG设计 | 知识库搭建与检索 | 知识结构图+数据接入方式 |
| 第5步：流程编排 | Chain+Action+Memory+状态控制 | 流程链设计方案 |

## AI任务类型识别

| 任务类型 | 说明 | 技术选型影响 |
|---------|------|-------------|
| 查询型任务 | 单轮输入，类似搜索 | 简单Prompt+知识库即可 |
| 交互型任务 | 多轮对话，引导澄清 | 需要Chain+上下文管理 |
| 闭环型任务 | 需要动作+执行+反馈 | 需要完整的Agent框架 |

## AI产品价值类型

| 价值类型 | 说明 | 典型场景 |
|---------|------|---------|
| 提效 | 提高效率，节约时间 | 自动写周报、会议纪要 |
| 替代 | 替代人工执行 | 智能客服、发票识别 |
| 增强 | 增强现有人的能力 | 销售话术建议、用户画像 |
| 创造 | 创造原本无法提供的服务 | 个性化推荐、AI陪伴对话 |

## 交付与迭代

### 产品阶段拆解
```
原型期（快速验证）→ MVP期（从能用到能跑）
→ 小范围测试（暴露问题）→ 正式交付（产品上线）
```

### 复盘迭代机制
- 可监控、可定位、可调整、可复用
- 用户评分模型 + 异常标签/自动记录 + 失败的Prompt收集
- 三张活表：Prompt模块表、任务链结构图、Prompt DSL语法库
