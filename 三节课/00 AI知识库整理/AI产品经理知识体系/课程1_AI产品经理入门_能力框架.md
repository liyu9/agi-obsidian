# 课程1：AI产品经理入门 — 能力框架

## 来源
AI产品经理入门 > 第一章_AI产品经理的能力要求

## AI产品两大类型

| 类型 | 说明 | 案例 |
|------|------|------|
| AI赋能型产品 | 使用AI技术提升原有业务效率 | 智能保顾、AI老师、电子病历 |
| AI技术型产品 | 以AI技术为核心驱动 | 智能客服、语音机器人、智能安防 |

## 四大核心能力框架

```
┌─────────────────────────────────────────────────┐
│               AI产品经理四大核心能力               │
├─────────────────────────────────────────────────┤
│  1. 业务洞察 ── 洞察业务场景诉求                  │
│     ├ 分析AI能解决/不能解决的问题                    │
│     ├ 判断哪些环节可标准化用AI提效                 │
│     └ 持续思考机器人解决问题的边界                  │
├─────────────────────────────────────────────────┤
│  2. 交互体验 ── 分析人机交互体验                  │
│     ├ 关注算法每轮返回结果是否符合预期             │
│     ├ 经常查看对话日志                             │
│     └ 分析如何提升机器人的智能感                  │
├─────────────────────────────────────────────────┤
│  3. 技术边界 ── 了解AI技术应用边界                │
│     ├ 了解当前行业核心算法技术边界                 │
│     └ 持续关注算法技术突破和头部公司创新           │
├─────────────────────────────────────────────────┤
│  4. 价值平衡 ── 平衡用户价值与商业价值            │
│     ├ 思考AI产品除降本外的其他价值                 │
│     ├ 技术突破给用户带来什么价值                   │
│     └ 商业价值是否被企业认可，ROI是否合理          │
└─────────────────────────────────────────────────┘
```

## 关键能力说明

| 能力维度 | 核心要求 | 典型案例场景 |
|---------|---------|-------------|
| 业务洞察 | 分析不同场景下AI的边界 | 智能客服在各行业的应用边界 |
| 交互体验 | 关注对话过程用户体验 | 用户提问→语义识别→答案匹配→反馈 |
| 技术边界 | 了解技术能力与限制 | 语音情绪识别效果尚不理想 |
| 价值平衡 | 同时实现用户价值与商业价值 | 机器人服务比人工更优质 |
