# 课程7：人工智能产品经理进阶提升 — 能力框架

## 来源
人工智能产品经理进阶提升 > 第一、四、六章

## AI产品经理五大工作流程

```
产品定位 → 需求分析 → 技术预研 → 模型开发 → 运营
```

## AI产品开发双线并行

```
            ┌────── 产品研发线 ──────┐
产品定位 → 需求分析                  → 运营
            └────── 模型开发线 ──────┘
                   技术预研 → 模型开发
```

## AI产品经理四大输出文档

| 文档类型 | 用途 | 核心内容 |
|----------|------|---------|
| 产品价值文档 | 论证商业价值和市场定位 | BRD、商业模式、行业分析 |
| 技术预研文档 | 业务需求转化为技术方案 | 业务技术化方案、算法选型分析 |
| 标注手册 | 数据标注标准和规范 | 标注标准、流程、验收标准 |
| 测试文档 | 模型测试和评估报告 | 测试方法、评价指标、测试结果 |

```
                    ┌──────────┐

           AI产品经理 ┼ 技术认知能力 │
                    ├──────────┤

                    └──────────┘
```

## 需求分析三大维度

```
项目是否适合做AI？
    ├── 数据维度：可获取性、质量、存量、闭环
    ├── 问题维度：可解释性、错误容忍、复杂度、鲁棒性、实时性
    └── 商业维度：业务价值、痛点、AI辅助人工、ROI
```

## 数据标注四角色

|------|------|
| 产品经理 | 定义标注标准、协调资源 |

| 标注人员 | 执行标注 |

## 核心原则

| 原则 | 说明 |
|------|------|
| 可用性原则 | 50%→90%（3天），90%→99%（1年），够用即可 |
| 场景大于逻辑 | 用户使用环境比产品逻辑更重要 |
| 十分之一原则 | AI定价 = 节省人工成本 ÷ 10 |
| 五秒钟法则 | 5秒内能反馈的任务适合AI解决 |
| AI上限法则 | AI的上限由数据的上限决定 |
