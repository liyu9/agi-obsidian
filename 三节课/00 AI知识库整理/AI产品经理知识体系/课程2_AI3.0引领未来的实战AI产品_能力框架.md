# 课程2：AI 3.0 引领未来的实战AI产品 — 能力框架

## 来源
AI 3.0 引领未来的实战AI产品 > 第一章 做好AI产品经理的必备能力

## AI产品三要素

```
            ┌─────────────────┐
            │    数据（Data）   │
            │ 用户行为/交易等   │
            ├─────────────────┤
            │   算法（Algorithm）│
            │ 机器视觉/协同过滤 │
            ├─────────────────┤
            │   算力（Computing）│
            │    CPU + GPU     │
            └─────────────────┘
```

## AI产品经理核心能力模型

| 能力项 | 具体内容 |
|-------|---------|
| Prompt能力 | 大语言模型生成原理、高质量Prompt编写、COT思维链 |
| AI编程能力 | GitHub Copilot、CodeWhisperer、MetaGPT |
| API调用能力 | 自然语言连接一切 |
| Embedding能力 | Token化计算、向量化处理 |
| 框架能力 | LangChain、AutoGPT等框架 |
| Fine-Tuning能力 | 微调、LoRA等模型优化 |
| 产品商业能力 | 传统PM基础能力 |
| 交付能力 | 懂GPU算力、云厂商选型、数据库选型、私有化部署 |
| 备案能力 | 算法备案 |

## AI产品经理分类

| 类型 | 特点 | 适合人群 |
|------|------|---------|
| AI产品经理（软件型） | 场景需求挖掘、技术选型、产品开发 | 软件背景从业者 |
| AI产品经理（软硬件协同型） | 额外需要BOM规划、硬件外观设计、开模 | 有硬件兴趣者 |
| 行业型AI产品经理 | AI+行业融合 | 行业专家转型 |
| 消费型AI产品经理 | 零售型AI产品开发 | 消费品背景 |
| 纯AI产品经理（基站型） | 底层算法、数据、算力 | 技术背景深厚者 |

## 工作职责统一闭环流程

```
业务Knowhow → 需求挖掘 → 数据处理 → AI建模 → 云计算/算力 → 沟通拉通
```

## 技术六级别分层

| 级别 | 技术内容 |
|------|---------|
| L0 | 科幻概念：机器人三定律、图灵测试 |
| L1 | 机器学习、神经网络、深度学习、数据挖掘 |
| L2 | 正则表达式、图搜索、对话系统 |
| L3 | 神经网络、线性回归、CNN、语义分析 |
| L4 | 马尔科夫链、集成学习、迁移学习、RNN |
| L5 | 博弈论、微分动力系统、流形学习 |
| L6 | 量子计算、泛函分析、认知科学 |
