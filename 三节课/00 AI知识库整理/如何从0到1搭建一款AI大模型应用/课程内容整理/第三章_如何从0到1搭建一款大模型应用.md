# 第三章：如何从0到1搭建一款大模型应用

## 3.1 场景探索的重要性

### 核心观点

> 在寻找AI应用场景时，不要想"我能用AI干什么"，而要想"用户有哪些未被解决的问题"。

### Why Now
- AI基础设施（大模型）已搭建好，找到了合适的应用场景 → 成功
- 没找到合适场景强行用AI → 失败概率极高

### 产品经理的技能护城河

> "为什么同样的技术在海量产品经理面前，有的人做出来的产品火，有的人做出来的产品不火？答案就在场景。"

**核心竞争力**：理解业务场景 + 挖掘用户需求的能力。

---

## 3.2 基于任务的场景探索方法

### 方法来源
- 哈佛商学院Clayton Christensen教授
- 核心概念："Jobs to be Done"（待办任务）
- 经典案例：《清晨的奶昔》

### 核心思想

> 用户购买一个产品，本质上是"雇佣"这个产品来完成一个任务。

### 实践框架

```
Step 1: 列出用户的所有任务
Step 2: 分析哪些任务没有被很好地解决
Step 3: 评估AI能否更好地解决这个任务
```

**示例**：证件过期提醒
- 用户任务：确保证件在有效期内
- 当前方案：靠记忆力 → 失败了怎么办？
- AI方案：自动识别证件上的过期时间并提醒

---

## 3.3 双钻模型

> 一个帮助寻找方向的经典设计方法论。

### 两大阶段

```
发现期（发散）
    ↓ 确定问题
定义期（收敛）—— 选场景
    ↓ 确定方案
发展期（发散）
    ↓ 产出方案
交付期（收敛）
```

### 双钻模型 + AI场景探索

```
第一阶段（发散）：列出所有AI可能解决的场景
第一阶段（收敛）：选择最关键、最值得做的场景
第二阶段（发散）：构思解决这个场景的多种方案
第二阶段（收敛）：确定最终的AI产品方案
```

## 3.4 案例介绍

### 实践项目背景

**选场景**：证件过期提醒

**选择理由**：
- 大多数用户都遇到过
- 当前解决方案（靠记忆力）不靠谱
- 用户因为证件过期造成损失 → 情绪共鸣

### 案例目标

用大模型能力帮助用户自动获取证件信息（证件类型、过期时间），在证件过期前触发提醒。

## 3.6 市场调研和用户调研

### 商业价值分析法（TAPCPT）

**Prompt框架9大维度**：

| 序号 | 维度 | 说明 |
|------|------|------|
| 1 | 市场大小 | 蛋糕是否足够大 |
| 2 | 市场细分 | 切哪个细分赛道 |
| 3 | 竞争关系 | 品类内的竞争对手分析 |
| 4 | 市场趋势 | 市场经济环境变化 |
| 5 | 用户画像 | 客户特征（年龄、性别、收入等） |
| 6 | 政策法规 | 市场限制条件 |
| 7 | 经济因素 | GDP、通货膨胀等 |
| 8 | 技术因素 | 保持业务领先性的先进技术 |
| 9 | 消费者反馈 | 用户抱怨和建议 |

**推荐工具**：Perplexity AI（免费，支持联网检索）

### 用户调研三方法

1. **深度访谈**：和用户深入交流，了解场景需求和痛点
2. **观察记录**：作为观察者记录用户行为和活动，挖掘洞察
3. **问卷调查**：设计问卷分发给目标用户

## 3.7 大模型可行性验证

### 五步验证

```
Step 1: 理解大语言模型原理
Step 2: 准备数据集
Step 3: OCR提取文字
Step 4: Prompt工程 + 大模型验证
Step 5: 效果评估
```

### Step 1: 大语言模型原理

**LLM定义**：对人类的语言建立数学模型（概率模型）

**通俗理解**：通讯系统中从受损编码中找出最可能的完整句子

### Step 2: 数据集准备

**数据收集**：10-20张符合场景的证件照片

**汇总表格结构**：

| 列 | 内容 |
|----|------|
| A列 | 图片信息（网盘链接） |
| B列 | OCR提取结果（过程数据） |
| C列 | 大模型提取结果（LLM输出） |
| D列 | 准确率判断（True/False） |

### Step 3: OCR提取

**推荐工具**：腾讯OCR（界面可操作，免费）

**操作**：上传本地图片 → 复制提取的文字 → 贴到Excel B列

### Step 4: Prompt工程

**Prompt三要素**：
- A: 角色扮演（告诉AI你是谁）
- B: 要做什么（具体任务）
- C: 不要做什么（限制条件）

**实践案例Prompt**：
```
你作为一个日历提醒系统。你需要在一组OCR提取的文本中，
告诉我此段文本涉及的两个字段：证件类型和到期时间。
回复格式要求：证件类型:xxx，过期时间:xxxx-xx-xx
注意：
1. 遇有效期至、注销日期、到期时间等统一输出为过期时间
2. 严格按照xxxx-xx-xx日期格式输出
```

**操作平台**：OpenAI Playground（免费）

**关键参数**：
| 参数 | 作用 | 建议 |
|------|------|------|
| Temperature | 控制随机性 | 低→稳定输出；高→创造性 |
| TopP | 控制随机性 | 降低→缩小选择范围 |

> ⚠️ 不要同时调整Temperature和TopP

### Step 5: 效果评估

**核心指标**：

| 指标 | 定义 | 通俗理解 |
|------|------|---------|
| 精确率（Precision） | 预测为正的样本中实际正确的比例 | 跑回来的小动物里有多少是狗 |
| 召回率（Recall） | 实际正样本中有多少被正确预测 | 本来有20只狗，只跑回来了8只 |

> 算法界金句：Garbage in, garbage out（垃圾进，垃圾出）
> → OCR准确率是影响大模型输出的关键因素

### 大模型落地关键因素

1. **稳定性**
   - 服务稳定性：选择稳定的大模型服务商
   - 结果稳定性：调参 + Prompt工程确保输出稳定

2. **规模化**
   - API调用有上限（如OpenAI GPT-4 8K：20K token/分钟）
   - 预估客户使用频率 → 评估rate limit
   - 解决方案：多开region / 多调用几个大模型

### NLP to Everything

```
NLP → reasoning（推理提取）
NLP → SQL（数据库查询）
NLP → PPT（文档生成）
NLP → everything
```
