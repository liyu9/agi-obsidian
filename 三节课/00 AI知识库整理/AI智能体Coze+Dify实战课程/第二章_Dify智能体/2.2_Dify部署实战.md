# Dify部署实战

## 一、服务器准备

### 最低配置要求
- CPU：至少2核
- 内存：至少4GB

## 二、部署步骤

### 1. 安装前提
- 安装Docker
- 安装Docker Compose

### 2. 下载Dify
```bash
git clone <dify仓库地址>
cd dify
```

### 3. 环境配置
```bash
cd docker
cp .env.example .env
```

### 4. 启动服务
```bash
docker-compose up -d
```

## 三、访问配置

### 端口访问
- 访问地址：服务器IP:80
- 首次访问需要初始化设置

### 初始化配置
1. 输入邮箱
2. 设置用户名
3. 设置密码
4. 完成设置

## 四、控制台功能

### 应用创建
- **空白应用**：完全自定义
- **创建工作流**：自动化任务编排
- **创建对话流**：多轮对话应用

### 功能模块
- 应用管理
- 知识库
- 插件扩展
- API集成
