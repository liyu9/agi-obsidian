# 疾病诊断智能体实战

## 一、项目概述

通过十个实战项目介绍Coze使用，每个项目使用不同功能模块。

## 二、创建智能体流程

### 1. 登录与进入开发平台
- 访问 coze.cn 或百度搜索"coze"
- 点击"免费体验" → 进入开发平台
- 点击"项目开发" → "创建智能体"

### 2. 配置智能体
- 输入智能体名称和介绍
- 可自定义图标

## 三、三种模式对比

| 模式 | 特点 | 适用场景 |
|------|------|----------|
| 自主规划模式 | 配置人设和回复逻辑，通过大模型自己思考规划 | 复杂问题求解 |
| 对话流模式 | 配置对话逻辑，智能客服式问答交互 | 智能客服、咨询类应用 |
| 工作流模式 | 拖拽节点完成具体任务 | 自动化任务执行 |

### 选择建议
- **需要交互问答** → 对话流模式
- **完成具体任务** → 工作流模式
- **复杂开放问题** → 自主规划模式

## 四、人设与回复逻辑配置

### 提示词结构
```
# 角色
# 技能
# 回复示例
# 限制
```

### 快速生成方法
使用"自动优化提示词"功能，输入简单描述让AI自动生成完整提示词。

## 五、模型配置详解

### 生成模式选择
| 模式 | 说明 | 适用场景 |
|------|------|----------|
| 精确模式 | 严格遵循指令 | 法律文档、正式文档 |
| 平衡模式 | 创新与精确平衡 | 日常应用场景 |
| 创意模式 | 激发创意新意 | 写小说、文案创作 |

### Token与资源点
- 个人免费版：每天500资源点
- 个人进阶版：9.9元/月，3万资源点
- 上下文轮数越大，消耗Token越多

## 六、工作流基础

### 工作流组成
通过大模型、插件、代码块等功能节点组合，实现复杂业务逻辑。

### 典型节点类型
- **大模型**：内容整理、文案生成
- **插件**：实现特定功能
- **代码块**：数据处理、格式转换

## 七、发布智能体

### 发布流程
1. 点击右上角"发布"
2. 填写发布记录（如1.0版本）
3. 选择发布平台（Coze商店、飞书、抖音、小程序等）
4. 点击发布

### 分享使用
发布后生成链接，可分享给朋友、同事使用。
