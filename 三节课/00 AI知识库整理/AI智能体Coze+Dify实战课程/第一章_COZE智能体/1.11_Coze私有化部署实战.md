# Coze私有化部署实战

## 一、私有化部署概述

### 开源背景
- Coze之前是闭源产品
- 字节跳动现已开源Coze
- 支持私有化部署

### 服务器要求
- CPU：至少2核
- 内存：至少4GB
- 需要安装Docker和Docker Compose

## 二、部署步骤

### 1. 拉取仓库
```bash
git clone <coze仓库地址>
```

### 2. 配置文件修改

#### 修改三个关键配置
1. **模型ID**：非零整数，全局唯一
2. **API Key**：火山方舟平台获取
3. **模型名称**：接入点ID

#### 获取API Key
1. 访问火山方舟管理控制台
2. API管理 → 创建API Key
3. 复制Key到配置文件

#### 获取模型接入点
1. 火山方舟 → 在线推理 → 自定义推理接入点
2. 创建推理接入点
3. 添加模型（如豆包1.5）
4. 复制接入点ID

### 3. 启动服务
```bash
cd coze/docker
cp .env.example .env
docker-compose up -d
```

### 4. 配置访问地址
- 修改环境变量中的服务器IP
- 确保端口监听正确地址

## 三、费用说明

### 公有云 vs 私有化
| 方案 | 费用方式 |
|------|----------|
| 公有Coze | 扣资源点 |
| 私有化部署 | 按量付费（调用大模型） |

### 支持的模型
- DeepSeek
- 通义千问
- 豆包
- 其他第三方模型

## 四、私有化界面

### 功能模块
- 项目开发：创建智能体
- 资源库：工作流、对话流、插件、知识库

### 界面特点
- 比公有版简洁
- 核心功能完整
- 可完全控制数据
