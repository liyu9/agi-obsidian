# 插件开发实战

## 一、插件创建方式

| 方式 | 说明 |
|------|------|
| 已有服务创建 | 调用第三方API接口 |
| Coze IDE创建 | 使用Python编写自定义功能 |

## 二、Coze IDE创建插件

### 适用场景
现有插件无法满足需求时，自定义开发

### 开发流程

#### 1. 创建插件
- 资源库 → 插件 → 添加插件
- 选择"在Coze IDE中创建"
- 选择Python 3

#### 2. 编写工具代码
```python
import re

def extract_urls(text: str) -> dict:
    # 正则表达式匹配URL
    url_pattern = r'https?://[^\s<>"{}|\\^`\[\]]+'
    urls = re.findall(url_pattern, text)
    return {"url_list": urls}
```

#### 3. 配置元数据
- 新增输入参数
- 设置参数名称、描述、类型
- 标记是否必填

#### 4. 测试与发布
- 使用测试输入验证功能
- 更新输入参数配置
- 发布插件

## 三、已有服务创建插件

### 适用场景
调用外部API服务

### 配置步骤

#### 1. 基本信息
- 插件名称
- 请求地址（API端点）
- 请求方法（GET/POST等）

#### 2. 认证配置
- 在Coze获取API Key
- 配置到插件设置中

#### 3. 请求参数
- 添加Header（如Authorization）
- 配置Query参数

#### 4. 返回参数
- 设置返回参数类型（数组、对象等）
- 配置参数映射

## 四、插件上架

### 发布到插件商店
1. 点击"上架插件"
2. 选择"插件商店"
3. 选择分类（使用工具）
4. 提交审核

### 审核后使用
- 在插件市场搜索
- 添加到项目使用

## 五、实战案例：URL提取插件

### 功能
从字符串中提取所有URL

### 实现要点
- 使用正则表达式：`r'https?://[^\s<>"{}|\\^`\[\]]+'`
- 返回数组类型
- 支持批量提取
