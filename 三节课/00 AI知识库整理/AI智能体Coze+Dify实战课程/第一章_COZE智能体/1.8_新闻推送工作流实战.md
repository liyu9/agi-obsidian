# 新闻推送工作流实战

## 一、项目需求

根据用户输入内容搜索新闻，按指定格式反馈新闻概要和链接

## 二、工作流架构

```
开始 → 头条搜索 → 数据整理(代码) → 整理新闻(大模型) → 结束
```

## 三、关键节点配置

### 1. 头条搜索
- 使用"头条搜索"插件
- 输入参数：
  - search_content：搜索内容
  - count：数量限制（默认10）
  - offset：偏移量

### 2. 数据整理（代码块）

#### 功能
提取搜索结果的标题、概要、URL、时间

#### Python代码示例
```python
results = []
for item in input.get("results", []):
    results.append({
        "title": item.get("title", ""),
        "summary": item.get("digest", ""),
        "url": item.get("url", ""),
        "time": item.get("publish_time", "")
    })
return {"formatted_results": results}
```

### 3. 整理新闻（大模型）
- 系统提示词：扮演新闻消息总结专家
- 技能：提炼概要、找出原地址
- 输入：代码整理后的数据

## 四、输出配置

### 结束节点变量
- 新闻概要
- 相关链接
- 整理后的内容

### 预览功能
点击预览查看生成的新闻摘要格式
