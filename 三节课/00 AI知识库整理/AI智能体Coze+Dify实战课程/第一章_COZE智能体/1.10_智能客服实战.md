# 智能客服实战

## 一、项目需求

创建生物学和历史领域的智能客服，支持文字和图片回复

## 二、对话流架构

```
开始 
    ↓
意图识别
    ↓
┌─────────────────────┬─────────────────────┐
│ 生物学问题          │ 其他问题            │
│ ↓                   │ ↓                   │
│ 知识库检索(文字)    │ 历史问题处理        │
│ ↓                   │ (大模型)            │
│ 知识库检索(图片)    │                     │
│ ↓                   │                     │
│ 大模型整合回复      │                     │
└─────────────────────┴─────────────────────┘
    ↓
结束（文字+图片输出）
```

## 三、核心配置

### 1. 意图识别
- 分析用户问题判断意图
- 自动分流到对应处理分支
- 比选择器更智能（不写死条件）

### 2. 知识库配置
- 文字知识库：高中生物知识库
- 图片知识库：生物图片集

#### 图片知识库创建
1. 上传图片
2. 选择"智能标注"或"人工标注"
3. 填写图片描述（提高匹配度）

### 3. 多分支处理
- 生物学问题：走知识库检索分支
- 历史问题：走历史大模型分支
- 其他问题：统一由历史大模型回复（限制范围）

### 4. 图片回复配置
- 知识库检索返回图片
- 大模型整理图片格式
- 结束节点同时输出文字和图片

## 四、意图识别 vs 选择器

| 特性 | 意图识别 | 选择器 |
|------|----------|--------|
| 判断方式 | AI分析语义 | 固定条件判断 |
| 灵活性 | 高 | 低 |
| 配置难度 | 简单 | 简单 |
| 适用场景 | 需要智能判断 | 精确条件判断 |

## 五、大模型配置

### 系统提示词要点
- 明确定义角色（生物学助手/历史助手）
- 设置回复范围限制
- 规定输出格式

### 非相关问题处理
- 明确告知用户不在服务范围内
- 引导用户提出相关问题
