## 一、知识库详解

### 1.1 知识库的核心价值

| 价值 | 说明 |
|------|------|
| 个性化知识输入 | 提供企业专属知识 |
| 专业检索 | 在知识库内检索，而非全网搜索 |
| 避免信息偏颇 | 减少全网搜索带来的各种问题 |

### 1.2 知识库类型

#### 类型一：上传文档

支持的文档格式：

| 格式类型 | 具体格式 |
|----------|----------|
| Office文档 | Word、Excel、PPT |
| PDF | PDF文档 |
| 扫描文件 | 支持OCR识别 |
| 图片 | JPG、PNG |
| 电子书 | 支持多种格式 |

**容量限制（智谱AI）：**
- 单次最多上传20个文件
- 总文件数不超过1000个
- 总字数不超过1亿字

#### 类型二：AI链接

输入网址链接获取知识。

**注意事项：**
- 不是搜索动作，是网址的list清单
- 要选择有小手图标的可点击链接
- 可以获取子链接内容

**示例：**
```
❌ 百度首页（只有广告）
✓ 搜索结果的具体文章页面（有知识内容的页面）
```

## 二、知识库配置实操

### 2.1 上传知识库文件

1. 点击"上传文件"
2. 添加云端知识库文件或本地文件
3. 以"AI办公专家岗位职责说明书"Word文档为例

### 2.2 测试知识库效果

**测试问题：** 请告诉我AI智能办公专家的岗位职责说明书

**预期效果：** AI在知识库中进行搜索和回复，而非全网搜索

### 2.3 回答设置

| 设置项 | 说明 |
|--------|------|
| 参考文档内容 | 是否显示来源文档 |
| 知识库相关段落 | 是否显示相关段落 |
| 仅从知识库回答 | 超出知识库时提示"臣妾做不到" |

**配置技巧：**
- 如果回答内容需要谨慎 → 关闭联网能力，开启"仅从知识库回答"
- 如果希望知识库优先，搜不到再联网 → 开启联网能力

## 三、知识库高级配置

### 3.1 授权内容

可以将微信公众号授权嵌入到知识库中，方便给用户做专项推送。

### 3.2 RAG模式

| 配置项 | 说明 |
|--------|------|
| 切片数量 | 知识库切分粒度 |
| 相关系数 | 匹配精度 |
| 全文模式 | 完整内容检索 |

### 3.3 温度设置

| 参数 | 说明 |
|------|------|
| 生成多样性 | 默认值0.95 |
| 数值越大 | 生成随机性越高 |
| 数值越小 | 输出结果越稳定 |

**温度（Temperature）：** 控制AI输出的多样性，值越低越稳定。

## 五、简历评分智能体实战

### 5.1 业务场景

顺着业务流程继续往下走：
- 已有：岗位职责说明书
- 下一步：简历智能筛选

### 5.2 简历评分流程

```
┌─────────────────────────────────────────────────────────┐
│               简历评分智能体流程                          │
├─────────────────────────────────────────────────────────┤
│  1. 提供岗位职责说明书（已在知识库中）                    │
│  2. 模拟候选人简历（让AI根据岗位要求生成）                │
│  3. AI进行简历评分（差异化评分）                        │
│  4. 给出评分理由                                        │
│  5. 进一步应用（面试问题设计等）                        │
└─────────────────────────────────────────────────────────┘
```

### 5.3 实操步骤

#### 步骤一：让AI模拟简历

**提示词：**

```
请你根据AI智能办公专家的岗位职责说明书的具体招聘要求，
为我模拟3份简历，他们分别是：表姐、林真、张胜明。
```

**AI生成的简历特点：**
- 表姐：计算机相关专业
- 林真：设计学专业
- 张胜明：数据分析专业

#### 步骤二：简历评分

**提示词：**

```
请你针对上面三位面试者的情况，结合岗位说明书进行简历评分。
要注意区分每个人的简历特色，进行差异化评分。
请你将评分结果以表格形式回复给我，告诉我各评分维度的得分情况及评分理由。
```

**评分结果示例：**

| 候选人 | 总分 | 评分亮点 |
|--------|------|----------|
| 表姐 | 88分 | 专业匹配度高 |
| 林真 | 83分 | 设计能力突出 |
| 张胜明 | 87分 | 数据分析能力强 |

#### 步骤三：设计面试问题

**提示词：**

```
请你针对简历最高得分的候选人进行面试，
请为我设计三个面试问题，并告诉我面试问题背后对应的目的。
```

**面试问题示例：**

```
问题1：你之前简历工作中，如何通过AI来优化办公流程？
目的：考察候选人在实际工作中AI工具的应用能力，
以及对办公流程优化的理解和实践。
```

#### 步骤四：角色扮演模拟

**提示词：**

```
请你转变角色，假设你就是表姐，
请结合你的简历情况来回复招聘方问题。
请在回答中提供具体的案例，要有数据支持、有理有据。
回答的口吻和语气要商务化、专业化。
```

## 七、讯飞星火对比体验

### 7.1 界面对比

| 功能 | 智谱AI | 讯飞星火 |
|------|--------|----------|
| 知识库回调显示 | ✅ 支持 | ❌ 不支持 |
| 工作流创建 | 一般 | ✅ 更优秀 |

### 7.2 讯飞星火的特点

- 智能体知识库配置中可以查看数据集
- 问答时不能显示知识库具体内容，回调不够精准
- 简历模拟功能有限

### 7.3 使用建议

**根据需求选择工具：**
- 需要精准回调 → 选择智谱AI
- 需要复杂工作流 → 选择讯飞星火
- 多做练习，举一反三
