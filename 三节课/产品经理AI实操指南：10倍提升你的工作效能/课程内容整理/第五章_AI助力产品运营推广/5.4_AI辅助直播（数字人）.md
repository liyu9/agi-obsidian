# 5.4 AI辅助直播，数字人制作和使用

> 同学们好 第四节的主题主要围绕AI辅助直播来展开。我会为你展示AI怎样在直播领域，尤其是在数字人制作和使用上带来的变革。AI技术可以使我们创造出栩栩如生的虚拟形象，这些数字人不仅能24小时不间断的直播，还可以和观众互动，提供一个全新的观看体验。

## 一、课程任务

创作一段介绍AI资讯助手的直播脚本，通过这个脚本，数字人会向目标群体（25-35岁的知识工作者）展示工具的强大功能。

## 二、直播脚本撰写

### 提示词结构

```markdown
让AI扮演一位经验丰富的直播知识付费主播：
- 目标人群：25-35岁知识工作者
- 产品功能：明确告知
- 脚本要求：包含产品试用、展示、互动、情感调动等关键要素
- 语言风格：专业且富有感染力
- 强调产品卖点，增加互动话题
- 负向要求：避免引起误解或操纵决策的表述
- 目标：提升产品认知，提高下载量
```

**提示词要点：**
| 要素 | 说明 |
|------|------|
| 目标用户 | 25-35岁知识工作者 |
| 产品信息 | 产品名字、功能列表 |
| 脚本要素 | 试用、展示、互动、情感调动 |
| 语言要求 | 专业、富有感染力 |
| 禁止内容 | 避免操纵性表述 |

### 案例对比

**ChatGPT输出：**
- 结构完整：开场白 → 产品介绍 → 适用展示 → 互动环节 → 情感调动 → 结束语
- 代入感强：用第一人称写直播脚本
- 框架可用，可进一步扩充

**智谱清言输出：**
- 相对简单
- 部分表达不够到位（如直接告诉用户年龄）
- 框架不如ChatGPT完整

## 三、数字人介绍

### 数字人应用场景

- **短视频内容出境**：自动生成口播视频
- **直播出境**：24小时不间断直播

## 六、数字人直播总结

### 工具对比

| 工具 | 公司 | 核心优势 | 价格 | 适用场景 |
|------|------|----------|------|----------|
| **万兴播报** | 万兴科技 | 多国籍数字人、出海营销 | 888-1888/月 | 出海、电商、本地生活 |
| **奇妙元** | 出门问问 | 100+数字人、问答库 | 9999/年 | 全行业直播 |

### 核心价值

| 价值点 | 说明 |
|--------|------|
| **24小时不间断** | 数字人可全天候直播 |
| **成本降低** | 减少真人主播投入 |
| **智能互动** | AI自动回复观众问题 |
| **多场景适配** | 支持电商、教育、本地生活等 |

### 局限性

1. **成本较高**：定制数字人价格不便宜
2. **个人定制复杂**：需要拍摄视频采集个人形象数据
3. **适合有财力的企业**：中小企业可能难以承担

## 七、总结

### AI直播解决方案

```
AI生成直播脚本 → 数字人技术呈现 → 智能互动系统
```

### 核心能力

| 能力 | 说明 |
|------|------|
| **脚本生成** | AI根据产品信息快速生成直播脚本 |
| **数字人形象** | 创建虚拟主播形象 |
| **24小时直播** | 全天候自动直播 |
| **智能问答** | AI根据知识库回复观众问题 |

### 适用建议

> 数字人直播技术和解决方案已比较成熟，但成本上不太适合普通人。建议根据公司预算和需求选择合适的方案。
