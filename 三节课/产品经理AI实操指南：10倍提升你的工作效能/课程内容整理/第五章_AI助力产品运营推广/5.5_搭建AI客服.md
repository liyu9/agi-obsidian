# 5.5 搭建AI客服，降低成本，提升体验

> 朋友们好 欢迎来到第五章 第五节。搭建AI客服 降低成本 提升体验。这节课作为咱们AI赋能课的收官制作。我会为你演示如何利用AI技术几分钟来创建一个智能客服系统。这个系统不仅可以整合你的业务数据，提供实时的客户支持，还能够优化客户体验，同时降低运营成本。

## 一、AI客服系统价值

| 价值点 | 说明 |
|--------|------|
| **全天候服务** | 7×24小时无间断服务 |
| **快速响应** | 快速响应客户查询 |
| **个性化帮助** | 提供个性化的帮助和解决问题 |
| **降低成本** | 完全不需要人介入 |
| **数据收集** | 收集用户反馈，持续改进产品 |

## 二、AI客服搭建六步法

### 第一步：选择AI客服平台

**推荐工具：Dify**

**Dify特点：**
- 开源且简单易用的LLMOps平台
- 可视化快速创建和运营AI应用
- 提供可视化的Prompt编排、运营、数据集管理等功能
- 无需AI背景知识也可快速上手
- 对接多个大模型供应商（GPT系列、Claude系列等）
- 支持私有化部署到本地或公司内网
- 也提供云端SaaS版本

### 第二步：申请大模型API密钥

**说明：**
- AI模型的消息调用需要消耗Token
- Dify支持多个大模型公司的API调用
- 初次注册可享受OpenAI GPT系列200次免费调用额度

### 第三步：构建知识库

**重要性：** 知识库决定了AI客服能否准确理解和使用业务数据来支持客户

**知识库构建步骤：**

| 步骤 | 说明 |
|------|------|
| 1. 上传文档 | 将公司产品文档上传到Dify知识库 |
| 2. 数据处理 | Dify自动进行数据分段处理和清洗 |
| 3. 向量化 | 对知识库进行向量化处理 |
| 4. 配置检索 | 选择检索方式（向量化检索/全文检索/混合检索） |

**支持文档格式：** 文本、Notion内容等

### 第四步：创建AI应用

**创建流程：**

1. **选择应用类型**：选择"聊天助手"

2. **添加基础信息**：
   - 图标
   - 名称

3. **编排Prompt（提示词）**：
   ```markdown
   扮演一个AI智能客服的角色
   名称：[自定义名称]
   解答产品相关的用户问题
   设置回答限制条件
   ```

4. **关联知识库**：
   - 让AI拥有业务知识
   - 利用知识库信息支持用户

5. **设置对话开场白**：
   ```markdown
   你好。我是[名称]的AI客服。
   可以向我提问有关[产品名]的任何问题。
   ```

6. **设置下一步问题建议**：
   - 即使用户不知道问什么，AI也能主动引导对话

7. **选择模型**：
   - 不同模型表现和Token价格不同
   - 根据需求和预算选择

### 第五步：发布AI客服

配置完成后，点击发布，AI助手即可上线，准备好与用户互动。

### 第六步：部署到官网

**访问方式：**

| 方式 | 说明 |
|------|------|
| **方式一** | 直接发布URL或二维码，让用户点击链接或扫码进入对话界面 |
| **方式二** | 将对话能力嵌入到网站，复制粘贴提供的代码即可 |

## 三、Dify平台详细操作

### 支持的模型供应商

| 类别 | 供应商 |
|------|--------|
| 国际 | OpenAI GPT系列、Claude系列 |
| 国内 | 智谱清言、讯飞星火、通义千问、文心一言 |

### 知识库创建详解

**数据源类型：**
- 导入已有文本
- 同步Notion内容
- 未来支持同步外国站点

**分段处理：**
- 选择自动分段清洗
- AI自动将文本分成若干段
- 预估分段数

**索引方式：**
| 方式 | 特点 |
|------|------|
| 高质量索引 | 效果好，消耗更多Token |
| 经济索引 | 成本低，效果一般 |

**检索设置：**
- 向量化检索
- 全文检索
- 混合检索（需额外配置Rerank模型）

### 应用配置详解

**Prompt提示词示例：**
```markdown
你是一个[产品名]的AI智能客服。
你的名字叫[名称]。
你的职责是解答用户关于这个产品的任何问题。
请用友好、专业的语气回答。
不要回答与产品无关的问题。
```

**功能配置：**
- 对话开场白：用户打开客服窗口时先打招呼
- 下一步问题建议：引导用户提问

**调试预览：**
- 在右侧调试框输入文字测试效果
- 确认无误后发布

## 四、部署方式

### 访问方式

1. **直接访问**：复制URL或二维码发给用户
2. **嵌入网站**：复制提供的嵌入代码到网站
3. **API接口**：提供后端服务API，可供其他企业调用

### 功能拓展

Dify提供的能力：
- 特定领域的聊天机器人和AI助理
- 文生文、文生图
- 不同长度的创意文档生成
- 自由链接的知识库问答和搜索引擎
- 构建半自主的Agent
- 私有化部署
