# 1.4 大厂如何运用AI增值、提效

> 朋友们好。第三节我们讲的是AI在各行业的应用方式，这一节则会更落地到公司的具体工作内容上。和你聊聊当下的互联网大厂是如何运用AI技术的。在这一节里，你会看到大厂各个产品设计团队是怎么利用AI技术去提升产出的数量和质量的。

## 一、京东案例：AI辅助设计

### 1. 案例背景

身为电商大厂，京东在海报出图、运营设计等领域都在积极探索AI落地的场景。

我们先看一个京东到家利用AI辅助制作营销视觉图的例子，最终落地的成品图视觉效果非常炫酷，看起来就很有食欲，和京东的品牌元素也有很好的融合。

### 2. "好好吃饭"项目挑战

整个项目的背景源于京东到家有一场叫做好好吃饭的项目。老板希望设计师们打造一组从早餐、午餐、下午茶到晚餐、夜宵、周末等**7个分时段**的长图海报，从而让用户感受到来京东可以随时享受生活。

**项目挑战**：
- 从需求提出到项目上线，**不足两周**的时间
- 设计师们统计了一下，他们得在这么短的时间内出**7张海报、7套会场页面**，以及延展的资源位、素材**70多个**

**面临的问题**：
- 怎么样能够快速的出创意？
- 怎么样满足个性化的主题诉求？
- 如何在紧张排期的情况下还能够快速的去落地这么多的设计稿？

最终他们选择了用AI辅助这次的项目生产。

### 3. AI辅助设计流程

整个流程经历了**5个步骤**：

```
关键词提取 → 参考图收集 → AI辅助创意 → AI素材生产 → 人工合成调优
```

**第一步：关键词提取**
- 由设计师确认主题风格的关键词
- 例如：希望呈现出在楼宇的店铺下丰富多元的生活化的场景
- 让用户感受到不同时段的美食享受和对美好生活的一种向往

**第二步：参考图收集**
- 在这个主题调下，收集了很多类似的参考图和主题字体

**第三步：AI辅助创意**
- 无需手动绘制
- 调用一款叫**MidJourney**的AI生图软件
- 直接就可以帮他们去完成场景图和各种各样的视觉元素的设计

**第四步：AI素材生产**
- 利用MidJourney批量生成设计素材

**第五步：人工合成调优**
- 在人工调整图上的部分细节
- 添加宣传文案和京东的各种品牌元素
- 形成了最终的海报图

### 4. 实施效果

后来京东内部复盘：
- 相比传统设计，AI辅助设计能让项目整体**提效50%**
- 沉淀下来的关键词还可以快速的应用到其他需求里
- 不断的帮他们提升AI的可用性

## 二、58集团案例：AI辅助设计

### 1. 案例一：风控专题故事

**目的**：以漫画的形式引导用户看完典型的欺诈案例，警纪类似的事件发生

**制作流程**：
- 故事背景、角色、分镜、画面风格都先由人来定好
- 再把想要的效果图用提示词输入到MidJourney里
- 最后基于ControlNet的技术进行多张场景切换式的人物的一致性微调
- 生成了生动并且有冲击力的最终效果图

### 2. 案例二：真人场景图生成

**目的**：58在求职记活动中需要去设计一组不同岗位职场人的宣传海报

**设计要求**：
- 生成职场人物和职业的场景
- 体现职场人生的故事
- 希望整个风格是真实、接地气，能触动人心

**视觉语言**：纪实风、胶片质感和电影感

**传统方式的问题**：通常宣传海报的真人上镜风格稍微有点土，也不够有震撼的效果。

**AI解决方案**：
1. 先通过关键词锁定需要的人物特征、姿态、表情、风格（写实还是严肃、正脸还是侧脸、沧桑感）
2. 强调角色身份（厨师、普通工人、美发师等）
3. 借助提示词快速改变性别、面部光影、表情、年龄、着装、工作环境、造型、比例、动作等基础信息
4. 最后通过"超写实、面部特写、皮肤的状态、超细节描述"等词语，输出更真实的皮肤质感

**最终效果**：相比普通的人物摄影，AI人物更加有质感、更真实，也更加有视觉冲击力。能快速生成想要的场景，为设计上带来很多新的思路。

## 三、网易AIGC实战案例

### 1. 网易常用的AI工具

网易这样的大厂常用的AI工具核心就**三款**：

| 工具名称 | 主要用途 | 特点 |
|---------|---------|------|
| **ChatGPT** | 文本输出为主 | 通用对话能力 |
| **MidJourney** | 高质量美术创意图的输出 | 创意性强 |
| **Stable Diffusion** | 高可控性设计稿的输出 | 可控性高 |

Stable Diffusion通常搭配**ControlNet**的插件进行微调改善。

### 2. AIGC输出流程

总结大厂常用的AIGC输出流程大概会分为**四步**：

```
需求分析 → 寻找参考 → 人工设计 → 论测微调
```

其中：
- **寻找参考**：可以借助AI工具辅助操作
- **人工设计**：可以借助AI工具辅助操作
- **需求分析**和**论测微调**：需要人工主导

从这套流程里可以看出：作为先进生产力工具的AI，实际上还无法完全替代人类工作，但是作为工作助手还是非常给力的。

### 3. 网易AI实战项目

基于这样的工作流程，网易发起了多个AIGC的落地实战项目：

#### （1）Icon图标绘制
- 借助文生图进行icon图标的绘制

#### （2）直播间特效设计
- 给直播间的氛围特效去做创意设计

#### （3）短视频宣传片制作
- 结合ChatGPT做文案
- Stable Diffusion做角色的设定
- 再用动画生成工具让图片动起来
- 使用文本转语音工具让人物能说话
- 最终合成一部完整的短视频宣传片

#### （4）其他应用场景
- AI辅助用户调研
- 辅助文档处理
- 辅助数据分析
- AI辅助字体生成

### 4. 实施效果

根据内部统计：
- 与以往流程相比，这些AI辅助下的工作产出，效率能提高**40-50%**
- 真正实现了降本增效的目的
