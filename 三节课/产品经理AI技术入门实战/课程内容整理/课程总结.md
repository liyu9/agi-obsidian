## 核心概念速查

### AI处理链路图

```
用户输入 → Token切分 → Embedding向量化 → Transformer处理 
→ Decoder推理 → Output生成 → 用户输出
```

### Agent架构公式

```
Agent = 大模型 + Prompt + RAG + Memory + Action/Tools + Chain
```

### 五大核心模块关系

| 模块 | 作用 | 类比 |
|------|------|------|
| **Prompt** | 工作指令，控制AI行为 | 产品PRD |
| **Embedding** | 语义地图，文本转向量 | 需求结构化 |
| **Token** | 文字碎片与预算限制 | 字符长度限制 |
| **RAG** | 先查资料再回答 | 查资料再汇报 |
| **Memory** | 长期记忆与上下文 | 会议记录 |

### 模型选型维度

| 维度 | 评估要素 |
|------|---------|
| **智力强度** | 理解能力、推理稳定性 |
| **语言适配** | 中英文支持程度 |
| **响应速度** | 延迟与吞吐量 |
| **成本控制** | Token计费与预算 |
| **接入便利** | API配置与部署方式 |

## 产品经理能力图谱

### AI时代的核心能力要求

1. **结构化思维**：将需求拆解为Prompt指令
2. **流程设计**：Chain编排与任务流设计
3. **数据意识**：知识库设计与向量库管理
4. **协作能力**：与技术团队的有效沟通
5. **迭代思维**：持续优化与反馈闭环

### 与传统产品能力的对比

| 传统产品能力 | AI产品能力 |
|-------------|-----------|
| 功能设计 | 能力调度 |
| 页面结构 | 任务流程 |
| 规则引擎 | 智能体编排 |
| 数据结构 | 知识向量 |
| 接口设计 | API集成 |

## AI项目五步法

1. **任务拆解**：把"我要个AI助手"翻译成"它要怎么干活"
2. **模型选型**：选最适合当前任务的模型而非最强的
3. **Prompt设计**：设计任务指令系统而非写文案
4. **RAG设计**：构建知识库让AI有据可查
5. **流程编排**：Chain+Action+Memory的完整链路

## 关键金句

1. **"AI不是全能的，你需要给它装上知识外挂"** —— RAG的核心价值

2. **"Prompt不是问问题，而是写任务说明书"** —— Prompt的本质

3. **"Embedding是AI理解语言世界的地图坐标系统"** —— 语义理解的基础

4. **"Agent等于大模型加工作链路加用户意图管理加反馈机制"** —— Agent的构成

5. **"AI和人类之间最后的那一厘米就是Output"** —— 输出设计的重要性

6. **"产品经理不是要变成算法专家，而是要成为AI系统的设计师"** —— 角色定位

7. **"AI不是一次性交付的作品，而是需要持续调教的可成长型产品"** —— 迭代思维
