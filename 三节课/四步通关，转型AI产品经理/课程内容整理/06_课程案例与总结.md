# 课程案例与总结

## 综合案例：新能源汽车公司AI产品落地

### 案例背景

- **行业**：新能源汽车，市场竞争激烈
- **挑战**：销售转化率低、销售量逐渐下降
- **根因**：客户跟进流程非标、质量差、客户信息积累不下来、客户画像不清晰
- **目标**：引入AI技术赋能销售团队，提升作战能力，带来业绩增长

### 第1步：寻找高价值场景

**业务定位**：销售部门，通过销售业绩带来商业价值

**阶段性目标**：提升销售转化率

**业务流程**：

```
客户线下接待 → 分配给执行销售 → 销售跟进客户
    → 形成画像 + 跟进纪要 → 个性化转化策略 → 订单成交
```

**关键举措**：提升客户跟进动作的标准化，为不同客户提供个性化服务策略

**挑战**：销售过程和结果链路长，看不出动作标准化和结果的关系，大家意愿低

> 他发愁了，我们就笑了——AI可应用的方向

**拆解操作流程**：

```
客户分配 → 3分钟内响应 → 标准跟进动作 → 生成结构化跟进总结和客户画像
```

**AI应用机会**：
1. AI自动做跟进总结
2. 基于跟进总结做智能跟进质检
3. 基于跟进总结做客户档案洞察
4. 基于客户画像安排跟进节奏和内容

**最终选择**：先做AI跟进总结 + AI智能跟进质检（成本和周期考虑，且是后置条件）

### 第2步：设计AI产品

**交付物**：销售完成跟进后10秒内生成结构化的跟进总结报告

**报告包含**：
- 本次跟进要点
- 客户跟进摘要
- 话术评分评级
- 下次跟进时间

**展示位置**：销售使用的移动CRM系统（功能嵌入）

**产品方案**：

| 组件 | 方案 |
|------|------|
| 基座模型 | 国内某一开源模型 |
| 记忆能力 | 训练行业小模型（输入销冠跟进数据+产品信息数据） |
| 输出约束 | Prompt约束输出格式和话术评分 |
| 知识库 | 各地话术要求上传管理，模型调用时使用 |
| 输入系统 | 工作手机采集外呼数据 + 即时聊天数据 → ASR转文字 → CRM跟进管理模块 |
| 工作流 | 数据采集 → ASR解析 → 存CRM → 代码调模型做总结（并行调知识库做话术评分）→ 数据落库 → 前端展示 |
| 交互设计 | 销售确认总结报告后才算跟进完成；后台生成，销售可继续跟进下一个客户 |

### 第3步：迭代AI产品

**指标体系**：

| 指标类别 | 指标 |
|----------|------|
| 模型指标 | 总结准确率、要点召回率、销冠人工评分（易用/可读） |
| 使用指标（⭐北极星） | 智能总结生成率、**采纳率**、满意度 |
| 业务指标 | 跟进动作标准化程度、跟进质量、业务转化率 |

**基线**：北极星指标采纳率60%（十次生成改四次，可接受）

**场景分类**：
- 外呼 vs 微信（两种数据源、两种链路）
- 外呼分不同通话时长，微信分不同会话轮次（时长越长幻觉概率越高）

**迭代手段**：

| 手段 | 说明 |
|------|------|
| 换ASR模型 | 提升输入数据质量 |
| 持续提炼新要点 | 每个要点形成300条数据，对模型微调 |
| 统一话术评分模板 | 各地按统一模板传规则，输出稳定 |
| 增强主管信任 | 主管页面可回溯评分对应的通话过程和要点 |
| 自动通知 | 模型每天总结各销售不合规情况，自动通知主管上下级 |

**推广节奏**：
```
1个门店打磨1个月（采纳率60%→80%）→ 分区域运营 → 全国推广
```

**重点突破**：普通话地区（方言地区ASR准确率差）

**价值扩张**：全国推广后，探索自动客户画像和智能客户分配

### 第4步：开展AI产品运营

**运营最佳实践**：
- 寻找**5名销冠**帮助总结报告要点和标注操作风格

**运营种子用户**：
- 通过社交关系和问卷找到**3名种子用户**打磨早期体验

**推广大众用户**：
- 每个门店**实机演示**
- 种子用户做成**海报**强化明星效应
- 持续强调种子用户的**采纳率峰值**和**实用价值**（十份报告只需改两份）

**运营管理者**：
- 立项时说好——**早期就是小实验**
- 业务负责人直接担任**项目总负责人**
- 所有项目过程以**日报形式抄送**自己的老板和技术干系人

## 课程总结

### 转型AI产品经理的时机

大语言模型技术已进入平稳发展阶段，规模化条件已具备。行业出现职业空白，需要懂行业、懂商业逻辑、懂技术应用、会在企业内落地的产品经理。

### 四个转型步骤总览

```
┌────────────────────────────────────────────────────────────┐
│                    转型AI产品经理四步法                     │
├────────────────────────────────────────────────────────────┤
│                                                            │
│  第1步                         第2步                       │
│  寻找高价值场景    ──────→     设计AI产品                  │
│  · 梳理业务认知                · 设计交付物                │
│  · 拆解操作流程                · 选择基座模型              │
│  · 结合AI能力识别机会          · 构建记忆能力              │
│  · 评估价值×成本选项目         · 自动化输入+工具+工作流    │
│        │                              │                   │
│        ↓                              ↓                   │
│  第4步 ←──────────────────  第3步                          │
│  开展AI产品运营             迭代AI产品                      │
│  · 运营三类用户              · 建三类指标体系              │
│  · 运营三类管理者            · 建迭代闭环流程              │
│  · 运营项目团队              · 分阶段专注迭代              │
│                                                            │
└────────────────────────────────────────────────────────────┘
```

### 四大坑及对应策略

| 坑 | 对应步骤 | 核心策略 |
|----|----------|----------|
| 找了错误场景 | 第1步 | 高价值场景思维，找能带来商业回报的场景 |
| 设计了不实用的方案 | 第2步 | 向人的交付对齐，追求实用性和稳定输出 |
| 迭代策略没做好 | 第3步 | 建指标体系，分阶段专注打磨 |
| 企业内运营不善 | 第4步 | 分群体运营，控制预期，体系化传递信息 |
