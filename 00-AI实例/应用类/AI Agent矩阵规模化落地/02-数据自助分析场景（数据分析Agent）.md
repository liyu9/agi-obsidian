# 数据自助分析场景（数据分析Agent）— 详细设计

> **产品设计方法论映射**：本场景按照"需求验证三步法→成功指标4步法+反指标→数据驱动迭代"闭环设计
> 方法论来源：[[产品设计核心知识总结]]

---

## 1. 需求验证（三步法）

| 步骤 | 内容 |
|------|------|
| **确认用户** | 业务运营人员（日常取数）、数据分析师（深度分析）、管理层决策者（看板+归因） |
| **痛点假设** | ①取数依赖分析师排期，平均耗时2小时 ②SQL门槛高，非技术人员无法自助 ③分析结论产出慢，从数据到洞察链路长 ④多表关联、口径不一致导致数据可信度低 |
| **验证假设** | 日常取数需求平均耗时2小时；分析师80%时间花在取数工单上；非技术人员取数比例<15% |

**用户问题说明**：作为业务运营人员，我想通过自然语言查询数据，从而帮助我无需等待排期即可获得分析结论

---

## 2. 核心交付

- 完成数据分析场景需求拆解与SOP设计，支持多表与多渠道数据源的自然语言查询
- 实现智能体自动规划分析方案：理解意图→关联多表→生成SQL→调用Python插件计算→输出可视化图表与分析结论
- 建立效果评估体系与Bad Case闭环机制

---

## 3. NL2SQL 8步处理流程

```
意图识别 → Query改写 → 智能追问 → Schema Linking → 波动归因 → SQL生成 → 校验 → 执行
```

| 步骤 | 核心机制 | 关键指标 |
|------|---------|---------|
| 意图识别 | 区分数据查询/波动归因/趋势分析 | 准确率≥90% |
| Query改写 | 同义重写、抽象化、HyDE | 歧义消除率 |
| 智能追问 | 信息不足时追问澄清 | 追问命中率 |
| Schema Linking | 自然语言→数据库表字段对齐 | 实体匹配率 |
| 波动归因 | 自动检测波动，量化各因子贡献度 | 归因准确率 |
| SQL生成 | NL2SQL大模型 + DSL中间层 | 语法正确率≥95% |
| 校验 | 语法检查+权限校验+结果验证+口径验证 | 执行成功率 |
| 执行 | 并发查询+结果缓存+超时中断+异常自修复 | 响应时间 |

## 4. 多Agent协作架构（Supervisor模式）

```
Plan Agent（协调者）
├── SQL Agent（数据查询与SQL生成）
├── Code Agent（复杂计算/Python执行）
└── RAG Agent（指标口径/业务知识检索）

记忆层：
├── 短期记忆（会话摘要、上下文追踪）
├── 长期记忆（事实数据、SQL语料库）
```

**编排逻辑**：

```
用户提问
  → Plan Agent：理解意图，制定分析计划
  → 分发任务：
    ├── SQL Agent：生成SQL、查询数据
    ├── Code Agent：复杂计算、统计分析、可视化
    └── RAG Agent：检索指标口径、业务规则
  → Plan Agent：整合结果，生成分析结论
  → 输出：可视化图表 + 分析结论 + 数据表格
```

## 6. 成功指标体系（4步法 + 反指标）

**第一步：产品最高目标** → 实现业务人员自助取数，释放分析师80%取数工单

**第二步：子指标分解**

| 类别 | 指标 | 当前值 | 目标值 |
|------|------|--------|--------|
| 效率 | 取数耗时 | 2小时 | 5分钟 |
| 效率 | 取数工单量 | 基线 | 减少80%+ |
| 效率 | 非技术人员自助取数比例 | <15% | 65% |
| 质量 | NL2SQL准确率 | — | ≥90% |
| 质量 | SQL语法正确率 | — | ≥95% |

**第三步：功能与指标关系**

| 功能模块 | 影响指标 | 影响方向 |
|----------|---------|---------|
| Schema Linking | NL2SQL准确率 | 正向，实体匹配是关键瓶颈 |
| 智能追问 | 一次解决率 | 正向，减少歧义查询 |
| DSL中间层 | 过程可验证性 | 正向，SQL透明化 |
| Python Code Agent | 分析深度 | 正向，突破SQL计算限制 |

**第四步：反指标（必须量化）**

| 反指标 | 安全阈值 | 降级策略 |
|--------|---------|---------|
| SQL执行失败率 | ≤5% | >10%暂停自动执行，转人工审核 |
| 口径不一致率 | ≤3% | >5%强制展示口径说明+人工确认 |
| 幻觉率（编造数据） | ≤2% | >3%标记数据来源，禁止推测性回答 |
| 敏感数据泄露率 | 0% | 任何泄露立即暂停服务，安全审计 |

---

## 7. 核心成果

- 日常取数需求从2小时压缩至5分钟
- 数据分析师取数工单量减少80%+
- 非技术人员自助取数比例提升至65%
