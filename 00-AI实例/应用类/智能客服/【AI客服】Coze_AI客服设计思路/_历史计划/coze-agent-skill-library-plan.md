### 1.2 从对话中提炼的经验分类

#### A. Agent 设计方法论
- 如何从零设计一个 Agent（需求分析 → 架构设计 → 节点配置）
- 意图分类设计原则（3-6 类，先精简后扩展）
- 缓存层设计（关键词匹配 + 增强检索 + 找人工两次触发）
- 知识库分层设计（FAQ 小库优先 + 产品大库兜底）
- 答案质量保障（审核 + 重试机制）
- 促单策略设计（场景化、自然、不生硬）

#### B. Coze 平台实操经验
- 对话流（Chatflow）搭建完整流程
- 数据库节点：创建、查询、导入数据格式（字符串类型、空值处理、模板导出）
- 代码节点：Python 语法、输入输出参数、变量引用
- 选择器节点：分支条件配置、与代码节点配合
- 大模型节点：模型选择（Lite vs Pro）、温度设置、Prompt 编写、JSON 输出
- 知识库检索节点：单节点多库检索、Query 限制
- 变量赋值节点：会话变量写入
- 会话变量：只支持 String、名称 ≤ 20 字符

#### C. 踩坑经验（Coze 平台限制）
- 变量只支持 String 类型，Number/Boolean 不支持
- 变量名长度限制 20 字符
- 代码输出变量不需要 n4_ 前缀
- 知识库检索 Query 只能一个输入，不能拼接
- 数据库导入：首行字段名必须匹配、数值用字符串、空值用空字符串
- 选择器条件表达式功能有限，复杂判断需代码节点
- 大模型节点 JSON 输出需要配置 JSON 样例

#### D. 文档生成格式规范
- 配置手册结构（标题 → 变更记录 → 流程总览 → 前置准备 → 节点配置 → 连接 → 测试 → 发布 → 排查 → 附录）
- 节点描述格式（节点作用 → 数据流向 → 输入/配置/输出）
- 选择器分支格式（条件 + → 连接到下游节点）
- 流程图格式（Mermaid + 文本版 + 节点速查表）
- 连接关系表格式

#### E. 迭代优化方法论
- 如何从 v1.0 迭代到 v1.2.3
- 减少节点（删除多余、合并 1:1 关联）
- 修复逻辑漏洞（计数重置、参数传递缺失）
- 提升体验（固定文案 → LLM 动态生成）
- 简化流程（双库合并为单节点）
- 标记可选节点（答案审核等高成本节点）

#### F. 调研方法论
- 如何调研一个新行业的客服需求
- 调研报告结构（背景 → 对象 → 功能对比 → 需求分类 → 高频问题 → 痛点 → 能力要求）
- 从多个竞品中提取共性（而非为每个竞品做不同方案）

#### G. 场景适配方法论
- 如何将通用架构适配到新场景（低代码、电商、教育等）
- 需要用户输入的适配项：意图分类、缓存规则、FAQ、知识库、促单话术
- 不需要改动的部分：流程架构、代码节点逻辑、选择器结构

## 第二步：Skill 设计

### Skill 定位

**通用 Coze Agent 搭建 Skill**，不局限于客服场景。适用于：
- 客服 Agent（电商、低代码、教育、金融等）
- 销售 Agent（线索筛选、产品推荐、促单转化）
- 运营 Agent（内容生成、数据分析、活动策划）
- HR Agent（招聘筛选、入职引导、政策咨询）
- 任何需要在 Coze 中搭建的对话式 Agent

### Skill 内容结构

```
# Coze Agent 搭建 Skill

## 一、适用场景
任何需要在 Coze 中搭建对话式 Agent 的场景

## 二、使用流程
阶段 1：需求分析 → 阶段 2：架构设计 → 阶段 3：数据准备 → 
阶段 4：配置手册生成 → 阶段 5：Coze 落地 → 阶段 6：测试 → 阶段 7：迭代

## 三、阶段 1：需求分析
- 引导用户描述 Agent 目标、业务场景、用户画像
- 提炼核心能力需求
- 生成调研报告（如需调研外部信息）

## 四、阶段 2：架构设计
- 基于 Agent 类型选择架构模板
- 设计意图分类
- 设计缓存策略
- 设计知识库结构
- 设计分支路由
- 对话确认方案

## 五、阶段 3：数据准备
- 生成知识库文档（FAQ + 业务知识库）
- 生成缓存规则数据表
- 生成数据库字段定义

## 六、阶段 4：配置手册生成
- 按文档格式规范生成完整配置手册
- 包含所有节点的详细配置
- 包含流程图、速查表、连接关系表

## 七、阶段 5-7：落地、测试、迭代
- Coze 搭建检查清单
- 测试用例模板
- 优化方向参考

## 八、附录
### 附录 A：Coze 平台限制与应对
### 附录 B：代码模板库
### 附录 C：Prompt 模板库
### 附录 D：文档格式规范
### 附录 E：迭代优化策略
### 附录 F：调研方法论
```
