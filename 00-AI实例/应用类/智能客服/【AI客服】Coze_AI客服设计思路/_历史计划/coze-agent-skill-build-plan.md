# 通用 Coze Agent 搭建 Skill 实施计划

## 概述

将 `/workspace/` 下 12 个文件中积累的 Coze Agent 搭建全量经验（v1.0 到 v1.2.3 的完整迭代），提炼为一个通用 Skill 文件 `coze-agent-build-skill.md`。该 Skill **不局限于客服场景**，可覆盖任意类型的 Coze 对话式 Agent 设计与搭建。

## 当前状态

- 已有 12 个产出物文件（配置手册、调研报告、知识库文档、数据准备清单等）
- 已完成 v1.0 → v1.1 → v1.2 → v1.2.2 → v1.2.3 共 5 个版本的迭代
- 已提炼 7 类经验（A-G），已获用户批准

## 产出物

- **文件**：`/workspace/coze-agent-build-skill.md`
- **格式**：单个 Markdown 文件
- **预估规模**：约 2000-3000 行

## 实施步骤

### 步骤 1：经验梳理与分类提炼

从所有文件中系统提取全量经验，按 A-G 七类归档：

#### A. Agent 设计方法论
- **数据来源**：v1.2.3 配置手册（26节点架构）、设计方案、v1.2 改动对比
- **提炼内容**：
  - 需求分析框架（从调研报告"能力矩阵"抽象）
  - 架构设计原则（确定性优先、知识驱动、安全兼容、体验为先、可迭代）
  - 意图分类设计原则（3-6类，先精简后扩展，按业务处理路径分）
  - 缓存层设计模式（找人工+业务缓存双机制）
  - 知识库分层设计（FAQ小库+业务大库 → 单节点多库检索演进）
  - 答案质量保障（审核+重试+revision_hint传递）
  - 管道式架构模式（输入→缓存→意图→路由→检索→生成→审核→输出）

#### B. Coze 平台实操经验
- **数据来源**：v1.2.3 配置手册（26节点配置）、导入后配置教程、搭建手册
- **提炼内容**：
  - 对话流搭建完整流程
  - 7种节点类型配置经验（数据库/代码/选择器/大模型/知识库/变量赋值/输出）
  - 会话变量管理（String类型、20字符限制）
  - 模型选型策略（Lite 7B做分类/审核，Pro 32B+做生成）

#### C. 踩坑经验（9条Coze平台限制）
- **数据来源**：v1.2.3 常见问题排查（20+条）、v1.2 改动对比
- **提炼内容**：
  1. 会话变量只支持String类型
  2. 变量名长度限制20字符
  3. 代码节点不能自引用自身输出
  4. 知识库检索Query只能一个输入
  5. 数据库导入格式特殊（字符串、空字符串、无系统字段）
  6. 选择器条件表达式功能有限
  7. 大模型JSON输出需配置JSON样例
  8. 变量引用在节点未创建时显示红色（正常现象）
  9. 流式输出仅在"返回文本"模式下生效

#### D. 文档生成格式规范
- **数据来源**：v1.2.3 配置手册（完整文档结构范例）
- **提炼内容**：
  - 配置手册整体结构（8个必选章节）
  - 节点描述格式（作用→数据流向→输入/配置/输出）
  - 选择器分支格式（条件+→连接到下游节点）
  - 流程图三件套（Mermaid+文本版+节点速查表）
  - 连接关系表、变更记录、版本对比表格式

#### E. 迭代优化方法论
- **数据来源**：v1.0→v1.1→v1.2→v1.2.3→v1.3 全部变更记录
- **提炼8项优化策略**：
  1. 减少节点（删除多余、合并1:1关联）
  2. 修复逻辑漏洞（计数重置、参数传递缺失）
  3. 提升体验（固定文案→LLM动态生成）
  4. 简化流程（双库串联→单节点并行）
  5. 标记可选节点（答案审核等高成本节点）
  6. 参数精简（输出参数从7个减为3个）
  7. 增强能力（新增intent输入、revision_hint）
  8. 统一规范（全局语气、节点命名、变量名缩短）

#### F. 调研方法论
- **数据来源**：低代码平台客服需求调研报告
- **提炼内容**：调研报告9章结构、需求分类方法、高频问题提炼、痛点分析框架、能力矩阵设计

#### G. 场景适配方法论
- **数据来源**：v1.2 vs v1.2.3 适配对比表、数据准备清单
- **提炼内容**：适配清单（需改/不需改）、适配对比表模板、数据准备分级（P0/P1/P2）

### 步骤 2：Skill 文件结构设计

```
# 通用 Coze Agent 搭建 Skill

## 元信息（适用范围、版本、经验来源）

## 阶段 1：需求分析
  1.1 引导用户描述 Agent 目标
  1.2 确定业务场景与用户画像
  1.3 提炼核心能力需求
  1.4 生成调研报告（可选）
  → 输出物：需求分析文档

## 阶段 2：架构设计
  2.1 技术选型（对话流 vs 工作流）
  2.2 设计意图分类体系
  2.3 设计缓存策略
  2.4 设计知识库结构
  2.5 设计分支路由
  2.6 设计答案质量保障机制
  2.7 设计会话变量
  → 输出物：架构设计文档 + 流程图

## 阶段 3：数据准备
  3.1 知识库内容准备（FAQ + 业务知识库）
  3.2 缓存规则数据表准备
  3.3 数据库字段定义
  3.4 品牌话术与敏感信息清单
  → 输出物：数据准备包

## 阶段 4：配置手册生成
  4.1 按文档格式规范生成完整配置手册
  4.2 包含所有节点的详细配置步骤
  4.3 包含流程图、速查表、连接关系表
  → 输出物：完整配置手册

## 阶段 5：Coze 落地
  5.1 创建对话流 → 创建知识库 → 创建会话变量
  5.2 按顺序配置节点
  5.3 连接节点
  5.4 搭建检查清单
  → 输出物：可运行的 Coze Agent

## 阶段 6：测试
  6.1 通用测试用例模板（覆盖所有分支路径）
  6.2 调试技巧
  → 输出物：测试报告

## 阶段 7：迭代
  7.1 迭代优化策略（8项）
  7.2 数据驱动优化方法
  → 输出物：优化方案

## 附录 A：Coze 平台限制与应对（9+条）
## 附录 B：代码模板库（4个模板：缓存匹配/命中判断/重试判断/转接原因生成）
## 附录 C：Prompt 模板库（8个模板：意图识别/答案生成/答案审核/挽留引导/能力引导/意图澄清/情绪安抚/未命中引导）
## 附录 D：文档格式规范
## 附录 E：迭代优化策略
## 附录 F：调研方法论
```
