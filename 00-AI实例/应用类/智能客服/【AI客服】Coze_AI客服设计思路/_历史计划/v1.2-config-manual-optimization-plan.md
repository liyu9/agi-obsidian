# v1.2 配置手册优化计划

## 概述

基于用户反馈的 8 个问题，对 v1.2 配置手册进行优化。

## 改动清单

### 改动 1：缓存规则细化关键词

**文件**：`/workspace/企业AI Agent客服应用 - Coze v1.2配置手册.md`

**位置**：节点 2 高频缓存匹配代码

**改动内容**：
- 去掉过于宽泛的单字关键词（如"退货"改为"怎么退货"、"退货流程"）
- 避免缓存命中覆盖用户具体描述

**改前**：
```python
{"keywords": ["退货", "退换货", "怎么退", "退货流程", "退款流程"], ...}
```

**改后**：
```python
{"keywords": ["退换货", "怎么退货", "退货流程", "退款流程", "如何退货"], ...}
```

### 改动 2：删除情绪检测和低置信度分支

**涉及内容**：

| 删除项 | 位置 |
|-------|------|

| 负面情绪分支 | 分支路由节点 |

```
分支2：product_info → 正常流程
分支3：order_logistics → 正常流程
分支4：after_sale → 正常流程
否则：转人工
```

---

### 改动 5：答案生成增加促单话术

**位置**：答案生成节点的 System Prompt

**新增指令**：
```
## 促单话术

如果用户咨询的是产品问题（intent=product_info），回答末尾加一句促单话术，例如：
- "这款现在有活动，可以考虑一下~"
- "库存不多了，喜欢的话可以早点下单~"

注意：
- 促单话术要自然，不要生硬
- 只在产品咨询场景加，订单物流和售后场景不加
```

---

### 改动 6：命中判断移到答案生成之前

**当前流程**：
```
知识库检索 → 答案生成 → 答案审核 → 命中判断 → 满意度判断
```

**优化后流程**：
```
知识库检索 → 命中判断
              ├── has_hit=true → 答案生成 → 答案审核 → 满意度判断
              └── has_hit=false → 免容回复 → 回复输出
```

**改动内容**：
1. 命中判断节点移到知识库检索之后
2. 新增一个「免容回复」输出节点
3. 更新连接关系表
4. 更新流程图

---
