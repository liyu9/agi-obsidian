# 无代码产品知识库

## 一、产品功能介绍

### 1.1 零代码应用搭建
通过拖拽式配置快速构建业务应用，无需编写代码。支持5分钟配置场景、5小时搭建应用、5天落地方案。

### 1.2 数据模型与字段类型
支持丰富的字段类型：
- 基础类型：文本、数字、日期、单选、多选、附件、人员
- 高级类型：关联字段、查找引用、公式、自动编号、条码
- 特殊类型：子表、地址、分组字段、审批字段

### 1.3 多视图呈现
同一份数据支持多种展示方式：
- 表格视图：类似Excel的数据展示
- 看板视图：按字段分组展示卡片
- 画册视图：图片为主的卡片展示
- 日历视图：按日期展示记录
- 甘特图视图：项目进度管理
- 树形视图：层级结构展示

### 1.4 自动化/工作流引擎
支持触发器+条件+动作的自动化流程：
- 触发器：新增/修改/删除记录时、定时触发、按钮触发、webhook触发
- 条件分支：支持多条件组合判断
- 执行动作：发送通知、更新字段、创建记录、调用API、循环处理
- 支持子流程和循环节点（专业版及以上）

### 1.5 权限管理
基于RBAC的精细化权限控制：
- 角色权限：创建角色，分配功能权限
- 数据权限：行级别权限（谁能看哪些数据）、列级别权限（谁能看哪些字段）
- 视图权限：控制不同角色看到的视图
- 外部用户权限：控制外部用户的访问范围

### 1.6 数据分析与仪表盘
- 统计图表：柱状图、折线图、饼图、漏斗图等
- 数据大屏：支持多组件联动展示（标准版及以上）
- 聚合表：跨表数据汇总分析
- 千人千面：按角色权限展示不同数据

### 1.7 API与集成
- 开放API：支持RESTful API调用，可查询、创建、更新、删除数据
- Webhook：支持事件触发时向外部URL发送数据
- 第三方集成：支持与企业微信、钉钉、飞书等平台对接
- 数据同步：支持多数据源同步（旗舰版）

## 三、使用教程

### 3.1 创建应用
1. 进入工作台 → 点击「创建应用」
2. 选择创建方式：空白创建 / 从模板创建 / 导入Excel创建
3. 填写应用名称和描述
4. 进入应用编辑器，开始配置

### 3.2 配置数据表
1. 在应用中点击「新建数据表」
2. 定义字段名称和字段类型
3. 设置字段属性（必填、唯一、默认值等）
4. 配置字段间的关联关系

### 3.3 配置自动化
1. 进入应用 → 点击「自动化」→ 新建规则
2. 选择触发类型（记录变更/定时/按钮/webhook）
3. 设置触发条件（如：当状态字段变为"待审批"时）
4. 添加执行动作（如：发送通知给指定人员）
5. 保存并启用

### 3.4 设置权限
1. 进入「设置」→「权限管理」
2. 创建角色（如：管理员、编辑者、查看者）
3. 为角色设置数据权限和功能权限
4. 将用户分配到对应角色

### 3.5 数据导入
1. 进入数据表 → 点击「导入」
2. 下载导入模板或直接上传Excel/CSV文件
3. 映射文件列与表字段的对应关系
4. 确认导入
5. 注意事项：
   - 字段类型需匹配（文本不能导入到数字字段）
   - Excel中不要有合并单元格
   - 大数据量建议分批导入（每次不超过1万行）

### 3.6 数据导出
1. 进入数据表 → 点击「导出」
2. 选择导出格式（Excel/CSV）
3. 选择导出范围（全部数据/当前筛选结果）
4. 确认导出

### 3.7 配置视图
1. 在数据表上方点击「+」添加视图
2. 选择视图类型（表格/看板/画册/日历等）
3. 配置视图的筛选条件和排序规则
4. 设置视图权限（哪些角色可以看到此视图）

## 四、常见错误与解决方案

### 4.1 数据导入失败
- 错误：字段类型不匹配 → 解决：确保Excel列的数据类型与表字段一致
- 错误：含合并单元格 → 解决：取消合并，每行独立
- 错误：含特殊字符 → 解决：清理数据中的特殊符号
- 错误：超过行数限制 → 解决：分批导入或升级版本

### 4.2 自动化不触发
- 检查触发条件是否正确配置
- 检查自动化是否已启用（开关状态）
- 检查自动化执行次数是否已耗尽
- 检查触发条件的字段是否正确引用

### 4.3 权限看不到数据
- 检查用户所属角色的数据权限设置
- 检查视图权限是否限制了可见性
- 检查行级别权限的过滤条件
- 确认数据是否属于该用户可见的范围

### 4.4 公式计算错误
- 检查公式语法是否正确
- 注意除数为零的情况
- 跨表引用的字段需确保目标表有数据
- 单个数据表内公式和查找引用字段总数有限制（通常100个）

### 4.5 关联字段无法选择数据
- 确认目标表中已有数据
- 检查关联字段的配置是否正确
- 检查当前用户是否有目标表的数据权限

## 五、API与集成指南

### 5.1 API基础
- API地址：在「设置」→「API管理」中查看
- 认证方式：API Key（Bearer Token）
- 支持的操作：查询列表、获取详情、创建记录、更新记录、删除记录
- 请求频率限制：根据版本不同有所区别

### 5.2 Webhook配置
1. 进入自动化 → 新建规则
2. 触发条件选择「记录变更」
3. 执行动作选择「发送Webhook」
4. 填写目标URL和请求参数
5. 保存并启用

### 5.3 第三方平台对接
- 企业微信：支持消息推送、审批对接
- 钉钉：支持消息推送、审批对接
- 飞书：支持消息推送、审批对接
- ERP/CRM：通过API或数据同步实现对接
