# 企业AI Agent客服应用 - 导入后配置教程

> 本文档基于 Coze 扣子平台，引导你从导入对话流到完成所有手动配置，最终上线可用。
> 前置条件：已拥有 Coze 付费套餐账号，已导入 `企业AI Agent客服应用-Coze导入文件.zip`。

## 第一步：创建并配置 5 个知识库

### 1.1 进入知识库管理

1. 登录 [Coze 扣子](https://www.coze.cn)
2. 左侧菜单 → **「知识库」**
3. 点击**「创建知识库」**

### 1.2 创建 5 个知识库

按以下顺序逐一创建，每个知识库选择**「本地文档」**上传方式：

| 序号 | 知识库名称 | 上传内容 | 搜索策略 | 最小匹配度 |
|------|-----------|---------|---------|-----------|
| ① | 产品知识库 | 产品信息文档（商品名称、品类、规格、描述等） | 语义 | 0.5 |
| ② | FAQ 知识库 | 常见问题与标准答案（Q&A 格式） | 混合 | 0.5 |
| ③ | 订单物流知识库 | 订单查询方式、发货政策、退换货流程 | 语义 | 0.5 |
| ④ | 售后政策知识库 | 退货政策、保修条款、投诉渠道 | 混合 | 0.5 |
| ⑤ | 营销活动知识库 | 当前活动规则、优惠券使用条件 | 语义 | 0.6 |

**每个知识库的创建步骤**：

1. 点击**「创建知识库」**
2. 输入知识库名称（如"产品知识库"）
3. 选择**「扣子知识库」**类型
4. 点击**「上传文档」**，选择对应的 Markdown / Word / TXT 文件
5. 等待文档解析完成
6. 在知识库设置中：
   - 搜索策略：按上表选择
   - 最小匹配度：按上表设置
7. 点击**「保存」**

### 1.3 文档内容规范

上传的文档建议遵循以下格式，便于检索命中：

```
Q: [用户常见问法]
A: [标准答案]

---

Q: [另一个问题]
A: [另一个答案]
```

**示例**：

```
Q: 羽绒服可以机洗吗
A: 我们的羽绒服不建议机洗，建议手洗或干洗。
手洗步骤：1. 用30°C以下温水浸泡10分钟
2. 使用中性洗涤剂轻柔搓洗
3. 悬挂晾干，避免阳光直射
4. 晾干后轻轻拍打恢复蓬松

Q: 退货需要多久
A: 退款审核通过后1-3个工作日退回原支付账户。
微信/支付宝一般当天到账，银行卡1-2个工作日。
```

## 第二步：绑定知识库到检索节点

### 2.1 打开对话流

1. 左侧菜单 → **「资源库」**
2. 找到已导入的**「AI客服对话流」**，点击进入编辑

### 2.2 配置知识库检索节点

1. 在画布上找到**「知识库检索」**节点，点击它
2. 在右侧配置面板中：
   - **知识库类型**：确认选择「扣子知识库」
   - **选择知识库**：勾选刚才创建的 5 个知识库
     - ☑ 产品知识库
     - ☑ FAQ 知识库
     - ☑ 订单物流知识库
     - ☑ 售后政策知识库
     - ☑ 营销活动知识库
   - **搜索策略**：选择「语义」
   - **最大召回数量**：5
   - **最小匹配度**：0.5
   - **查询改写**：开启
   - **结果重排**：开启
3. 点击**「保存」**

## 第三步：配置人工转接接口

### 3.1 找到人工转接节点

在画布上找到**「人工转接」**节点，点击它。

### 3.2 配置 HTTP 插件

1. 确认插件类型为**「HTTP Request」**
   - 如果没有该插件，点击插件名称 → 搜索「HTTP Request」→ 添加
2. 在请求配置中：
   - **请求方法**：POST
   - **请求 URL**：替换为你的实际接口地址

**URL 替换位置**：

```
当前值：https://your-crm-system.com/api/customer-service/ticket
替换为：https://你的实际域名/api/xxx
```

3. **请求头**（Headers）：
```json
{"Content-Type": "application/json"}
```

4. **请求体**（Body）保持不变：
```json
{
  "user_id": "{{CONVERSATION_NAME}}",
  "question": "{{USER_INPUT}}",
  "intent": "{{N3.intent}}",
  "transfer_reason": "{{N4_5.transfer_reason}}",
  "source": "ai_customer_service"
}
```

### 3.3 如果没有现成的 CRM 接口

**临时方案**：将人工转接节点替换为**输出节点**

1. 删除「人工转接」节点
2. 在原位置添加一个**「输出节点」**
3. 输出内容设为：
```
已为您转接人工客服，会有专人为您处理，请稍等~
```
4. 流式输出：关闭
5. 会话历史写入：不写入
6. 将上游连线重新连接到这个输出节点

## 第四步：确认模型选择

### 4.1 检查意图识别节点

1. 点击**「意图识别」**节点
2. 在模型配置中确认：
   - **模型**：豆包 Lite（7B 或类似小模型）
   - **温度**：0.2
   - **最大输出长度**：500
   - **输出格式**：JSON

### 4.2 检查答案生成节点

1. 点击**「答案生成」**节点
2. 在模型配置中确认：
   - **模型**：豆包 Pro（32B+ 或类似大模型）
   - **温度**：0.4
   - **最大输出长度**：1024
   - **输出格式**：文本

### 4.3 检查答案审核节点

1. 点击**「答案审核」**节点
2. 在模型配置中确认：
   - **模型**：豆包 Lite（7B+ 或类似小模型）
   - **温度**：0.1
   - **最大输出长度**：300
   - **输出格式**：JSON

> 如果模型显示为默认模型或不可用，点击模型下拉框手动选择。

## 第五步：更新高频缓存规则

### 5.1 找到高频缓存匹配节点

在画布上找到**「高频缓存匹配」**节点，点击它。

### 5.2 查看当前缓存规则

当前内置了 5 条缓存规则：

| 规则 | 关键词 | 覆盖场景 |
|------|-------|---------|
| 1 | 退货、退换货、怎么退、退货流程、退款流程 | 退货相关问题 |
| 2 | 支付方式、怎么付款、付款方式 | 支付相关问题 |
| 3 | 发货时间、什么时候发货、多久发货 | 发货相关问题 |
| 4 | 运费、包邮、邮费、运费多少 | 运费相关问题 |
| 5 | 发票、开票、增值税发票 | 发票相关问题 |

### 5.3 根据实际数据更新

1. 从你的**用户问题列表**中统计 TOP 5 高频问题
2. 在代码编辑区域找到 `cacheRules` 数组
3. 按以下格式添加或修改规则：

```javascript
{
  keywords: ['关键词1', '关键词2', '关键词3'],
  answer: '预设的标准答案内容'
}
```

**示例**：如果"会员权益"是高频问题，添加：

```javascript
{
  keywords: ['会员', '会员权益', 'VIP', '会员等级'],
  answer: '您好！我们的会员权益如下：\n- 普通会员：全场95折\n- 金卡会员：全场9折 + 免运费\n- 钻石会员：全场85折 + 专属客服\n\n消费满1000元自动升级为金卡会员~'
}
```

4. 点击**「保存」**

## 第六步：测试验证

### 6.1 打开预览

点击编辑器右上角的**「预览」**按钮，打开预览对话框。

### 6.2 按以下顺序测试

**测试 1：高频缓存命中**

```
输入：怎么退货
预期：直接返回退货流程说明（响应 < 1秒）
验证点：不需要等待，答案立即出现
```

**测试 2：产品咨询**

```
输入：羽绒服可以机洗吗
预期：返回产品知识库中的洗涤说明
验证点：回答基于知识库内容，没有编造信息
```

**测试 3：订单/物流查询**

```
输入：我的订单什么时候发货
预期：返回发货政策说明
验证点：回答包含"工作日16:00前下单当天发货"等信息
```

**测试 4：非客服问题（转人工）**

```
输入：今天天气怎么样
预期：收到"已为您转接人工客服"的安抚消息
验证点：意图识别为 non_service，走转人工路径
```

**测试 5：多轮对话**

```
第一轮：你们的羽绒服多少钱
第二轮：那个可以机洗吗
预期：第二轮能理解"那个"指羽绒服
验证点：结合上下文正确回答
```

### 6.3 查看节点执行结果

如果测试结果不符合预期，可以点击画布上的每个节点查看输入输出：

1. 点击节点
2. 查看右侧面板的**「输入」**和**「输出」**标签页
3. 定位问题节点

## 第七步：发布上线

### 7.1 发布对话流

1. 测试全部通过后，点击右上角**「发布」**
2. 填写版本描述（如"v1.0 初始版本"）
3. 点击**「确认发布」**

### 7.2 绑定到智能体

1. 创建或打开一个**智能体（Bot）**
2. 在智能体编排页面，添加刚发布的对话流
3. 配置智能体的基本信息（名称、头像、欢迎语等）

### 7.3 发布到渠道

在智能体发布页面，选择需要的发布渠道：

| 渠道 | 适用场景 |
|------|---------|
| API & SDK | 嵌入自有网站或 APP |
| 微信小程序 | 微信客服场景 |
| 飞书 | 飞书机器人 |
| 网页 | 嵌入网页客服窗口 |

## 常见问题排查

| 问题 | 排查步骤 |
|------|---------|
| 导入后看不到节点 | 确认使用付费套餐；刷新页面重试 |
| 知识库检索无结果 | 检查知识库是否已绑定；确认文档已解析完成；尝试降低最小匹配度到 0.3 |
| 意图识别分类错误 | 检查模型是否为豆包 Lite 7B；降低温度到 0.1；在 Prompt 中增加更多示例 |
| 回答内容编造 | 检查知识库内容是否充足；确认答案生成节点的 Prompt 中有"不编造信息"约束 |
| 转人工不生效 | 检查人工转接节点的 URL 是否正确；确认网络可达；查看节点输出中的错误信息 |
| 变量显示为空 | 检查节点连线是否正确；确认变量引用格式为 `{{节点名.字段名}}` |
| 流式输出不生效 | 确认结束节点为"返回文本"模式；确认使用的是对话流（非工作流） |
