### 关键约束（AI 必须遵守）

1. **会话变量全部为 String 类型**：Coze 平台限制，所有会话变量（guide_cnt / transfer_cnt）都是 String 类型，代码中比较前必须 `int()` 转换，输出时必须 `str()` 转换
2. **代码节点签名**：所有 Python 代码节点必须使用 `async def main(args: Args) -> Output:` 签名
3. **变量名长度限制**：Coze 会话变量名最长 20 个字符
4. **节点编号**：主流程 1-26，辅助节点 16.1（递增引导计数）
5. **模型选择策略**：分类/引导用 Lite 7B（低成本），答案生成用 Pro 32B+（高质量），答案审核用 Lite 7B+（稳定性）
6. **两大关键会话变量**：
   - `guide_cnt`：未命中引导次数，最多 1 次
   - `transfer_cnt`：找人工请求次数，第 1 次挽留，第 2 次转人工
