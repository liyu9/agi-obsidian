## 1. 主题说明

本主题围绕"如何用多智能体（Multi-Agent）协作，把一份 MRD（市场需求文档）转写成结构化 PRD（产品需求文档）"。核心问题是：

1. **角色怎么拆**？是 1 主+3 子，还是 1 主+5 子？
2. **方法论怎么沉淀**？4 步法、4 维价值评估、KANO 优先级漏斗怎么跨 Agent 一致？
3. **质量怎么保证**？100 分制质检、6 项反指标、3 级降级如何运作？
4. **怎么从 v1 演化到 v3**？单 Agent 拆分的关键决策点是什么？
