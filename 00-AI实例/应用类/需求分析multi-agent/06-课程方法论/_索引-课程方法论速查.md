- 6 列：字段 / 当前 / 目标 / 实施成本 / 风险 / 引用课程 L 课

- 表格：技能名 / 来源 L 课 / 调用条件 / 输出
- "来源 L 课" 列查本表 4 大知识域

- 文件树模板查 6.2 §7 "v3 记忆架构全景"

- 表格：检索对象 / 索引方式 / 更新频率 / 数据源
