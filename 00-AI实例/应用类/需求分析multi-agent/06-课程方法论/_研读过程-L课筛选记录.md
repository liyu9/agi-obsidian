## 5. 筛选方法说明

### 5.1 筛选维度
1. **方法论价值**（高 / 中 / 低）—— 是否提炼出可复用的设计原则
2. **v3 适用性**（高 / 中 / 低）—— 是否能直接指导 v3 架构
3. **跨场景泛化**（高 / 中 / 低）—— 是否能跨项目复用

### 5.2 入选标准（满足任一）
- **高方法论价值 + 高 v3 适用性** → 主线（如 L23/L25/L26）
- **高方法论价值 + 中 v3 适用性** → 主线（如 L34 适用性评估）
- **中方法论价值 + 高 v3 适用性** → 主线（如 L32 沙箱）

### 5.3 排除标准（满足任一）
- 纯工程操作（无方法论价值）
- 单一项目实战（不可泛化）
- 软性话题 / 源码解析

### 5.4 边界争议
- **L09**：本身是"任务调度"，但同时出现在模块二（能力）和模块四（协作）—— **6.1 + 6.3 双引用**
- **L25**：本身是"团队角色体系"，但涉及"协作行为规范"—— **6.1 主战场（如何拆）+ 6.3 引用（如何协作）**
- **L26**：本身是"任务链"，但涉及"信息传递"—— **6.3 主战场**
