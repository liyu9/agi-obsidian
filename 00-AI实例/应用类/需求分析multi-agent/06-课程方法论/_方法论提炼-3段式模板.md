# _方法论提炼 · 3 段式模板

> **本文件**：6.x 课程方法论中"关键 takeaway"的提炼方法
> **使用范围**：6.1-6.4 4 篇知识域的每条 takeaway
> **3 段式** = **课程原话**（直接引用）+ **v3 映射**（章节 / 节 / 字段）+ **实施建议**（actionable）
> **配套文档**：`_研读过程-L课筛选记录.md`（22 课主线筛选）

---

## 1. 为什么需要 3 段式

### 1.1 现状问题
- 6.x 4 篇知识域的 takeaway 写法不统一
- 有的只引用课程原话（缺 v3 映射）
- 有的只给实施建议（缺课程原话）
- 有的混合写（缺可读性）

### 1.2 3 段式的价值
- **可追溯**：每条 takeaway 都能追溯到具体 L 课原话
- **可落地**：每条 takeaway 都有具体实施建议
- **可对比**：与 v3 现状对比，明确"已有 / 缺 / 待补"

---

## 2. 3 段式模板

### 2.1 模板结构

```markdown
#### 【takeaway N】<一句话核心>

**课程原话**（LXX §X）：
> "<直接引用 L 课原文，至少 1-2 句，>20 字>"

**v3 映射**（§X.X）：
- 已有：<v3 已体现的章节 / 节 / 字段>
- 缺：<v3 未体现但课程要求的内容>
- 待补：<v3 框架有但需细化的内容>

**实施建议**（v3.X 阶段）：
- 短期（v3.0）：<1 周可做>
- 中期（v3.1）：<1 月可做>
- 长期（v3.2+）：<3 月+可做>
```

### 2.2 字段要求

| 字段 | 字数 | 必须 | 说明 |
|------|------|------|------|
| **课程原话** | 20-100 字 | ✅ | 直接引用 L 课原文，**不能改写** |
| **v3 映射** | 50-150 字 | ✅ | 三类（已有/缺/待补）各列 1-3 条 |
| **实施建议** | 30-80 字 | ✅ | 短期/中期/长期 各 1-2 条 |

### 2.3 质量标准
- ✅ 课程原话是**直接引用**（带引号 + 课号 + 章节）
- ✅ v3 映射有**章节号 / 节号 / 字段名**
- ✅ 实施建议**actionable**（含动词 + 量化）
