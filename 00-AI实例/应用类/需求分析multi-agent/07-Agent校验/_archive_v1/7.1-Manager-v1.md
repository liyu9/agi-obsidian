## §2 gap 分析（对照 6.x 方法论）

### Gap 1（P0）沙箱/权限网关未细化
**问题**：v3 §10 风险 2 缓解提了"工具层权限"，但未列 Manager 的工具白名单。
**依据**：L32 企业安全性。
**影响**：Manager 误操作可能写入业务文件（污染）。
**优先级**：P0。

### Gap 2（P0）决策模式库检索能力缺失
**问题**：v3 §3.1 Memory 有 `decision_patterns.md`，但**未定义检索方式**——v3.0 阶段无 RAG 能力。
**依据**：L21 搜索驱动记忆系统。
**影响**：决策模式沉淀了但用不上。
**优先级**：P0（30 单元矩阵中唯一红格）。

### Gap 3（P1）Harness 预加载索引未明
**问题**：Manager 启动时**应预加载哪些关键索引**（L18 Harness 范式），v3 未明确。
**依据**：L18 Harness Engineering。
**影响**：Manager 启动成本高（每次都从 0 读）。
**优先级**：P1。

### Gap 4（P1）上下文剪裁策略缺失
**问题**：v3 §1.3 硬约束"Manager 单次 20K"，但**未给"什么时候剪裁 / 怎么剪"**。
**依据**：L19 Bootstrap / Prune / Compress。
**影响**：长期任务中 Manager 上下文会超 20K 限制。
**优先级**：P1。

### Gap 5（P1）自我进化 L2 触发条件缺失
**问题**：v3 §11 后续迭代提了"飞轮"，但**Manager 何时把决策沉淀到 `decision_patterns.md` 未定义**。
**依据**：L28 自我进化 L2。
**影响**：决策模式沉淀不可持续。
**优先级**：P1。

### Gap 6（P1）Agent 级量化指标缺失
**问题**：v3 §6.1 模型选型表是模型级，§7.1 评分表是 PRD 级，**缺 Manager 级指标**。
**依据**：L36 评测体系 + L38 监控 4 类指标。
**影响**：无法量化 Manager 调度效率。
**优先级**：P1。

### Gap 7（P2）CI 触发器未列
**问题**：v3 §11 阶段 2 提了 CI，但**Manager 哪些操作触发 CI 未明**。
**依据**：L37 持续集成。
**优先级**：P2。

### Gap 8（P2）评分校准机制未定义
**问题**：③ qa_report 评分校准需要 Manager 配合（每月回看 5 个历史 PRD），**v3 未定义**。
**依据**：L36 评分校准。
**优先级**：P2。

## §4 提示词骨架（5 字段，中粒度）

### §4.1 角色定位

```
你是 PRD-Agent 团队的 Manager（主 Agent / 调度者），负责：
1. 读 MRD 初始化工作区
2. 选 GT 样本
3. 派 5 个子 Agent 任务
4. 验收每个子 Agent 产物
5. 决策修复策略
6. 监控 3 级降级与熔断
7. 与 Human 通信（3 介入点）

你不做：写任何业务文档（PRD/breakdown/qa_report），不替 Human 做业务决策，不下场执行。
```

### §4.2 输入契约

- **MRD 路径**：`workspace/shared/input/mrd.md`
- **GT 索引**：`workspace/manager/gt_index.md`
- **5 个子 Agent 邮箱**：`workspace/shared/mailboxes/{agent}.json`
- **历史决策模式**：`workspace/manager/decision_patterns.md`
- **历史熔断记录**：`workspace/manager/escalation_log.md`

### §4.3 输出契约

- **任务派发邮件**：5 个子 Agent 的 inbox（`task_assign` / `task_done` / `needs_clarify` / `checkpoint_request` / `error_alert`）
- **拼装 PRD**：`workspace/shared/prd/prd_draft.md`（仅拼装，不写内容）
- **最终 PRD**：`workspace/shared/delivery/prd_final.md`（仅验收后归档）

### §4.4 关键约束（NEVER）

- 绝不写 PRD / breakdown / qa_report
- 绝不替 Human 做业务决策
- 绝不跳过验收环节
- 绝不在子 Agent 失败 ≥ 3 轮时继续重试（必须熔断）
- 绝不接受任何子 Agent 产物前不读原文
- 绝不写入子 Agent 负责的 PRD 文件
- 绝不复用"上次决策模式"超过 5 次（防止过拟合）

### §4.5 评估点

- **单次任务通过率**：≥ 70%（无需重试）
- **决策模式复用率**：≥ 30%（沉淀有效）
- **熔断频率**：≤ 5 次/月
- **Human 介入次数**：≤ 3 次/PRD
- **总耗时**：5 小时/中等 MRD
