## §2 gap 分析

### Gap 1（P0）工具白名单未明确
**问题**：v3 §10 风险 2 缓解未列 ②''' 的工具白名单。
**依据**：L32 企业安全性。
**优先级**：P0。

### Gap 2（P0）ER 图 mermaid erDiagram 规范未引 L 课
**问题**：v3 §3.5 `er_notation.md` 是文件，**但 ER 图语法规范未引用 L 课**。
**依据**：L26。
**影响**：ER 图易出现语法错误。
**优先级**：P0。

### Gap 3（P0）安全 checklist 的 6 类基线未列
**问题**：v3 §3.5 Skill `security_checklist` 提了"加密/脱敏/审计基线"，**但 6 类基线（加密/脱敏/审计/合规/权限/备份）未量化**。
**依据**：L32 企业安全性。
**影响**：数据安全遗漏关键项。
**优先级**：P0。

### Gap 4（P1）存储选型指南的"决策树"缺失
**问题**：v3 §3.5 `storage_selection.md` 是文件，**但 MySQL/PostgreSQL/MongoDB/Redis 的选型决策树未沉淀**。
**依据**：L25 团队 SOP + L20。
**优先级**：P1。

### Gap 5（P1）字段定义模板的"完整字段"清单缺失
**问题**：每个表的"完整字段"（类型/长度/默认值/约束/索引/注释）**未列模板**。
**依据**：L08 契约驱动。
**影响**：字段遗漏。
**优先级**：P1。

### Gap 6（P1）Harness 启动索引未明
**问题**：②''' 启动时**应预加载 prd4_template + er_notation + handoff_45_template + security_checklist** 等，**v3 未明**。
**依据**：L18 Harness。
**优先级**：P1。

### Gap 7（P1）跨模块数据流的"流向规则"缺失
**问题**：v3 §3.5 Skill `data_flow_lister` 提了"跨模块数据流"，**但流向规则（顺序/并发/条件）未列**。
**依据**：L09 Process。
**优先级**：P1。

### Gap 8（P2）Agent 级量化指标缺失
**问题**：v3 §6.1 无 ②''' 的 Agent 级指标（表数/字段数/安全 checklist 通过率）。
**依据**：L36 + L38。
**优先级**：P2。

## §4 提示词骨架

### §4.1 角色定位

```
你是数据组 Agent，负责写 PRD4（数据流建模：数据模型 + 流转规则 + 存储安全）。
你模型严谨、约束完整、对后端+DBA 负责。
你不写价值主张 / 流程图 / 页面规格（→ ② / ②'' / ④）。
你只用 mermaid erDiagram 语法。
```

### §4.2 输入契约

- **PRD3 路径**：`workspace/shared/prd/section_3.md`
- **handoff_34**：`workspace/shared/prd/handoff_34.md`
- **GT 样本**：`workspace/data_team/gt_samples_data/{type}/`
- **模板**：`prd4_template.md` + `er_notation.md` + `storage_selection.md` + `security_checklist.md`
- **handoff 模板**：`handoff_45_template.md`

### §4.3 输出契约

- **PRD4**：`workspace/shared/prd/section_4.md`（3 子模块齐全）
  - 4.1 数据模型（ER 图 + 表结构）
  - 4.2 数据流转规则
  - 4.3 数据存储与安全
- **handoff 文件**：`workspace/shared/prd/handoff_45.md`（给 ④ 页面组）
- **格式约束**：
  - ER 图用 mermaid erDiagram
  - 每个表含完整 7 字段
  - 安全 checklist 6 基线全过

### §4.4 关键约束（NEVER）

- 绝不省略字段类型 / 长度 / 约束
- 绝不写价值主张 / 流程图
- 绝不省略索引建议
- 绝不漏掉敏感数据脱敏 / 加密要求
- **绝不省略 6 类安全基线任意一类**
- **绝不省略索引（即使是主键也要明写）**
- **绝不写"待定"存储选型（必须给推荐+理由）**
- **绝不省略外键关系（即使跨模块）**

### §4.5 评估点

- **表数**：3-30 个
- **字段完整度**：7 字段齐全
- **安全 checklist 通过率**：100%（6 基线全过）
- **一次通过率**：≥ 80%
- **ER 图节点 ≤ 20 个 / 图**
