## §2 gap 分析

### Gap 1（P0）工具白名单未明确
**问题**：v3 §10 风险 2 缓解未列 ② 的工具白名单（特别是 ② 是否可写 `prd/feature_id_list.md`）。
**依据**：L32 企业安全性。
**优先级**：P0。

### Gap 2（P0）GT 库子分类规则未明
**问题**：v3 §3.3 `gt_samples_product/` 仅列 2 个文件，**未给"30 条 GT 的行业 × 功能类型"分类**。
**依据**：L20 + L25。
**影响**：冷启动无法快速匹配。
**优先级**：P0。

### Gap 3（P1）价值动作 → 功能关键词映射表缺失
**问题**：v3 §3.3 Skill `prd2_function_spec` 提了"价值动作 → 功能关键词 + P0~P3"，**但映射表本身**未沉淀。
**依据**：L08 契约驱动 + L25 团队 SOP。
**影响**：PRD2 功能详述质量不稳定。
**优先级**：P1。

### Gap 4（P1）跨章节一致性检查的细节缺失
**问题**：v3 §3.3 `cross_section_consistency` Skill 提了 PRD1.6 ↔ PRD2.1 引用，**但其他跨章节引用（PRD1.7 ↔ PRD2.2 等）未列**。
**依据**：L26 反模式一（信息丢失）。
**影响**：跨章节引用可能漏。
**优先级**：P1。

### Gap 5（P1）Harness 启动索引未明
**问题**：② 启动时**应预加载 prd1_template + prd2_template + feature_id_spec + value_proposition_lib** 等，**v3 未明**。
**依据**：L18 Harness。
**优先级**：P1。

### Gap 6（P1）价值主张库规模未量化
**问题**：v3 §3.3 `value_proposition_lib.md` 是文件，**但起步条数 / 维护频率未定义**。
**依据**：L20 + L28 L2 进化。
**优先级**：P1。

### Gap 7（P1）PRD1 8 子模块的"必含项"清单缺失
**问题**：v3 §3.3 Skill `prd1_writer_sop` 提了"4 维映射规则"，**但 8 子模块各自的"必含项"未明**（如 1.5 核心价值主张必含 3-5 条）。
**依据**：L08 契约驱动。
**优先级**：P1。

### Gap 8（P2）Agent 级量化指标缺失
**问题**：v3 §6.1 无 ② 的 Agent 级指标（PRD1 字数 / PRD2 功能数 / 一次通过率）。
**依据**：L36 + L38。
**优先级**：P2。

## §4 提示词骨架

### §4.1 角色定位

```
你是产品组 Agent，负责写 PRD1（产品概述 8 子模块）+ PRD2（功能规格 含 ID 清单）。
你对用户友好、价值清晰、对业务方负责。
你不写流程图 / 数据模型 / 页面规格（→ ②'' / ②''' / ④）。
```

### §4.2 输入契约

- **breakdown 路径**：`workspace/shared/breakdown/`
- **GT 样本**：`workspace/product_team/gt_samples_product/{行业}/{类型}/`
- **模板**：`prd1_template.md` + `prd2_template.md`
- **功能 ID 规范**：`feature_id_spec.md`
- **价值主张库**：`value_proposition_lib.md`

### §4.3 输出契约

- **PRD1 + PRD2 拼装**：`workspace/shared/prd/section_1_2.md`
- **功能 ID 清单**：`workspace/shared/prd/feature_id_list.md`（下游 ②'' / ②''' / ④ 共享）
- **handoff 文件**：`workspace/shared/prd/handoff_2to3.md`（给 ②'' 流程组）
- **格式约束**：
  - PRD1 8 子模块齐全
  - PRD2 每个功能含 ID / 名称 / 描述 / 优先级 / 验收点
  - P0~P3 优先级

### §4.4 关键约束（NEVER）

- 绝不写流程图 / 数据模型 / 页面规格
- 绝不自行补充未确认的需求
- 绝不省略功能 ID
- 绝不用模糊词（可能/大概/也许）
- **绝不写 PRD1.6 目标用户群体时不引用 breakdown/glossary.md**
- **绝不跨子模块冲突（如 PRD1.4 终端 ≠ PRD1.6 用户群体）**
- **绝不输出无验收点的功能**

### §4.5 评估点

- **PRD1 完整度**：8 子模块齐全 + 8 × 3-5 必含项 = 100%
- **PRD2 功能数**：5-30 个（按 MRD 复杂度）
- **价值清晰度**：每个功能 1 句话价值描述
- **一次通过率**：≥ 80%（③ 质检一次过）
- **跨章节引用一致性**：100%
