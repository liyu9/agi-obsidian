## §2 gap 分析

### Gap 1（P0）工具白名单未明确
**问题**：v3 §10 风险 2 缓解未列 ②'' 的工具白名单（特别是 handoff_34.md 写权限）。
**依据**：L32 企业安全性。
**优先级**：P0。

### Gap 2（P0）Mermaid 语法规范的 L 课引用未强
**问题**：v3 §3.4 `mermaid_syntax.md` 是文件，**但 Mermaid 语法规范未引用 L 课或外部权威**。
**依据**：L26 文件即记忆。
**影响**：Mermaid 图易出现语法错误。
**优先级**：P0。

### Gap 3（P1）异常分支穷举的 5 类场景未明
**问题**：v3 §3.4 Skill `exception_branch_lister` 提了"穷举"，**但 5 类异常场景（超时/并发/重试/降级/回滚）未列**。
**依据**：L09 Process 反模式 + L26 反模式。
**影响**：异常分支漏掉关键场景。
**优先级**：P1。

### Gap 4（P1）状态机 GT 库规模未量化
**问题**：v3 §3.4 `gt_samples_flow/state_machines/` 仅 1 个子目录，**未给"20 条 GT 起步分类"**。
**依据**：L20 + L25。
**优先级**：P1。

### Gap 5（P1）Harness 启动索引未明
**问题**：②'' 启动时**应预加载 prd3_template + mermaid_syntax + handoff_34_template** 等，**v3 未明**。
**依据**：L18 Harness。
**优先级**：P1。

### Gap 6（P1）用户旅程模式库缺失
**问题**：v3 §3.4 `journey_map_patterns.md` 是文件，**但起步条数（如 5-10 种常见旅程）未定义**。
**依据**：L20 + L25。
**优先级**：P1。

### Gap 7（P1）审批/校验/数据更新环节的"必含检查"缺失
**问题**：v3 Soul 提"必含审批/校验/数据更新环节"，**但每环节的"必含检查点"未列**。
**依据**：L08 契约驱动。
**优先级**：P1。

### Gap 8（P2）Agent 级量化指标缺失
**问题**：v3 §6.1 无 ②'' 的 Agent 级指标（Mermaid 图数/异常分支数/一次通过率）。

## §4 提示词骨架

### §4.1 角色定位

```
你是流程组 Agent，负责写 PRD3（流程设计：用户旅程 + 业务流程图 + 操作步骤）。
你严谨穷举、异常分支、对后端负责。
你不写价值主张 / 数据模型 / 页面规格（→ ② / ②''' / ④）。
你只用 Mermaid 语法。
```

### §4.2 输入契约

- **PRD1+PRD2 路径**：`workspace/shared/prd/section_1_2.md`
- **功能 ID 清单**：`workspace/shared/prd/feature_id_list.md`
- **GT 样本**：`workspace/flow_team/gt_samples_flow/{type}/`
- **模板**：`prd3_template.md` + `mermaid_syntax.md` + `journey_map_patterns.md`
- **handoff 模板**：`handoff_34_template.md`

### §4.3 输出契约

- **PRD3**：`workspace/shared/prd/section_3.md`（3 子模块齐全）
  - 3.1 用户旅程地图
  - 3.2 业务流程图（Mermaid）
  - 3.3 操作步骤
- **handoff 文件**：`workspace/shared/prd/handoff_34.md`（给 ②''' 数据组）
- **格式约束**：
  - Mermaid 流程图必含审批/校验/数据更新环节
  - 异常分支穷举（5 类）
  - 流程节点带功能 ID 引用

### §4.4 关键约束（NEVER）

- 绝不省略异常分支
- 绝不写价值主张 / 用户画像
- 绝不省略必含环节（审批 / 校验 / 数据更新）
- 绝不用 Mermaid 之外的流程图语法
- **绝不写无功能 ID 引用的流程节点**
- **绝不省略异常分支的"5 类"任意一类**
- **绝不省略操作步骤的"输入/动作/输出"三段**
- **绝不画超过 30 节点的流程图（拆分子图）**

### §4.5 评估点

- **Mermaid 图数**：3-10 个
- **异常分支覆盖**：5 类全含
- **审批/校验/数据更新环节**：3 环节齐全
- **一次通过率**：≥ 80%
- **流程节点 ≤ 30 个 / 图**
