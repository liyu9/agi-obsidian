## 四、八节内容速览

### 4.1 需求建模

**核心问题**：如何把业务需求翻译成 Agent 可执行的任务？

**核心方法**：
- Agent 任务 5 要素（输入/输出/工具/状态/终止条件）
- 需求建模 5 步法（识别目标 → 拆解任务 → 明确要素 → 定义协议 → 画流图）
- 需求文档 6 段结构
- 3 个反模式（太抽象 / 100% 复制传统 PRD / 跳过任务流图）

**主素材**：L10 + L11 + L12

### 4.2 边界与护栏

**核心问题**：AI 产品的"不可越界"如何设计？

**核心方法**：
- 边界三问（能力 / 数据 / 操作）
- 三道护栏（输入 / 过程 / 输出）
- 5 类错误降级策略
- 5 类角色权限矩阵（最小权限原则）
- 3 层审计日志

**主素材**：L15 + L16 + L17 + L18 + L19

### 4.3 上下文与提示词

**核心问题**：如何让 AI 理解任务、记住对话、按规则做？

**核心方法**：
- 3 类上下文 + 窗口管理策略
- 提示词 4 层结构（角色 / 任务 / 规则 / 示例）
- 5 个常见错误 + Few-shot / CoT 设计
- 提示词版本管理 5 维度

**主素材**：L20 + L21 + L22 + L23 + L24

### 4.4 规划与执行

**核心问题**：如何让 AI 学会自己拆解任务、按计划做、从错误中学习？

**核心方法**：
- 规划 3 个层次（任务级 / 步骤级 / 操作级）
- 3 种执行模式（顺序 / 并行 / 条件）
- 反思 3 个层次（结果自检 / 过程回溯 / 策略调整）
- ReAct vs Plan-and-Execute 选择指南

**主素材**：L25 + L26 + L27 + L28 + L29

### 4.5 工具与能力

**核心问题**：如何让 AI 操作外部世界的"手和脚"？

**核心方法**：
- Function Calling 4 个核心机制
- 工具描述 4 字段（命名 / 描述 / 参数 / 返回值）
- 3 个设计原则（必要性 / 最小权限 / 可控性）
- 工具编排引擎（DAG / 工作流）
- 工具安全 4 道防线

**主素材**：L30 + L31 + L32 + L33 + L34

### 4.6 记忆机制

**核心问题**：如何让 AI 拥有"短期 / 长期 / 工作 / 知识库"四类记忆？

**核心方法**：
- 4 类记忆对比（短期 / 工作 / 长期 / 知识库）
- 4 类记忆的典型场景
- 记忆管理 3 时机（写入 / 读取 / 清理）
- 4 个反模式（无短期 / 无工作 / 无长期 / 无知识库）

**主素材**：L35 + L36 + L37 + L38 + L39

### 4.7 评估体系

**核心问题**：如何让 AI 效果"可量化、可对比、可监控"？

**核心方法**：
- 4 层评估体系（离线 / 在线 / A/B / 业务翻译）
- 在线监测 6 维度核心指标
- A/B 测试 4 步流程
- AI 效果 → 业务价值翻译公式

**主素材**：L40 + L41 + L42 + L43 + L44

### 4.8 部署、可观测与商业化

**核心问题**：AI 产品的"上线三件套"如何准备？

## 五、八节内容之间的逻辑关系

八节之间是"需求 → 设计 → 实现 → 上线"的端到端流程：

```
4.1 需求建模（开始：业务话 → 任务）
   ↓
4.2 边界与护栏（约束：能做什么 + 怎么做）
   ↓
4.3 上下文与提示词（细节：怎么对话）
   ↓
4.4 规划与执行（流程：怎么拆解 + 执行）
   ↓
4.5 工具与能力（扩展：操作外部）
   ↓
4.6 记忆机制（持续：记住什么）
   ↓
4.7 评估体系（度量：怎么判断好坏）
   ↓
4.8 部署、可观测与商业化（结束：怎么上线 + 怎么算账）
```

PM 在做 AI 项目时应按这个顺序建立能力体系。

## 六、使用建议

### 6.1 适合什么人读

- **AI 产品的 PM / 产品设计师**：要设计具体的 AI 功能
- **AI 项目的架构师 / 工程师**：要实现具体的 AI 系统
- **AI 项目的测试 / 评估人员**：要建立评估体系
- **AI 项目的运营 / 商业化人员**：要落地商业化方案

### 6.2 怎么读

1. **第一遍**：按 4.1 → 4.8 的顺序通读，建立端到端认知
2. **第二遍**：针对一个具体 AI 功能，对照 8 节设计该功能
3. **第三遍**：把 8 节作为"工具书"按需查阅

### 6.3 与其他章节的衔接

- **第三/四章** 假定 PM 已经掌握第一章的"基础认知"和第二章的"决策框架"
- **本章** 是"通用设计全流程"，适用于所有形态的 AI 项目
- **第五章 Multi-Agent** 假定 PM 已掌握本章的"单 Agent 设计方法"，扩展到多 Agent
- **第六章组织进化** 假定 PM 已掌握本章的"AI 设计 + 上线"全流程，进入"组织级"思考
