# 4.8 部署、可观测与商业化：AI 产品的"上线三件套"

> **核心结论**：部署 + 可观测 + 商业化 = AI 上线的三件套——少了任何一件都难以为继。
> **判断铁律**：上线前必过部署清单，上线后必有过可观测仪表盘，运营前必有商业化方案。
> **底线思维**：没想好商业化就上线的 AI 项目 = 烧钱无底洞。

## 一、为什么部署、可观测、商业化是"三件套"

很多 AI 项目死在"最后一公里"——Demo 跑得通，上了生产环境就崩。PM 必须把"上线"看作三件事：

| 维度 | 解决什么 |
|------|---------|
| **部署** | 让 AI 从"开发机"走到"生产环境" |
| **可观测** | 让 AI 运行过程透明，故障可定位 |
| **商业化** | 让 AI 项目"算得过来账"，可持续运营 |

## 二、部署：从 Demo 到生产环境

### 2.1 部署的 4 个阶段

| 阶段 | 含义 | 流量比例 |
|------|------|---------|
| **开发** | 在开发机跑通 | 0% |
| **内测** | 内部员工使用 | 1-5% |
| **灰度** | 小部分真实用户 | 5-20% |
| **全量** | 全部用户 | 100% |

**关键原则**：每阶段必过评估才能进下一阶段。**不可跳级**。

### 2.2 部署清单

| 检查项 | 内容 |
|--------|------|
| **环境一致** | 开发、测试、生产环境配置一致 |
| **资源充足** | GPU / 内存 / 网络 / 存储足够 |
| **灾备方案** | 主备切换 / 多 AZ 部署 |
| **灰度策略** | 流量切分方案（按用户/按请求） |
| **回滚方案** | 5 分钟内能回滚到上一版 |
| **监控告警** | 关键指标异常时自动告警 |

反面案例：某 AI 跳过了灰度直接全量上线，1 小时后服务过载，1 万用户受影响。根因是"无灰度策略"。

## 三、可观测：让 AI 运行透明

### 3.1 3 层可观测

| 层 | 监控内容 | 工具 |
|----|---------|------|
| **基础设施层** | CPU / GPU / 内存 / 网络 | Prometheus + Grafana |
| **服务层** | API 响应时间 / 错误率 / QPS | APM（SkyWalking / Jaeger） |
| **业务层** | AI 任务完成率 / Token 消耗 / 用户反馈 | 自研 + ELK |

### 3.2 AI 特有的可观测

| 维度 | 监控内容 |
|------|---------|
| **推理质量** | 任务完成率、一次解决率 |
| **Token 消耗** | 单任务 Token、累计 Token、单用户 Token |
| **工具调用** | 调用次数、成功率、平均耗时 |
| **用户反馈** | 👍/👎 比例、CSAT 评分 |
| **业务指标** | 节省人工、转化率、错误率 |

### 3.3 可观测的 3 个反模式

| 反模式 | 表现 | 应对 |
|-------|------|------|
| **只看基础设施** | 只看 CPU 内存 | 必须 3 层全看 |
| **告警风暴** | 告警太多没人看 | 关键告警 + 抑制 |
| **日志无结构** | 出问题无法定位 | 结构化日志 + trace ID |

## 四、商业化：让 AI 项目"算得过来账"

### 4.1 AI 商业化的 4 种模式

| 模式 | 适用 | 定价 |
|------|------|------|
| **SaaS 订阅** | 标准化 AI 产品 | 月费 / 年费 / 按席位 |
| **按量付费** | Token 计费 / 调用次数 | 单价 × 用量 |
| **私有化部署** | 大型企业 | 一次性 + 维护费 |
| **增值服务** | AI + 人工 | AI 部分 + 人工服务费 |

### 4.2 商业化的 4 个关键计算

| 计算 | 公式 |
|------|------|
| **单任务成本** | Token 成本 + 算力成本 + 人力分摊 |
| **客户付费** | 月费 / 年费 / 调用单价 |
| **毛利** | 客户付费 - 单任务成本 |
| **回收期** | 投入 / 月毛利 |

反面案例：某 AI 项目每单任务成本 1 元，定价 0.5 元/单。看似有客户，但"越用越亏"，3 个月后停服。

### 4.3 商业化的 3 个反模式

| 反模式 | 表现 | 应对 |
|-------|------|------|
| **免费推广** | 烧钱拉客 | 必走付费转化测试 |
| **不看成本** | 不算 Token 消耗 | 必算单任务成本 |
| **大客户陷阱** | 1 个大客户占 80% 收入 | 必分散客户结构 |

## 五、PM 行动清单

看完本节后：

1. **每个 AI 功能必走 4 阶段部署**：开发 → 内测 → 灰度 → 全量
2. **上线前必过部署清单**：6 项检查
3. **可观测必过 3 层**：基础设施 / 服务 / 业务
4. **商业化必过 4 个计算**：单任务成本 / 客户付费 / 毛利 / 回收期
5. **AI 项目必算账**：不算账的项目不要启动
