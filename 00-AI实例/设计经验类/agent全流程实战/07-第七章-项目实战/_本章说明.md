## 使用建议

按 **递进式学习** 路径阅读：

1. **先读 7.1 小红书爆款笔记** — 体验一个最小完整的 Agent 实战，理解 Prompt + 多模态 + 单 Agent 工具链的协作范式，建立"端到端可跑通"的感觉。

2. **再读 7.2 / 7.3 XiaoPaw 能力篇 / 记忆篇** — 看一个企业级助手如何把"能力"和"记忆"两件事做到位：
   - 7.2 重点是**能力（Tools/MCP/Skills）**——让 Agent 能动手操作真实系统。
   - 7.3 重点是**记忆（Memory/上下文工程）**——让 Agent 越用越懂用户。
   - 这两篇对应第四章 4.5 工具与能力、4.6 记忆机制。

3. **最后读 7.4 Agent 小队** — 看单个 Agent 如何扩展为团队：Orchestrator + 角色分工 + 任务链 + 人类介入点，对应第五章 Multi-Agent 范式。
