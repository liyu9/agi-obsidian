# 1.1 四种基础形态

> **本章定位**：方法论第 1 部分"认知奠基"中的四种基础形态——**单 Prompt / Workflow / Single-Agent / Multi-Agent**。这是 PM 设计 Agent 之前必须明确的第一性问题。

## 学习目标
- 能清楚区分"接了 LLM 聊天"与"真正的 Agent"的本质差别
- 能用一句话判断一个 AI 应用属于四种形态中的哪一类
- 理解为什么 PM 不能跳过形态认知直接谈 Agent 设计
