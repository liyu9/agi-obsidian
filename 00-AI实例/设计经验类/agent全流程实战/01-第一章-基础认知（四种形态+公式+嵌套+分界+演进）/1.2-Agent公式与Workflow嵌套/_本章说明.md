# 1.2 Agent 公式与 Workflow 嵌套

> **本章定位**：方法论第 1 部分"认知奠基"中的 Agent 经典公式（Lilian Weng 公式）以及 **Agent 与 Workflow 相互嵌套**的关系。这是 Coze/Dify 等平台设计 Agent 的核心认知。

## 学习目标
- 能准确写出 Agent = LLM + Planning + Memory + Tool Use 的公式
- 能用示意图展示 Agent ⊃ Workflow / Workflow ⊃ Agent / Multi-Agent 编排三种嵌套
- 理解为什么"Agent 内部可以跑 Workflow，Workflow 内部又可以嵌入 Agent"
- 能在 Coze/Dify 上找到对应的节点类型
