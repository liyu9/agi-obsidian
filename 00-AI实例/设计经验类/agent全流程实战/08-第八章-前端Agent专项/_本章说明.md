# 第八章 前端 Agent 专项

## 一、章节定位

**回答 PM 在前端场景下遇到的"前端 Agent 怎么搭、怎么编排、怎么用工具、怎么交付"四大问题。**

第二至六章奠定了"通用 Agent 怎么搭"的方法论基础。第八章把视角从"通用后端架构"拉回到"浏览器侧 + 前端工程师"——这是企业级 Agent 走向 C 端用户、走向端侧 AI 不可绕开的一环。

前端 Agent 有 4 个不可回避的现实：

1. **网络边界 + CORS**——API Key 不能进浏览器，必须 BFF 中转
2. **流式优先**——大模型推理以秒计，必须 SSE / Fetch ReadableStream
3. **JSON 封闭性**——模型输出是封闭结构，与流式渲染天然矛盾
4. **端侧能力**——Transformers.js 让 AI 推理在浏览器内发生，前端第一次拥有"端侧 AI"

跳过这 4 个现实去做"前端 AI 应用"，结果必然是"后端能跑、前端卡死"。

## 五、四节内容之间的逻辑关系

四节之间是从"调用 → 编排 → 增强 → 交付"的递进关系：

```

   ↓

   ↓
```

**关键逻辑**：
- 8.1 是"调用"——前端如何把 LLM API 跑起来

- 8.3 是"增强"——让 Agent 拥有工具调用 + 知识更新能力
- 8.4 是"交付"——Vibe Coding 提效 + 私有化部署 + 端侧运行

PM 推动前端 Agent 项目时，按 8.1 → 8.2 → 8.3 → 8.4 顺序走完四节。**任一环节跳过，前端 Agent 都跑不通**。
