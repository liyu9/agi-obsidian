# Prompt工程




## Prompt能力是AI产品经理核心技能




> 来源：课程2

AI产品经理需要掌握的Prompt三大核心能力：

| 能力 | 说明 |
|------|------|
| 大语言模型生成原理 | 理解模型如何从输入生成输出 |
| 高质量Prompt编写 | 掌握结构化、任务导向的Prompt设计方法 |
| COT思维链 | Chain of Thought，引导模型分步推理 |

## 为什么产品经理要学Prompt设计




> 来源：课程5第十三章

Prompt设计直接影响AI的**执行力**、**用户体验**和**产品智能化水平**。

Prompt思维是每个产品经理的**必备技能**，需要从以下角度设计清晰的任务目标：

- **任务拆解**：将复杂任务分解为可执行的子步骤
- **信息提炼**：提取关键信息作为Prompt的输入
- **上下文管理**：管理对话历史和背景信息

## Prompt设计与普通提示词的区别




| 维度 | 普通提示词 | Prompt设计 |
|------|-----------|------------|
| 目的 | 快速获得回答 | 系统化任务设计 |
| 复杂性 | 简单直接 | 涉及业务拆解、上下文管理 |
| 控制 | 不关心生成过程 | 通过结构化设计控制AI行为 |

## Prompt基本结构三大要素




```
┌─────────────────────────────┐
│       Prompt基本结构          │
├─────────────────────────────┤
│ 1. 目标任务                  │
│    → 希望AI做什么            │
│                             │
│ 2. 输入数据                  │
│    → 给AI的材料              │
│                             │
│ 3. 输出格式                  │
│    → 希望AI怎样呈现结果       │
└─────────────────────────────┘
```

| 要素 | 说明 | 示例 |
|------|------|------|
| 目标任务 | 希望AI做什么 | "请分析以下用户反馈的情感倾向" |
| 输入数据 | 给AI的材料 | 用户评论文本、产品参数表 |
| 输出格式 | 希望AI怎样呈现结果 | JSON格式、表格、分级评分 |

## 设计高效Prompt核心原则




| 原则 | 说明 |
|------|------|
| 明确任务目标 | 清晰描述期望AI完成的任务，避免模糊表述 |
| 简洁和可操作性 | 用最少的文字传达最精确的指令 |
| 避免引导性偏差 | 不在Prompt中暗示期望的答案方向 |

## 多轮Prompt设计




分阶段设计，把对话设计成小任务。

**案例：智能客服——用户账户被冻结**

```
第一轮：获取账户ID
  用户：我的账户被冻结了
  Prompt策略：引导用户提供账户ID

第二轮：查找冻结原因
  输入：账户ID
  Prompt策略：查询系统获取冻结原因

第三轮：给出操作建议
  输入：冻结原因
  Prompt策略：根据原因生成对应的解冻指引
```

## 模块化Prompt设计




将复杂任务拆解为小的**可重复模块**。

### 优势




| 优势 | 说明 |
|------|------|
| 提升复用性 | 相同模块可在不同场景中重复使用 |
| 提高灵活性 | 可自由组合模块应对不同需求 |
| 降低复杂性 | 每个模块职责单一，便于维护和优化 |

### 可复用模板示例




| 模块 | 功能 | 触发条件 |
|------|------|----------|
| 查询订单模块 | 根据订单号查询物流状态 | 用户询问订单相关 |
| 解决问题模块 | 诊断问题并给出解决方案 | 用户反馈问题或异常 |
| 产品推荐模块 | 根据用户偏好推荐产品 | 用户表达购买意向 |

## 案例：智能推荐系统多轮Prompt




```
第一轮：信息收集
  → 了解用户基本需求和预算

第二轮：确认偏好
  → 明确品牌、风格、功能偏好

第三轮：选择类别
  → 缩小到具体产品类别

第四轮：给出推荐

  → 结合以上信息生成个性化推荐列表
```

## 补充：极客时间课程

### Temperature参数控制
来自06课程第5讲。Temperature控制大模型输出的创造性和确定性平衡。低Temperature=更确定但缺乏创意，高Temperature=更有创意但可能偏离主题。产品经理需要根据场景设置：客服场景用低Temperature（0.3以下），创意生成用高Temperature（0.7以上）。

### Prompt作为应用开发核心
来自06课程。编写提示词=对大模型的进一步训练。从第一个提示词开始就在打造专属大模型。zero-shot/one-shot/few-shot小样本学习是提示工程基础。
