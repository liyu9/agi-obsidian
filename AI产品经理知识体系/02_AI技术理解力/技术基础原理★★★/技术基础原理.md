# 技术基础原理




## AI产品三要素




> 来源：课程2

| 要素 | 说明 | 示例 |
|------|------|------|
| 数据 | AI的"原材料"，决定模型上限 | 用户行为数据、交易数据、社交数据、传感器数据 |
| 算法 | AI的"加工方法"，决定如何从数据中学习 | 机器视觉、滤波、特征提取、协同过滤 |
| 算力 | AI的"动力来源"，决定训练和推理效率 | CPU + GPU |

## AI四层架构




> 来源：课程7

```
创造智能  ← 最高层：AI具备创造性输出能力
   ↑
认知智能  ← 理解、推理、决策能力
   ↑
感知智能  ← 看、听、触等感知能力（语音识别、图像识别）
   ↑
运算智能  ← 基础层：快速计算与存储能力
```

## AI三大基石




用烹饪做类比：

| 基石 | 类比 | 含义 |
|------|------|------|
| 数据 | 食材 | 没有好数据就没有好模型 |
| 算力 | 燃气/火候 | 决定处理能力和速度 |
| 算法 | 烹饪水平 | 决定如何利用数据和算力产出结果 |

## Transformer架构




> 来源：课程2

Transformer是一种**统一架构**，可处理CV、NLP、强化学习、语音、翻译、图数据等多种任务。

```
┌─────────────────────────────────────────────┐
│                  输出部分                      │
│         线性层 + Softmax → 概率分布             │
├─────────────────────────────────────────────┤
│                  解码器                        │
│  Masked多头注意力 → 编解码注意力 → 前馈网络      │
│  + 规范化 + 残差连接                            │
├─────────────────────────────────────────────┤
│                  编码器                        │
│  多头注意力 → 规范化 → 残差连接 → 前馈全连接      │
├─────────────────────────────────────────────┤
│                  输入部分                      │
│         文本嵌入 + 位置编码                     │
└─────────────────────────────────────────────┘
```

### Transformer核心组件说明




| 组件 | 作用 |
|------|------|
| 输入部分 | 文本嵌入（Token Embedding）+ 位置编码（Positional Encoding） |
| 编码器 | 多头注意力 + 规范化 + 残差连接 + 前馈全连接层 |
| 解码器 | Masked多头注意力 + 编解码注意力 + 前馈 + 规范 + 残差 |
| 输出部分 | 线性层 + Softmax 生成概率分布 |

## GPT vs BERT vs T5




| 模型 | 使用架构 | 擅长任务 | 特点 |
|------|----------|----------|------|
| GPT | Decoder | 文本生成 | 自回归生成，逐token预测 |
| BERT | Encoder | 文本分类 | 双向编码，理解上下文语义 |
| T5 | Encoder + Decoder | 多种任务 | 文本到文本统一框架 |

## 不懂技术可能遇到的问题




| 问题类型 | 具体表现 |
|----------|----------|
| 沟通障碍 | 与算法工程师沟通专业度不足，无法有效传达需求 |
| 评估困难 | 无法评价技术实现难度，容易给出不合理的排期 |
| 算力盲区 | 不懂算力容易被"卡脖子"，无法合理规划资源 |
| 文档缺失 | 无法撰写专业的AI产品规划文档 |
