# 标注手册




> 来源：三节课AI知识库课程内容整理

## 一、数据标注在AI产品中的重要性




> 来自课程7（人工智能产品经理进阶提升）

数据处理是AI产品区别于传统产品的核心环节，数据标注的质量直接决定模型的效果。

**AI的核心法则**：

> **AI的上限由数据的上限决定**
> 有什么样的数据，就能做出什么样水平的模型

## 二、数据标注的5个步骤




> 来自课程7

```
业务理解 → 确定原始数据 → 标注标准 → 标注过程 → 结果验收
```

| 步骤 | 说明 |
|------|------|
| **业务理解** | 理解业务需求和数据背景 |
| **确定原始数据** | 选择需要标注的数据源 |
| **标注标准** | 制定明确的标注规范和标准文档 |
| **标注过程** | 执行标注工作 |
| **结果验收** | 验证标注数据的质量 |

## 三、数据标注的4个角色




> 来自课程7

| 角色 | 职责 | 说明 |
|------|------|------|
| **产品经理** | 定义标注标准、协调资源 | 负责标注标准的制定和整体协调 |
| **算法工程师** | 技术验证 | 确保标注数据能被算法使用 |
| **行业专家** | 边界样本判定 | 处理高难度/边界情况的样本 |
| **标注人员** | 执行标注 | 按照标注标准执行具体标注工作 |

> 专家示例：医学影像标注中的高年资医生，负责处理普通医生难以判断的边界影像

## 四、标注手册核心内容




> 来自课程7

### 1. 标注标准



- 明确的标注规则和定义
- 减少主观判断
- 标注示例（正例和反例）

### 2. 标注流程



- 数据分发方式
- 标注工具使用说明
- 标注质量控制点

### 3. 验收标准



- 质量检查机制
- 抽检比例和规则
- 不合格数据的处理方式

## 五、标注质量控制




> 来自课程7

- 标注标准必须清晰明确，减少主观判断
- 建立标注验收机制
- 专家定期抽查标注质量
- 标注过程需不断迭代优化标准

## 七、数据处理关键步骤




> 来自课程7

| 步骤 | 说明 | 关键点 |
|------|------|--------|
| **数据定义** | 明确输入数据是什么，预测目标是什么 | 确定数据量和问题类型（分类/排序等） |
| **数据切分** | 训练集/验证集/测试集的划分 | 通常比例：60%/20%/20% |
| **数据标注** | 人工标注训练数据 | 涉及大量成本 |
| **数据归一化** | 将数据统一到相同尺度 | 提高训练稳定性 |

## 八、微调数据设计




> 来自课程3（工作流重塑与能力跃迁）

产品经理在微调中的数据设计职责：

- 设计对应的微调数据范围跟质量标准
- 输出标注任务的说明，包括标签体系、数据格式、案例等
- 交给数据团队去执行

**微调的通俗理解**：
- **预训练**：模型在非常大的图书馆里面去自学成才。参数量跟语料的丰富多样性几乎直接决定了预训练后模型的智商上限
- **微调**：你当模型的老师，帮模型定义标准答案。打磨优质的学生样本，对他进行针对性的辅导。样本本身的质量和多样性决定了模型的专业度跟可控性
