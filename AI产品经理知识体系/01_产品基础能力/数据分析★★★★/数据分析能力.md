# 数据分析能力




## 1. AI产品经理的数据分析定位




> 来源：课程3 — 工作流重塑与能力跃迁

AI产品经理的数据分析跟策略设计息息相关，需要**数据驱动**，需要设计策略并且获取高质量的数据来指导算法优化，对于数据和策略的理解要求比传统产品经理高很多。

| 维度 | 传统产品经理 | AI产品经理 |
|------|-------------|-----------|
| 数据作用 | 辅助决策 | 驱动算法优化 |
| 策略设计 | 功能策略 | 数据策略 + 算法策略 |
| 数据要求 | 基础分析 | 高质量数据获取与闭环 |

## 2. 量化需求分析




> 来源：课程7 — 进阶提升

量化需求分析是将业务场景转化为技术边界指标的**翻译过程**。

### 功能性需求 vs 非功能性需求




| 类型 | 具体内容 |
|------|---------|
| 功能性需求 | 具体要实现的业务功能 |
| 非功能性需求 | 安全性、可用性、可靠性、性能指标、可支持性 |

### 模型期望类型




| 应用场景 | 核心指标 | 说明 |
|---------|---------|------|
| 科研工作 | 精确率（Precision） | 宁可少给，给的必须准 |
| 医学筛查 | 召回率（Recall） | 宁可多给，不能漏掉 |

## 3. 复盘和迭代机制




> 来源：课程5 — AI技术入门实战

### 四个核心原则




1. **可监控** — 实时了解系统运行状态
2. **可定位** — 出现问题时能快速找到原因
3. **可调整** — 能灵活修改策略和参数
4. **可复用** — 解决方案可以沉淀复用

### 反馈机制组件




| 组件 | 作用 |
|------|------|
| 用户评分模型 | 收集用户对输出的满意度评价 |
| 异常情况标签和自动记录 | 自动捕获和标记异常case |
| 失败的Prompt收集 | 积累失败案例用于优化 |

### 三张活表




```
1. Prompt模块表      — 管理所有Prompt模板及其版本
2. 任务链结构图      — 可视化展示多步骤任务的执行链路
3. Prompt DSL语法库  — Prompt的结构化语法规范库
```

### 问题定位思考路径




```
Prompt设计问题
    ↓ 排除
输入信息不足
    ↓ 排除
任务链顺序错误
    ↓ 排除
知识库命中不准
```

> 按顺序逐层排查：Prompt设计 → 输入信息 → 任务链顺序 → 知识库命中

## 4. 构建高质量数据飞轮




> 来源：课程3 — 工作流重塑与能力跃迁

### Midjourney案例




Midjourney通过让用户在四个选项中选一个，实现了**100%数据反馈率**。

```
用户输入Prompt
    ↓
AI生成4张候选图
    ↓
用户选择1张（或重新生成）  ← 100%反馈率
    ↓
数据回流优化模型
    ↓
生成质量提升 → 吸引更多用户
    ↓
形成飞轮效应
```

**核心启示**：将数据收集融入产品交互流程，让用户在无感知的情况下完成数据标注，实现数据飞轮的自运转。
