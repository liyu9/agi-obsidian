# 产品开发流程




## AI大模型产品研发流程




> 来自课程6

### 传统产品研发流程




```
规划 → 需求 → 设计 → 研发 → 交付 → 运营 → 迭代
```

### AI时代流程变化




| 传统环节 | AI时代变化 |
|---------|-----------|
| 规划 | 新增**技术展望** |
| 需求分析 | 角色重构 |
| 设计 | 融合AI能力 |
| 研发 | 协同模型+工程 |
| 交付 | 关注组织变化 |
| 运营 | 关注模型反馈 |
| 迭代 | 数据+模型驱动 |

### 新增环节：技术展望




> 来自课程6

在产品规划过程中，除了围绕业务、产品、规划协同的工作外，还需要做**技术的展望和预言**，知道落地过程中有哪些能力可用，哪些能力成熟度不够。

## 技术预研




> 来自课程7

AI产品经理核心能力——**业务技术化**（将业务需求转化为技术方案）。

**案例：专利语义检索**

| 转化步骤 | 内容 |
|---------|------|
| 业务需求 | 判断专利是否侵权 |
| 技术问题转化 | 语义检索任务 |
| 聚焦范围 | 标题+摘要+权利要求 |
| 技术细分 | 中文分词 → 语义相似度计算 → PageRank评分 |

## 数据处理关键步骤




> 来自课程7

| 步骤 | 说明 |
|------|------|
| 数据定义 | 明确数据范围和标准 |
| 数据切分 | 训练集60% / 验证集20% / 测试集20% |
| 数据标注 | 按标准对数据进行标注 |
| 数据归一化 | 统一数据格式和标准 |
