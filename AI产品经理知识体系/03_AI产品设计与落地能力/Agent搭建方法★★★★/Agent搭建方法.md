# Agent搭建方法




## Agent搭建六步法




> 来自课程5第一章

| 步骤 | 核心任务 | 技术手段 | 产品经理关注点 |
|------|---------|---------|--------------|
| 1. 确定输入数据类型 | 判断文本/图像/语音 | 文本→NLP；图像→CV；语音→ASR/TTS | 是否需要识别结构？是否有语义模糊？ |
| 2. 数据转换处理 | 标准化输入数据 | 文本→embedding；语音→ASR/TTS；图像→图像分类 | 输入需要提前标准化处理吗？需要找相似文档做语义搜索吗？ |
| 3. 选择模型能力 | 匹配业务需求与模型能力 | 见下方决策表 | 大模型用还是不用？成本考虑？能否使用已有API？ |
| 4. 控制输出 | 控制生成结果的质量和结构 | Prompt设计；微调；模板封装 | 写Prompt示例、定义输入输出格式、做兜底策略和fallback方案 |
| 5. 对接服务 | API对接与推理结果获取 | API对接模型服务 | 跟研发沟通接口结构、跟算法确认调用频率/token数/延迟、评估用户体验流畅度 |
| 6. 构建Agent | 自动化流程编排 | 大模型+Prompt+RAG+Memory+工具接口 | — |

### 1. 确定输入数据类型




判断输入是文本、图像还是语音，确定处理方式：
- **文本**：用NLP处理
- **图像**：用CV处理
- **语音**：用ASR和TTS处理

### 2. 数据转换处理




- 文本通过 **embedding**
- 语音通过 **ASR/TTS**
- 图像通过 **图像分类**

产品经理思考：
- 输入需要提前标准化处理吗？
- 需要找相似文档做语义搜索吗？

### 3. 选择模型能力




| 业务需求 | 推荐方案 |
|---------|---------|
| 需要内容生成 | 大模型 |
| 需要精确回答 | 检索增强（RAG） |
| 只是打标签 | 普通分类模型 |
| 多模态理解 | 大模型+图文输入 |

### 4. 控制输出




- **Prompt设计**：控制生成结果结构
- **微调**：适配垂直行业风格
- **模板封装**：让交互更安全

产品经理职责：
- 写Prompt示例
- 定义输入输出格式
- 做兜底策略和fallback方案

### 5. 对接服务




通过API对接模型服务，判断模型来源，等待推理拿结果。

产品经理职责：
- 跟研发沟通接口结构
- 跟算法确认调用频率/token数/延迟
- 评估用户体验流畅度

### 6. 构建Agent




```
Agent = 大模型 + Prompt + RAG + Memory + 工具接口
```

核心能力：
- 自动处理流程
- 多步执行任务
- 持续记忆
- 反馈学习
