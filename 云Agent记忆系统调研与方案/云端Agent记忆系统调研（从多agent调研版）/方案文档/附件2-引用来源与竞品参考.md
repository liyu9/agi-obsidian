## 附录 B：竞品功能参考（Coze / VikingDB / Dify）

以下三款商业产品不在候选选型池内，仅用于借鉴功能设计。本附录按 §4.4 记忆系统核心能力与 §4.5 RAG / 向量数据库底座能力回填其功能事实，方便未来设计开源记忆系统时对齐落地经验。一手 URL 见附录 A。

### B.1 Coze（扣子）

**产品定位**：字节跳动低代码 Agent 平台，记忆能力拆成 变量 / 数据库 / 长期记忆（LTM）/ 知识库 / 插件 + 工作流 五类资源。

**§4.4 记忆系统核心能力速览**

| 能力 | 事实要点 |
|---|---|
| 作用域与隔离 | workspace + uuid + sys_platform + 渠道隔离；无部门 / 细粒度 ACL；作用域与隔离在部门级为 ❌ |
| 记忆写入 | 变量 / DB / LTM / 知识库多入口；LTM 2025-10 起支持"记忆库绑定多智能体" |
| 记忆类型 | 事实 / 偏好 / 文档；无实体-关系；过程型无 schema |
| 记忆召回 | 语义 / 全文 / 混合三种检索策略 |
| 生命周期 | 仅支持删除；无压缩 / 版本 / 衰减 |
| 跨 Agent 共享 | 记忆库可绑定多个 Bot；协议层无抽象 |
| 治理与安全 | 传输加密 + 基础消息日志；无 SSO 与合规审计（企业版另议） |
| 可观测性 | 消息日志 / 数据分析面板；无命中率 / 污染率指标 |

**主要功能借鉴点**

- 「记忆库绑定多智能体」是"跨 Agent 语义"的低成本近似做法，可作为开源候选补齐 §4.4 跨 Agent 共享 的参考。
- 分片规则允许「分段标识符 + 字符长度」双参数，值得沉淀为默认切片策略。
- 消息日志 + 数据分析面板的组合，适合作为开源记忆系统的最小可观测形态参考。

### B.2 火山引擎 VikingDB

**产品定位**：企业级向量数据库；上层可以叠 Viking 知识库（本节按向量数据库层记录）。

**§4.4 记忆系统核心能力速览**

| 能力 | 事实要点 |
|---|---|
| 作用域与隔离 | 项目 / 数据集 / RAM 账号权限；靠子索引 / namespace 承担多租户隔离；无 Agent 语义 |
| 记忆写入 | `upsert_data` 原子写入；支持批量 |
| 记忆类型 | 向量 + 元数据 + 原始文本；语义结构靠上层组织 |
| 记忆召回 | HNSW / HNSW-Hybrid / Flat / IVF / 量化索引；余弦 / 欧氏 / 内积 |
| 生命周期 | 仅 upsert / delete；无内置去重 / 压缩 / 衰减 |
| 跨 Agent 共享 | 协议层无 Agent 上下文；跨 Agent 共享为 ❌ |
| 治理与安全 | 传输 + 静态加密；审计日志；数据驻留可选 |
| 可观测性 | 控制台可查 QPS / 命中率 / P99；提供公开价与配额说明 |

**主要功能借鉴点**

- Pipeline 与实验版本的设计，适合开源候选参考"检索方案 A/B 对比"的落地形式。
- 子索引 + 标量过滤字段的组合，是"部门级 / 项目级切片"的通用做法。
- 「标量过滤检索」作为混合检索的官方定义，值得沉淀为文档词汇。

### B.3 Dify

**产品定位**：开源 + 商业版 LLM 应用开发平台；知识库 + 会话变量 + Chatflow Memory 构成业务侧最低可接受的记忆模型。

**§4.4 记忆系统核心能力速览**

| 能力 | 事实要点 |
|---|---|
| 作用域与隔离 | workspace + 知识库 3 档权限（Only me / All team members / Partial team members）；无部门树 |
| 记忆写入 | 知识库写入 + 会话变量赋值；Chatflow 可持有会话状态 |
| 记忆类型 | 事实 / 偏好 / 文档；无实体-关系 |
| 记忆召回 | Top-K + Score Threshold + 元数据过滤 + N-to-1 / Multi-way Recall |
| 生命周期 | 支持删除；去重 / 压缩靠工作流拼装；无版本化 / 衰减 |
| 跨 Agent 共享 | 「多 Agent」实为工作流编排；跨 Agent 共享为 ⚠️ |
| 治理与安全 | 企业版审计 + SSO；社区版依赖部署侧 |
| 可观测性 | 企业版监控；社区靠 Langfuse 等外接方案 |

**主要功能借鉴点**

- 知识库 3 档权限（Only me / All / Partial）是「个人 → 团队 → 全员」权限模型的最简可用样板。
- 外部知识库连接 API 与「仅检索权限」的边界描述，适合开源记忆系统对齐外部知识源接入协议。
- Retrieval Testing 面板 + Score Threshold 默认值，为开源候选补齐 §4.4 可观测性（命中率 / 记忆污染率）评估提供参考。
