## ⚠️ 常见问题处理

| 问题 | 解决方案 |
|------|----------|
| 文件路径中有空格/特殊字符 | 使用引号包裹路径：`"文件路径"` |
| 文件读取失败 | 使用 `Get-Content -Raw -Path` 命令 |
| Mermaid字体白色 | 必须添加 `color:#000000` |
| 内容来源不确定 | 在总结中标注"根据原文xxx推断" |
| 与已有流程冲突 | 以原文为准，在总结中说明关联关系 |
