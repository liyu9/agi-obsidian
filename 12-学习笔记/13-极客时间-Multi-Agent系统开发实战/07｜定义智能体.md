最佳实践与反模式
反模式
Role 太宽泛：
无法有效激活专业领域知识，不利于其它
agent 委托
Goal 的目标与 task 冲突：
Goal 是罗盘，Task 才是终点。 如果把格式要
求写在 Goal 里，Agent 会在任务还没开始思
考时就急着凑格式，导致内容质量下降
Backstory 写死流程 ：
你的 Agent 变成了一次性脚本，失去对 task 
的通用性。Backstory 只存心法，不存招式
最佳实践
元提示词：
让模型帮你生成和优化 PE：
• role 的设定让模型推荐
• backstory 中的知识和 sop 用深度研究的报告去提取
• 拿着执行日志和 prompt 让模型去分析问题优化
