最佳实践与反模式
反模式
审批疲劳
checkpoint 不是越多越好，设太多反而让真正需要确认的
决策也被橡皮图章通过。
人完全退出循环
"Agent完全自主"和"建立数字员工团队"是两件不同的事
——没有甲方的项目没有边界。
无审计轨迹
不只是"有人看了一眼"，要有据可查——谁、批准了什么、
什么时候、基于什么信息。
谎言在循环中
你在对话框看到的和 Agent 实际执行的可能不是同一件
事，HITL 本身需要防护。
最佳实践
"在循环之上" 定位
甲方的价值在于定义标准和设计流程，而不是审查
每一行输出——后者是微管理，不是监督。
风险分级审批
低风险 + 高置信度→自动执行；中等→人工确认；
高风险或低置信度→阻塞并路由给指定负责人。
实践效果：减少 60-80% 无效审批。
全局停止开关 + 指定事故负责人
全局停止标志 + 分工具熔断器 + 回滚手册，
每个异常类型有指定负责人和响应时间 SLA。
