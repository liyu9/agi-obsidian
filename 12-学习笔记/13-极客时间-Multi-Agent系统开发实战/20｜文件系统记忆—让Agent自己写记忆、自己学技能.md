最佳实践与反模式
反模式
记忆污染链：
幻觉或者攻击的信息写入记忆，扩大影响范围
记忆贪婪症：
无差别写入的 Agent 在基准测试上比空记忆还
差
记忆腐化——只写不治理：
过时的事实比缺失的信息危害更大，记忆失控让 
API 开销从 $127/周飙升到 $47,000/月
跨用户记忆泄露：
多用户共用同一套文件系统，需要强校验记忆写
入范围
最佳实践
准入四门控：
在调用前过滤，不是写入后清理，在源头控制比事后
清理省 10 倍力气
双时间戳：
每条记忆带上“生产日期”和“有效期”，记录created
（事件产生时间）和 updated（最近一次确认修改时
间）
更新优于追加：
记忆文件应该越来越准确，不是越来越长，写入前读
目标文件，找到旧记忆用 str_replace 精准更新
闭环治理：
让 Agent 主动感知阈值，自动触发 GC
