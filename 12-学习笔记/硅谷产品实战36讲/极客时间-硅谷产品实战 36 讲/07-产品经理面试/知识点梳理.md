# 产品经理面试 - 知识点梳理

## 一、好的产品经理和卓越的产品经理

### Facebook面试PM的两个测试

- **坐飞机测试**：你愿意和这个PM坐长途飞机吗？（考察相处舒适度）
- **请假测试**：PM请假期间，团队是否能正常运转？（考察团队建设能力）

### 卓越PM vs 好的PM的6个区别

1. **痛点真实存在吗**
   - 好的PM：假设痛点存在，直接设计解决方案
   - 卓越PM：先验证痛点是否真实存在

2. **长期目标vs短期目标**
   - 好的PM：只给单一指标
   - 卓越PM：分短期小目标和长期大目标
   - 案例：年轻人找职业导师产品
     - 短期：导师回复率
     - 中期：联系频率
     - 长期：薪水涨幅

3. **得到的代价是什么**
   - 好的PM：头脑风暴给20个主意
   - 卓越PM：给出每个主意的代价和权衡取舍

4. **只在乎自己管辖的功能vs全局思考**
   - 好的PM：只看自己功能指标
   - 卓越PM：站在产品总监/CPO高度思考对整个产品的影响
   - 案例：Messenger生日GIF功能——不仅看GIF使用率，还要考虑对Messenger整体体验的影响

5. **不符合公司设计准则**
   - 好的PM：听话换方式
   - 卓越PM：敢于质疑准则本身并提出优化

6. **抽象化vs细节化**
   - 好的PM：按流程一步步来
   - 卓越PM：有思考框架，先抽象后细节
   - 案例：生日功能——抽象为三个核心人性需求：
     - 有在乎自己的人
     - 让自己更加在乎自己
     - 有互相在乎的关系

### 个人特点和风格

- 好的PM：中规中矩
- 卓越PM：特点鲜明，深挖自己特点并发挥

## 二、产品经理面试考察的是什么？

### 面试形式

- 以对话方式进行
- 考察能力：分析能力、讲故事能力、沟通能力、权衡取舍能力、解决问题能力

### 四个考察主题

1. **产品体验设计**
   - 从用户需求出发设计产品体验
   - 经典题：设计00后新闻APP

2. **产品分析和执行**
   - 深入浅出，拆分大问题为小问题
   - 经典题：视频浏览量降低20%怎么办

3. **领袖气质**
   - 领导力、沟通力、同理心、勇气
   - 经典题：挑战权威的例子

4. **团队管理**
   - 艰难环境下掌控局面，建立信任
   - 经典题：工程师不信任你怎么办

### 面试流程

- HR面 → 两轮电话面（产品体验设计 + 产品分析） → 最后一轮现场面（全面考察）

### 面试官独立评价系统

- 6级推荐等级，面试官独立给出评价

### 开放进组机制

- 综合考察，不针对具体部门
- 入职后通过新兵训练营(bootcamp)双向选择

## 三、如何提升产品感（product sense）？

### 产品感定义

- 能把用户需求转化成用户喜欢、用得顺手的产品体验

### 产品感四个方面

1. 将模糊想法转化为产品方案
2. 设计符合用户习惯的产品
3. 制定产品策略和功能优先级
4. 明确产品重点和成功标准

### 一句话概括

- 知不知道如何做产品决定，产品决定是否有道理

### 案例：IGTV竖版全屏

- 针对年轻用户，竖版全屏更沉浸

### 提升产品感的4个方法

1. **对比研究同类产品**
   - 对比目标用户、功能、用户体验
   - 如上传同一视频对比体验差异

2. **给喜欢的产品挑刺**
   - 越好的产品挑错空间越小，锻炼产品感

3. **思考产品成功指标的制定过程**
   - Facebook看重用户使用时间 → 信息流放视频
   - YouTube看重观看总时长 → 推荐长视频
   - 若改订阅制指标如何变化

4. **从非互联网产品中找灵感**
   - 时尚产品的目标用户定位
   - 金融产品的用户分层策略

## 四、如何提升产品经理的综合素质？

### 三大软实力

#### 1. 讲故事的能力

- 给团队讲清楚做什么、为什么值得做
- **方法一：用具体人物细节**
  - 案例：奥巴马2008年演讲用106岁黑人妇女经历
- **方法二：借鉴虚拟文学写作方式**
  - 结构：开端 → 铺垫 → 高潮 → 结局
  - 对应：痛点 → 为何未解决 → 解决方案 → 期待

#### 2. 和他人建立信任的能力

- 心理学研究：领袖吸引人的两个特点——有能力、慷慨
- 不仅是建立关系，还包括修复信任关系
- **Sheryl Sandberg方法**
  - 敢于面对不舒服的对话(Difficult Conversation)
  - 主动问别人对你有没有意见
- Facebook产品主管需接受不舒服对话培训
- **锻炼方式**
  - 社交活动和陌生人聊天
  - 一周内修复不顺心人的关系

#### 3. 创造能力

- 跨学科碰撞最能提升创造力
- 斐济·西默(Fidji Simo)的新年计划：每周做一件有创造力的事
- 创造力如健身，不练会退化
- 哈佛商业评论每日贴士推荐

## 五、非计算机专业也能做产品经理？

### 硅谷趋势

- 从要求CS背景 → 允许各种背景 → 重视多元化

### 核心观点

- 理想PM需要计算机知识，但不需CS学位

### CS学位的三大帮助及弥补方式

1. **给工程师的第一印象**
   - CS学位 → 工程师默认你不好蒙骗
   - 无CS → 保持好奇心多问问题、展示能力即可

2. **判断项目复杂程度**
   - CS学位 → 理解项目复杂度和拆分方式
   - 无CS → 新项目开始时了解5类问题：
     1. 工程结构图
     2. 依赖关系
     3. 用户流程图
     4. 复杂度和耗时部分
     5. 产品质量影响

3. **了解技术是否可实现**
   - CS学位 → 了解技术限制
   - 无CS →
     - AI项目：明确"宁缺毋滥"还是"一个都不能少"；明确数据量和来源
     - 移动端项目：明确信息处理在设备端还是服务器端；UI是否必须是native

## 六、模拟一场硅谷的产品经理面试

### 模拟面试主题

- 设计找房产品

### 面试关键点

1. 不要害怕多要思考时间，经过思考的回答比脱口而出好
2. 面试官故意问模糊问题，考验思考能力
3. 面试者先明确问题范围（买房vs租房），给出逻辑分析选择租房
   - 交易频率高
   - 发挥公司用户数据优势
   - 室友匹配需求
4. 先考虑用户痛点，再设计功能
5. 面对质疑（房源信息来源），能分析利弊做出判断
   - 自建平台 vs 爬取信息
6. 冷启动策略
   - 运营团队拉房东入驻
   - 一个城市一个城市发布
7. 明确MVP优先级
   - 搜索筛选 + 房源信息 + 房东室友信息为差异化亮点
8. 利用公司独特优势
   - 用户数据 → 同校推荐、实名评价
9. 成功指标定义
   - 房客给房东发消息数量（而非签合同数）
   - 原因：平台价值在于高效筛选
10. 成功标准最好在设计功能之前先说

### 面试官评价维度

- 逻辑分析能力
- 权衡取舍能力
- 成功指标定位
