## 知识体系全景图

```
产品设计核心知识链
│
├─ 模块一：用户需求与定位
│  ├─ 需求验证三步法：确认用户→痛点假设→验证假设
│  ├─ 用户调查：一对一面谈（深挖）vs 问卷调查（量化）
│  ├─ 目标客户：先拓展再专注
│  ├─ 用户画像：生动描述，抽象成一个人
│  ├─ 用户问题说明：作为XX，我想做XX，从而帮助我XXXX
│  └─ 用例写法：触发条件+用户结果+复用架构 → 具体化
│
├─ 模块二：产品定义与成功指标
│  ├─ MVP = 最小化（降低试错成本）+ 可行性（解决核心需求）
│  ├─ 成功指标4步法：产品最高目标→子指标→功能与指标关系→反指标
│  ├─ PRD 5要素：痛点→论证痛点→指标+反指标→场景→功能方案
│  └─ 侵蚀效应：新功能挤占原有产品成绩
│
├─ 模块三：数据驱动与功能优化
│  ├─ 数据决策4步：具体假设→A/B验证→找影响规律→决定功能
│  ├─ 魔法数字：找到影响力最大的临界点
│  ├─ A/B测试：验证因果性唯一途径；注意短期vs长期数据
│  ├─ 5步科学迭代：指标→工作流→机会→头脑风暴→快速执行比对
│  └─ UIE增长论：了解（每步数据）→找到（最大机会）→执行（验证发布）
│
└─ 模块四：优先级与权衡取舍
   ├─ P0/P1/P2分级 + 4大误区
   ├─ 跨部门对齐 + "一定不优先"板块
   ├─ 增长代价 = 短期增长对长期发展的不利影响
   ├─ 使命宣言 + 核心原则（不可违背的最高戒律）
   └─ 反指标必须量化，成为核心数据
```
