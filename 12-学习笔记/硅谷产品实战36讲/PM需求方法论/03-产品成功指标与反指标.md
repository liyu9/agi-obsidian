# 产品成功指标与反指标

> 来源：《硅谷产品实战36讲》第12讲

## 核心原则

**当你确定了正确的成功指标，你就成功了一半。**

错误的成功指标 → 错误的产品策略 → 产品失败。成功指标必须与用户需求相契合。

---

## 方法论：制定成功指标四步法

### 第一步：明确整个产品的最高目标

从产品的核心价值出发，确定最高层指标。

> 示例：微信的核心指标 = 用户活跃程度（评论×1 + 分享×0.5 + 发消息×1）

### 第二步：思考功能还有哪些小指标需要注意

除了核心指标，还有哪些与功能相关的指标。

> 示例：朋友圈要穿插广告，用户浏览朋友状态的数量也是指标（更多浏览 = 更多广告曝光）

### 第三步：明确功能如何提升指标

建立新功能与指标的因果链。

> 示例：表情包评论 → 降低互动门槛 → 评论数增加 → 发状态者更受激励 → 发更多状态 → 总活跃分提升

### 第四步：明确反指标（Counter Metrics）

反指标 = 产品带来的负面影响。

> 示例：表情包评论的反指标 = 降低朋友圈内容质量分（表情包替代深度文字交流，交流流于表面）

---

## 方法论：A/B测试验证指标

设定实验组和对照组，观察成功指标和反指标的变化：
- 实验组成功指标增加显著 + 反指标被控制 → 功能有效
- 设定量化提升目标（如5%），低于此则不值得发布

### 两个关键问题

1. **多指标权衡取舍** — 按重要性排序，确保新功能不影响产品总指标
2. **A/B测试时间** — 必须等数据稳定后再做决定（至少一周，排除新鲜感效应）

---

## 方法论：好指标的标准

指标 = 期限 + 具体数值 + 可衡量结果

| 好指标 | 差指标 |
|--------|--------|
| 2018年底前实现100万日活 | 争取用户规模达到100万 |
| — | 让用户多花时间在APP上 |

---

## 案例

### 微信朋友圈 — 成功指标与反指标的完整推演

**功能**：朋友圈加表情包评论

| 步骤 | 分析 |
|------|------|
| 最高目标 | 微信总活跃分 |
| 小指标 | 用户浏览朋友状态数量（广告曝光） |
| 因果链 | 表情包降低互动门槛 → 评论增加 → 发状态者更受激励 → 总活跃分提升 |
| 反指标 | 朋友圈内容质量分下降 |

**A/B测试决策**：
- 成功指标增加 + 反指标控制住 → 发布
- 成功指标提升低于5% → 砍掉
- 成功指标增加但反指标恶化 → 需权衡，可能升级到公司高层决策

### 电商 — 指标选择决定策略方向

- 错误指标：总用户数量 → 可以通过抽奖下载刷量，但用户不下单
- 正确指标：下单用户数 → 引导真正有价值的用户行为

### 朋友圈 — 指标与用户需求脱节的反面案例

如果成功指标 = 用户在朋友圈花的时间：
- 推送更多花时间的内容（文章、视频），减少朋友发的文字/图片
- 用户使用朋友圈的目的是和朋友互动，需求得不到满足 → 减少使用甚至放弃

### 豆瓣图书推荐 — 侵蚀效应

- 成功指标：通过推荐功能下载/购买图书的次数
- 反指标：用户使用豆瓣其他产品（电影、电视剧）的频率
- 如果图书推荐成功但挤占了其他产品使用 → 侵蚀效应（Cannibalization）
