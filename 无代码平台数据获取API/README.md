## 🔍 核心要点

### 伙伴云筛选条件

```python
filter_conditions = {
    "and": [
        {"field": "字段ID", "query": {"in": ["牛", "饼干", "糖"]}}
    ]
}
```

**关键操作符**：
- `eq` = 精确匹配
- `in` = 子串匹配（推荐）
- `ne` = 不等于（精确）
- `nin` = 不包含（精确）
- `gt/gte/lt/lte` = 数值比较
