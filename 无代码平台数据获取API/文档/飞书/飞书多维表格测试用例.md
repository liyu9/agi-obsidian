## 测试用例

### 测试1：多字段 OR + 多字段 OR

**筛选条件**：`标题[投诉 客户] 内容[24 小时]`

```json
{
  "filter": {
    "conjunction": "and",
    "children": [
      {
        "conjunction": "or",
        "conditions": [
          {"field_name": "知识标题", "operator": "contains", "value": ["投诉"]},
          {"field_name": "知识标题", "operator": "contains", "value": ["客户"]}
        ]
      },
      {
        "conjunction": "or",
        "conditions": [
          {"field_name": "知识内容", "operator": "contains", "value": ["24"]},
          {"field_name": "知识内容", "operator": "contains", "value": ["小时"]}
        ]
      }
    ]
  }
}
```

**结果**：✅ 命中 9 条

## 关键发现

1. **纯数字可用**：搜索 "1", "7", "24", "48", "72" 等纯数字都可以正常工作
2. **children 结构必须正确**：每个子元素必须是 `{conjunction, conditions}` 结构
3. **单字段多关键词**：使用 OR 逻辑在同一字段中搜索多个关键词
4. **多字段组合**：使用 AND 逻辑组合多个字段的筛选条件
