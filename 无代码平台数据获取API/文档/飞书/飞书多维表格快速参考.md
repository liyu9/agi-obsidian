## 1. 获取 Token

```python
import requests
def get_token():
    resp = requests.post(
        "https://open.feishu.cn/open-apis/auth/v3/tenant_access_token/internal",
        json={"app_id": "cli_xxx", "app_secret": "xxx"}
    )
    return resp.json().get("tenant_access_token")
```

## 2. 查询数据

```python
import requests

def search(token, filter_config=None):
    url = "https://open.feishu.cn/open-apis/bitable/v1/apps/{APP_TOKEN}/tables/{TABLE_ID}/records/search"
    headers = {"Authorization": f"Bearer {token}", "Content-Type": "application/json"}
    body = {"view_id": "{VIEW_ID}", "page_size": 100}
    if filter_config:
        body["filter"] = filter_config
    resp = requests.post(url, headers=headers, json=body)
    return resp.json().get("data", {}).get("items", [])
```

## 3. 筛选条件模板

### 3.1 单字段单关键词
```json
{"filter": {"conjunction": "or", "conditions": [{"field_name": "字段", "operator": "contains", "value": ["关键词"]}]}}
```

### 3.2 单字段多关键词 (OR)
```json
{"filter": {"conjunction": "or", "conditions": [
    {"field_name": "字段", "operator": "contains", "value": ["词1"]},
    {"field_name": "字段", "operator": "contains", "value": ["词2"]}
]}}
```

### 3.3 多字段 AND
```json
{"filter": {"conjunction": "and", "children": [
    {"conjunction": "or", "conditions": [{"field_name": "字段1", "operator": "contains", "value": ["词1"]}]},
    {"conjunction": "or", "conditions": [{"field_name": "字段2", "operator": "contains", "value": ["词2"]}]}
]}}
```

## 4. 动态构建函数 (Python)

```python
def build_filter(field_keywords):
    conditions = []
    for field, keywords in field_keywords.items():
        if not keywords: continue
        conditions.append({
            "conjunction": "or",
            "conditions": [{"field_name": field, "operator": "contains", "value": [k]} for k in keywords]
        })
    if len(conditions) == 1:
        return {"filter": conditions[0]}
    return {"filter": {"conjunction": "and", "children": conditions}}

# 使用
filter_config = build_filter({"知识标题": ["投诉", "售后"], "知识内容": ["24", "48"]})
```

## 5. 动态构建函数 (JavaScript)

```javascript
function buildFilter(fieldKeywords) {
  const conditions = Object.entries(fieldKeywords).map(([field, keywords]) => ({
    conjunction: "or",
    conditions: keywords.map(word => ({ field_name: field, operator: "contains", value: [word] }))
  }));
  if (conditions.length === 1) return { filter: conditions[0] };
  return { filter: { conjunction: "and", children: conditions } };
}
```

## 6. 操作符速查

| 操作符 | 说明 |
|---|---|
| `contains` | 包含（文本） |
| `is` | 等于 |
| `isNot` | 不等于 |
| `isEmpty` | 为空 |
| `isNotEmpty` | 不为空 |
| `isGreater` | 大于（数字） |
| `isLess` | 小于（数字） |

## 7. 常见错误

| 错误 | 原因 | 解决 |
|---|---|---|
| `1254302` | 无权限 | 给应用添加协作者 |
| `field validation failed` | children 结构错误 | 检查每个 children 元素是否是 `{conjunction, conditions}` 结构 |
