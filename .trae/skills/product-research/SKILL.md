# Product Research

调研产品信息，结合本地PM书籍方法论和GitHub最佳实践，生成结构化调研报告。

## 触发条件

用户提到以下意图时激活本skill：
- 调研某个产品（"调研一下飞书"）
- 分析竞品（"对比石墨文档和飞书"）
- 研究行业（"分析国内CRM SaaS行业"）
- 做市场分析（"XX行业的市场规模有多大"）

### Step 3: 多源信息收集

并行执行以下搜索（按需选择）：

1. **Web搜索**: 产品官网、行业报告、融资信息、用户评价

3. **竞品官网**: 逐一访问竞品官网获取功能/定价/定位信息

### Step 4: 按框架填充分析

#### 框架A: 行业与市场分析

```
1. 产业链结构: 绘制上下游关系，标注高利润节点
2. 市场规模: TAM/SAM/SOM 或 "目标客户业务规模 × IT投入占比" 估算
3. 行业集中度: CRn指数，判断竞争格局
4. 客群细分: STP理论 (Segmentation → Targeting → Positioning)
5. 趋势判断: 行业三问 — 玩家是谁? 变化是什么? 机会在哪?
```

#### 框架B: 竞品分析（五层模型）

```
1. 战略层: 产品定位、目标客户、市场规模、竞争策略
2. 资源层: 资金、标杆客户、网络效应、数据积累
3. 能力层: 技术壁垒、创新能力、平台化能力
4. 场景层: 核心功能 → 通用需求 → 产品架构 递进对比
5. 感受层: 可用性、操作效率、界面设计
补充: SWOT / 波特五力 / 功能对比矩阵
```

#### 框架C: 用户洞察

```
1. 用户画像: 核心用户群体特征
2. 需求动机: 表面需求 → 深层动机（追问"为什么"）
3. 用户旅程: 关键触点与痛点
4. 未满足需求: 长尾需求、创新机会点
```

### Step 5: 输出报告

按以下模板输出Markdown格式报告：

```markdown
# {产品/行业} 调研报告

## 1. 调研概述
- 调研目标与范围
- 使用的方法论（标注来源）

## 2. 行业与市场分析
- 产业链 / 市场规模 / 竞争格局 / 客群 / 趋势

## 3. 竞品分析
- 竞品全景 / 五层对比 / SWOT / 功能矩阵

## 4. 用户洞察
- 用户画像 / 核心需求与动机 / 痛点

## 5. 结论与建议
- 关键发现 / 机会点 / 风险提示

## 附录: 方法论来源与数据来源
```
