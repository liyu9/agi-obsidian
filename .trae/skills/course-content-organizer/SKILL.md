# 课程内容整理技能

整理知识付费课程文字稿，保留原文结构，忠实还原内容，添加结构化处理。

## 核心原则

### 黄金法则（必须遵守）

1. **100%忠实原文**
   - 每个观点必须有原文对应
   - 每个案例必须来自原文
   - 每个数据必须原文提供
   - ❌ 禁止凭空创造任何内容

2. **完整保留核心内容**
   - ✅ 保留所有商业案例（如：网易逆水寒、阿里鲁班）
   - ✅ 保留所有关键数据（如：1.7亿、4亿、50%）
   - ✅ 保留所有核心观点和金句
   - ✅ 保留所有具体细节和描述

3. **允许的结构化处理**
   - ✅ 添加层级标题（如：一、XXX；二、XXX）
   - ✅ 创建表格归类信息
   - ✅ 绘制流程图/架构图
   - ✅ 提炼学习要点和总结
   - ❌ 不能改变原文的核心观点
   - ❌ 不能省略重要案例细节

4. **可接受的省略（少量）**
   - 开场引导语（如"同学们好"）可精简
   - 口语化感叹词可规范
   - 重复性强调语可精简
   - ❌ 但核心知识不能省略

## 处理流程

### Step 1: 准备工作

1. **确认输入**
   - 用户提供课程文字稿路径
   - 确认是哪个章节/小节

2. **创建输出目录**
   - 路径：`原文件目录/../课程内容整理/章节名称/`
   - 示例：`三节课/产品经理AI实操指南/课程内容整理/第一章_内容主题/`

3. **建立任务清单**
   ```
   - [ ] 创建输出目录
   - [ ] 读取所有原文文件
   - [ ] 逐章节整理内容
   - [ ] 创建章节总结
   - [ ] 质量检查
   ```

### Step 2: 内容整理规则

#### 标题层级

```
# 第一章/第一节：完整标题
## 一、大标题
### 1. 中标题
#### （1）小标题
```

#### 内容模块

每个整理文件应包含：

1. **章节导语**（保留原文引入）
2. **核心知识点**（分模块详细整理）
3. **案例详解**（保留所有案例细节）
4. **总结提炼**（学习要点、关键术语）

#### 案例保留标准

必须完整保留：
- 具体公司/产品名称（如：网易《逆水寒》、阿里鲁班）
- 具体数字数据（如：1.7亿、4亿、每秒8000张）
- 具体场景描述（如：NPC互动、场景生成）
- 具体对话/情节（如：卖茶女诈骗、问号识别）

#### 金句提取

保留原文金句格式：
```
> "原文原句" —— 出处/场景
```

#### 引导语保留

在章节开头保留少量引导语：

```markdown
# 第一章：AI基础认知

> 同学们好，让我们开始第一章的学习...

## 一、AI是什么
```

### Step 3: 内容完整性检查

整理时逐项核对：

| 检查项 | 必须保留 |
|--------|----------|
| 案例公司 | ✅ 网易、阿里、京东、58等 |
| 案例产品 | ✅ 逆水寒、鲁班、好好吃饭等 |
| 关键数据 | ✅ 所有数字、百分比 |
| 核心观点 | ✅ 原文原话 |
| 方法论 | ✅ 四步法、MECE等 |
| 工具清单 | ✅ ChatGPT、Midjourney等 |

### Step 4: 质量检查清单

#### 整理后自检

```markdown
## 质量检查清单

- [ ] 所有原文案例已保留
- [ ] 所有关键数据已保留
- [ ] 核心观点无遗漏
- [ ] 无凭空创造内容
- [ ] 结构清晰易读
- [ ] 包含总结和提炼
```

#### 评估标准

| 维度 | 优秀 | 合格 | 不合格 |
|------|------|------|--------|
| 忠实度 | 95%+ | 80-95% | <80% |
| 完整性 | 95%+ | 80-95% | <80% |
| 可读性 | 结构清晰 | 基本可读 | 混乱 |
| 增值 | 有总结 | 基本结构 | 无提炼 |


### 章节总结文件

## 示例

### 原文处理示例

**原文**：
```
同学们好。接下来我们来看第三节的内容。AI商业应用案例分析。在这一节里我们会一起来去探索AI在商业领域的各种应用。你会发现AI其实已经悄悄渗透到我们生活里面的方方面面。
```

**整理后**：

```markdown
# 1.3 AI商业应用案例分析

> 同学们好。接下来我们来看第三节的内容...

## 一、AIGC产业全景图

### 两大方向

#### 面向C端用户的产品
按内容形态分类：
- 文本生成
- 图片生成
- 音频生成
- 视频生成
- 虚拟人生成
```

### 案例整理示例

**原文**：
```
比如网易福西平台就把他们研发的预言大模型全面应用在他们的游戏《逆水寒》里，让这款游戏的可玩性和趣味性变得更强。我给你举三个例子。
第一种应用是把AI和NPC互动结合在一起。传统游戏的NPC都是程序员设定好固定的动作和对话语言。但经过AI的加成。NPC会和玩家有更多元的交互方式。
```

**整理后**：

```markdown
#### 案例：网易《逆水寒》

**应用一：AI + NPC互动**
- **传统方式**：程序员设定固定动作和对话语言
- **AI赋能**：
  - 玩家对话从选择题变为开放式问答题
  - NPC具有多元交互方式
  - 可识别并回应玩家的调侃
```

## 常见问题处理

### Q1: 原文有口语化表达怎么办？

**处理方式**：规范为正式表述，但不改变原意

### Q2: 原文前后重复？

**处理方式**：保留一处详细描述，其他精简

### Q3: 原文缺少结构？

**处理方式**：添加逻辑分层，但基于原文内容

### Q4: 用户要求省略某些内容？

**处理方式**：
- 确认是核心内容还是引导语
- 核心内容必须保留
- 可省略：开场白、重复强调、口头禅

## 使用场景

### 触发条件

当用户说：
- "整理课程内容"
- "体系化学习"
- "提取课程知识点"
- "基于文字稿组织内容"
- "帮我学习这个课程"

### 不适用场景

- 用户要的不是课程内容整理
- 用户要求写全新的课程内容
- 用户要求创作课程内容
