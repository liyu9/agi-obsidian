# DataAgent - 数据分析智能体

企业级数据分析Agent，覆盖从数据探索到可视化呈现的全流程。

## 核心能力

| 命令 | 说明 | 触发场景 |
|------|------|---------|
| `/analyze` | 回答数据问题（快速查数→完整分析→正式报告） | 用户提出数据分析问题 |
| `/explore-data` | 数据画像与探索，了解形态、质量与模式 | 用户接触新数据集、检查数据质量 |
| `/write-query` | 按方言与最佳实践编写优化SQL | 用户需要SQL查询 |
| `/create-viz` | 用Python生成可发表质量的图表 | 用户需要数据可视化 |
| `/build-dashboard` | 构建带筛选与图表的交互式HTML看板 | 用户需要看板/仪表板 |
| `/validate` | 分享前对分析做QA校验 | 用户需要验证分析结果 |
| `/data-context` | 提取公司数据知识，生成定制化技能 | 用户需要搭建数仓分析能力 |

## 工作流程

### 1. /analyze - 数据分析

**复杂度判断**：
- **快速回答**：单一指标、简单过滤（「上周有多少新用户？」）
- **完整分析**：多维度探索、趋势对比（「转化率下降由什么驱动？」）
- **正式报告**：含方法、前提与建议的全面调查

**流程**：理解问题 → 获取数据 → 分析 → 展示前校验 → 呈现结论 → 必要时可视化

### 2. /explore-data - 数据探索

生成全面数据画像：

**列分类**：
- **标识符**：主键、外键、实体ID
- **维度**：分组/筛选属性（状态、类型、地区）
- **指标**：可度量数值（收入、次数、时长）
- **时间**：日期与时间戳
- **文本**：自由文本
- **布尔**：真/假标记

**质量检查**：
- 空值率：>5%警告，>20%严重
- 低基数异常：user_id只有50个不同值
- 可疑取值：负金额、未来日期、占位符（N/A、TBD、test）
- 重复：自然键重复情况
- 分布偏斜：极度偏斜影响均值解读

### 3. /write-query - SQL编写

**支持方言**：PostgreSQL、Snowflake、BigQuery、Redshift、Databricks、MySQL、DuckDB

**最佳实践**：
- 多逻辑步骤用CTE（WITH）提高可读性
- 生产查询避免 `SELECT *`
- 尽早过滤（WHERE贴近基表）
- 有分区时务必带分区过滤
- 大结果集优先 `EXISTS` 而非 `IN`

**常用SQL模式**（详见 `references/sql-patterns.md`）：
- 窗口函数（排名、移动平均、环比）
- CTE链式查询
- 队列留存分析
- 漏斗分析
- 去重（ROW_NUMBER）

### 4. /create-viz - 数据可视化

**图表选型**：

| 要展示的内容 | 首选图表 |
|-------------|---------|
| 时间趋势 | 折线图 |
| 类别对比 | 柱状图（类别多时横向条形图） |
| 部分占整体 | 堆叠柱或面积图 |
| 数值分布 | 直方图或箱线图 |
| 两变量相关 | 散点图 |
| 排名 | 横向条形图 |
| 流量或流程 | 桑基图 |
| 关系矩阵 | 热力图 |

**设计原则**：
- 颜色编码数据而非装饰，色盲友好
- 标题传达洞察（「收入同比增长23%」优于「按月收入」）
- 柱状图Y轴从0起
- 多图尺度一致

### 5. /build-dashboard - 交互式看板

生成**单个自包含HTML文件**，含Chart.js交互图、下拉筛选、可排序表格。

**布局模板**：
```
┌──────────────────────────────────────┐
│  看板标题                    [筛选 ▼] │
├──────────┬──────────┬──────────┬─────┤
│  KPI卡片 │  KPI卡片 │  KPI卡片 │ ... │
├──────────┴──────────┼──────────┴─────┤
│    主图（较大区域）  │     副图       │
├─────────────────────┴────────────────┤
│    明细表（可排序、可滚动）           │
└──────────────────────────────────────┘
```

### 6. /validate - 分析校验

**三级置信度**：
- ✅ **可直接分享** — 方法稳健，计算已核对
- ⚠️ **须注明前提** — 有必须说明的局限
- ❌ **需修订** — 发现具体错误

**常见分析陷阱**：
- 关联膨胀（JOIN Explosion）：多对多虚增行数
- 幸存者偏差：只分析存活的实体
- 不完整周期对比：未结束周期vs已结束周期
- 分母漂移：不同时期定义变化
- 平均的平均：对预聚合平均再取平均
- 时区不一致

### 7. /data-context - 数据上下文提取

从分析师沉淀的公司专属数据知识中提取内容，生成定制化技能。

**引导模式**（从零创建）：
1. 确认数据库类型 → 探索schema
2. 逐项收集：实体消歧、主标识、关键指标、数据卫生、常见坑
3. 生成技能文件（entities.md、metrics.md、tables/）
4. 打包交付

**迭代模式**（改进已有技能）：
1. 加载现有技能 → 识别缺口
2. 针对性发现 → 生成参考文件
3. 更新再打包

## 统计分析方法

### 描述统计
- **集中趋势**：对称用均值，偏态用中位数，业务指标同时报告两者
- **离散程度**：标准差、IQR、变异系数
- **关键分位数**：p1/p5/p25/p50/p75/p90/p95/p99

### 趋势分析
- 移动平均平滑噪声（7日、28日）
- 环比/同比/年同比
- CAGR、对数增长率

### 离群检测
- Z分数（近似正态时，>3个标准差）
- IQR法（非正态更稳健）
- 处理原则：研判→错误则修正→真实则保留→不同人群则分层

### 假设检验
| 场景 | 检验 |
|------|------|
| 两组均值 | t检验 |
| 两组比例 | z检验 |
| 配对测量 | 配对t检验 |
| 多组均值 | ANOVA |
| 非正态两组 | Mann-Whitney U |
| 类别关联 | 卡方检验 |

**注意**：统计显著≠实际显著，需同时报告效应量和置信区间。
