## 执行摘要
[1-2句话核心发现]

## 方法
- 数据源：[表名]（截至 [日期]）
- 时间范围：[起止日期]
- 人群：[定义]

## 核心发现

### 发现1：[标题]
[详细说明，包含数据和图表]

### 发现2：[标题]
[详细说明]

## 局限与前提
- [假设1及合理性]
- [局限1及影响]

## 建议
1. [具体可执行建议]
2. ...

## 附录：SQL查询
```sql
[所用查询]
```
```

## 数据画像示例

```markdown
## 数据画像：[table_name]

### 概览
- 行数：2,340,891
- 列数：23（8维度、6指标、4日期、5ID）
- 日期范围：2021-03-15 至 2024-01-22

### 列详情

| 列名 | 类型 | 非空率 | 基数 | 备注 |
|--------|------|---------|------|------|
| user_id | STRING | 99.8% | 230万 | 主键 |
| created_at | TIMESTAMP | 100% | - | 分区列 |

### 数据质量问题
- ⚠️ [问题1]：影响[描述]
- ❌ [问题2]：需修复

### 建议探索方向
1. 按 [维度] 看 [指标] 趋势
2. [metric_a] 与 [metric_b] 相关分析
```
