### 改动 2：新增 3.7 端到端转化案例（1 个）

**位置**：3.6 后新增 3.7

**目的**：用真实文本展示"一段 MRD 内容 → 一段 PRD 内容"的转化全过程。

**内容**：
- 输入：MRD 2.2 一段场景化故事（来自校园外卖配送案例）
- 推导：分析这段 MRD 覆盖了哪些字段
- 输出：对应的 PRD 4.1 旅程地图一行 + PRD 4.4 一条 User Story + PRD 3.1 一条功能详述 + PRD 3.2 一条 AC

**示例骨架**：

```
输入（MRD 2.2 场景化故事）：
"小王是北京某高校大一学生，下课高峰期食堂人山人海，
 想订外卖又不想跑到校门口取。后来发现某外卖软件
 能将外卖送到校内，半小时后在宿舍楼下取到外卖。"

推导过程：
1. 角色识别：小王 = 在校大学生（PRD 4.4 Persona）
2. 场景识别：用餐高峰 + 宿舍楼下（PRD 4.1 旅程地图 1 行）
3. 痛点识别：高峰期 + 跑校门口（PRD 4.1 痛点列）
4. 解决方案：外卖送到校内（PRD 3.1 功能 F-LOGISTICS_001）
5. 价值识别：节省时间 + 在宿舍取（PRD 4.4 Story 的"以便..."部分）

输出（PRD 4.4 一条 User Story）：
"作为一个在校大学生，我想在用餐高峰通过外卖软件下单
 并由配送员将外卖送到宿舍楼下，以便我不用排队食堂
 也不用跑校门口取餐，节省 30 分钟用餐时间。"

输出（PRD 3.2 一条 AC）：
"Given 用户在宿舍楼下且订单状态为已送达
 When 用户点击'确认取餐'
 Then 系统在 5 秒内更新订单状态为'已完成'，并触发评价入口"
```
