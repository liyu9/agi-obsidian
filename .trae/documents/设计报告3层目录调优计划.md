## Assumptions & Decisions

1. **保留现有报告**：第 1 层只做轻微修改（精简 §4 + 移除附录到第 2 层），不重写
2. **内容来源 v3 + 7.x**：v3 提供四层框架基底，7.x 提供 Memory 字段细化 / Skills 调用条件 / 评估指标 / trace_id 等增强
3. **每 Agent 篇 4-6 KB**：比 7.x 校验文档（5-9 KB）略精简，因为不含 gap 分析和自检清单，只保留"是什么"的配置定义
4. **第 3 层是字典**：不放叙事，纯结构化定义，方便查阅
5. **Skills 字典合并为 1 篇**：30+ 个 Skill 每个只有 5-8 行，合在一篇更便于交叉查找，不按 Agent 拆
6. **遵循 doc-writing-guide**：描述性语言、避免检查清单式写法、避免术语堆砌

## Verification Steps

1. **结构完整性**：3 层目录齐全（1 + 8 + 5 = 14 篇）
2. **内容完整性**：每个 Agent 的四层框架（Charter/Soul/NEVER/Memory/Skills）在第 2 层完整呈现
3. **交叉引用**：第 2 层引用第 3 层的 Skills 字典和配置文档，链接可点击
4. **事实准确性**：所有字段/工具名/参数与 v3 主文档 + 7.x 一致
5. **大小控制**：第 2 层每篇 4-6 KB，第 3 层每篇 5-10 KB，总计 ~80 KB
6. **Obsidian 渲染**：相对路径正确，表格/代码块正常渲染
