## 执行策略

### 执行原则

* **严格按 Skill 流程执行**：每篇文章走完 detect → extract → download-images → generate-md → validate 全流程

* **实时更新进度**：每完成一个步骤，用 TodoWrite 更新该文章的状态

* **质量第一**：校验 FAIL 项必须修复，不跳过

### 阶段一：迁移已有文章（2篇）

1. 迁移 05 讲 → `02-第二章-产品定义与架构设计/05-架构设计下/`
2. 整理 06 讲 → `02-第二章-产品定义与架构设计/06-CLAUDE.md与工程规范/`

### 阶段二：批量获取（29篇）

**每篇文章的标准流程（按 Skill 定义）：**

```
Step 1: 环境检测    → node scripts/cdp.cjs detect
Step 2: 提取内容    → node scripts/extract.js "article/<id>" article-raw-<id>.json
Step 3: 下载图片    → node scripts/download-images.js article-raw-<id>.json <章节目录>
Step 4: 生成Markdown → node scripts/generate-md.js article-raw-<id>.json image-map.json <输出.md> "<URL>"
Step 5: 校验(异步)  → subagent 执行 node scripts/validate.js <输出.md> article-raw-<id>.json
Step 6: 清理临时文件 → 删除 article-raw-<id>.json 和 image-map.json
```

**进度追踪机制：**

每篇文章用 TodoWrite 跟踪，格式如下：

```
[文章编号] 文章标题
  - Step 1: 环境检测 ✅
  - Step 2: 提取内容 ⏳
  - Step 3: 下载图片 ⬜
  - Step 4: 生成MD   ⬜
  - Step 5: 校验     ⬜
  - Step 6: 清理     ⬜
```

每完成一个步骤立即更新状态，用户可实时看到进度。

**校验策略（质量+效率平衡）：**

* 提取完一篇后**立即继续下一篇**，不等待校验结果

* 用 **subagent 并行校验**，校验结果汇总到队列

* 每完成一个章节批次后，统一检查该批次校验结果

* 有 FAIL 的文章，在批次间修复，不阻塞其他文章获取

* 校验队列实时追踪，避免遗漏

### 并行执行策略

**2 篇文章粒度并行 + subagent 异步校验：**

```
轮次1:  文章A: 提取→下载图片→生成MD ──→ subagent校验
        文章B: 提取→下载图片→生成MD ──→ subagent校验
                    ↓ 2篇都完成后
轮次2:  文章C: 提取→下载图片→生成MD ──→ subagent校验
        文章D: 提取→下载图片→生成MD ──→ subagent校验
                    ↓
        ... 每批次结束后统一修复 FAIL 项
```

**并行可行性评估（质量第一）：**

| 步骤    | 并行可行性 | 建议并发   | 风险                                    |
| ----- | ----- | ------ | ------------------------------------- |
| 提取内容  | ✅ 可并行 | 2篇     | Chrome 可同时 evaluate 多个 page，过高可能超时/截断 |
| 下载图片  | ✅ 可并行 | 5-10请求 | CDN 可能限流                              |
| 生成 MD | ✅ 可并行 | 无限制    | 纯文件操作，互不依赖                            |
| 校验    | ✅ 可并行 | 无限制    | subagent 异步执行                         |

**具体并行点：**

| 并行场景            | 方式          | 说明                          |
| --------------- | ----------- | --------------------------- |
| 2篇文章同时提取        | Promise.all | Puppeteer 可同时操作 2 个 page 对象 |
| 同篇文章内提取→下载→生成MD | 串行          | 有数据依赖（raw→image-map→md）     |
| 提取 vs 校验        | subagent    | 提取完立即继续，校验异步执行              |
| 同批次校验           | 并行 subagent | 多个校验任务同时跑                   |
| 不同章节批次          | 串行          | 避免文件系统冲突，按章节顺序执行            |
