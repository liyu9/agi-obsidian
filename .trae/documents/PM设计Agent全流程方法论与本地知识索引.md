## 三、方法论框架（写入文档的核心内容，v2 深化版）

> 来源：Anthropic《Building Effective Agents》《Context Engineering》、OpenAI《Practical Guide》《Agents SDK》、Gartner《Enterprise AI Agent Competency Framework》、McKinsey AI Agent Report、Lilian Weng、Andrew Ng、Coze/Dify/LangGraph、国内腾讯/字节/智源实践。

### 第一部分：认知奠基
- Agent 经典公式：**LLM + Planning + Memory + Tool Use**
- Workflow vs Agent 分界（Anthropic）：预定义路径 vs 动态自主；**简单优先，能不 Agent 化就不**
- 演进路径：Chatbot → Copilot → Agent → Agentic AI / Multi-Agent
- 企业级 vs 消费级的核心差异（详见第三部分）

### 第二部分：企业 Agent 落地场景地图（新增，回应用户反馈）

#### 2.1 企业内部高价值场景清单（按部门）
| 部门 | 典型场景 | 适合的 Agent 类型 | 落地优先级 |
|---|---|---|---|
| 研发 | 代码生成、Code Review、测试、DevOps | Copilot/执行型 | 高（容错性高） |
| 客服 | 工单分派、智能问答、售后 | 对话型/检索型 | 高 |
| 数据分析 | 报表生成、归因分析、洞察 | 执行型/决策型 | 高 |
| 运维 | 故障诊断、工单处理、自动化修复 | 自主型 | 中高 |
| 销售 | 线索筛选、话术辅助、CRM 录入 | Copilot | 中 |
| HR | 简历筛选、政策问答、培训助手 | 检索型/对话型 | 中 |
| 财务 | 报销审核、对账、合规检查 | 工作流型 | 中（需合规） |
| 法务 | 合同审查、风险提示 | 检索型+人工兜底 | 中（高风险） |

#### 2.2 落地优先级判断标准
- **价值 × 容错性矩阵**：高价值+高容错 = 优先做；高价值+低容错 = 谨慎做+人工兜底；低价值 = 暂不做
- **数据成熟度**：是否有结构化数据/知识库可用
- **集成可行性**：能否对接现有系统 API
- **ROI**：节省的人力成本 vs 开发+算力+维护成本

### 第三部分：Agent 分类与选型（新增，回应用户反馈）

#### 3.1 按自主性分级
| 类型 | 自主度 | 人类介入 | 适用 |
|---|---|---|---|
| Copilot 助手型 | 低 | 每步 | 写作、编码辅助 |
| Assist 协作型 | 中 | 关键节点 | 数据分析、调研 |
| Automated 自主型 | 高 | 仅异常 | 监控、工单处理 |

#### 3.2 按形态分类
- 对话型（Chatbot）：问答为主
- 工作流型（Workflow）：步骤明确、LLM 编排
- 自主型（Autonomous Agent）：动态规划执行
- 多智能体型（Multi-Agent）：多角色协作

#### 3.3 按能力分类
- 检索型（RAG）：知识问答
- 执行型（Tool-heavy）：操作外部系统
- 决策型（Planning-heavy）：复杂判断

### 第四部分：企业级 Agent 设计思路（新增，回应用户反馈）

#### 4.1 企业级 vs 消费级的 7 大差异
权限管控 / 数据安全与隔离 / 合规审计 / 可观测性（全链路 trace）/ 系统集成 / 高可用与性能 / 多租户

#### 4.2 企业 Agent 架构分层
- **接入层**：前端/IM/API/语音多渠道
- **编排层**：Agent 编排引擎、工作流、Multi-Agent 协调
- **能力层**：提示词、Skills、Tools、子Agent
- **数据层**：RAG、知识库、记忆、向量库
- **基础设施层**：模型网关、算力、监控、安全

#### 4.3 Gartner 企业 Agent 能力框架（Competency Framework）
以"企业上下文为核心"，用能力（Competency）定义 Agent 边界。

### 第五部分：Agent 通用设计全流程（深化原十阶段）

1. **需求定义与必要性判断**：Agent 必要性三条件（OpenAI）；问题建模五要素；自动化边界
2. **能力边界与护栏设计**：边界三问；护栏三类（输入/输出/行为）；HITL 介入点
3. **上下文/提示词工程**：Prompt→Context→Harness 跃迁；System Prompt 设计；上下文三支柱（Compaction/Note-taking/Sub-agents）
4. **规划机制设计**：CoT/ToT/ReAct；四大 Agentic Patterns（Reflection/Tool/Planning/Multi-agent）
5. **工具设计**：工具三要素；Function Calling/Tool Use/MCP；原子化原则
6. **记忆机制设计**：短期/长期双层；四步模式；写入检索策略
7. **评估体系（Evals）**：离线 Golden Set；在线 LLM-as-Judge/用户反馈/Trace；指标层级
8. **迭代飞轮**：badcase→Golden Set→改→回归→上线→观测
9. **部署与可观测**：trace/日志/监控；成本延迟准确率三角
10. **商业化**：算力成本、私有化部署、商业模式

### 第六部分：多智能体（Multi-Agent）企业落地（新增）
- **何时用多 Agent**：任务复杂度超单 Agent 边界；需多角色/多技能；并行提效
- **协作模式**：Orchestrator-Worker / Hierarchical 层级 / Peer 对等 / Debate 辩论
- **企业数字员工团队**：按职能分工的 Agent 编队设计
- **单 vs 多 Agent 决策树**

### PM 十大核心原则
简单优先 / 边界清晰 / 上下文稀缺 / 工具>记忆 / 护栏必需 / 评估驱动 / 人机协同 / 可观测 / 最小可用起步 / 权衡三角
