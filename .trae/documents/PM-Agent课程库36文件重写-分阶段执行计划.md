## 四、上下文管理策略

### 单次 LLM 调用输入预算（≤ 25K 字节 ≈ 10K tokens）

| 输入项 | 字节预算 |
|--------|---------|
| 风格锚点（2.4） | 9.4K |
| 重写规范 | 2-3K |
| 当前待改文件 | 5-15K |
| 跨章术语表 | 1-2K |
| 改写指令 prompt | 1-2K |

### 分片读取策略

| 场景 | 策略 |
|------|------|
| 单文件 ≤ 250 行 | 一次性 Read |
| 单文件 250-500 行 | Read 两次 |
| 单文件 500+ 行 | 强制分段生成（8.3 适用） |

### 防上下文丢失的 3 道防线

1. **每文件独立上下文**：不一次性把整章加载到 LLM
2. **风格锚点必带**：2.4 样章在每个文件改写时必带
3. **每章完成 50% 时做对齐回扫**：用已完成样本做风格对齐
