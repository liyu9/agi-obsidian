## 3. 假设与决策（Assumptions & Decisions）

### 3.1 假设
1. **用户角色**：产品经理，需要的是"可落地的补充专题"，而非"再写一份综合方案"
2. **使用环境**：Obsidian 知识库，需保持 Markdown 兼容 + Mermaid 图表
3. **协作模式**：单人或小团队补充，不需要 Git 流程
4. **历史保留**：原方案文档保持不变，作为"主索引"被各补充专题引用

### 3.2 决策记录
| 决策 | 选项 | 选择 | 理由 |
|---|---|---|---|
| 文档组织 | 追加原文 / 分文件 | **分文件** | 用户明确要求；原文已厚 |
| 文档数量 | 27 项各一份 / 按模块归并 | **按模块归并为 8 份** | 避免碎片化，便于查阅 |
| 优先级标注 | 标题前缀 / Frontmatter | **Frontmatter** | Obsidian 原生支持，便于 Dataview 查询 |
| 模板驱动 | 全部展开 / 模板+示例 | **模板+示例** | 既给骨架也给参考 |
| 图表 | Mermaid / 图片 | **Mermaid** | 纯文本可版本化 |
| 链接方式 | 相对路径 / 维基链接 | **相对路径** | 跨平台稳定 |

### 3.3 范围外（Out of Scope）
- **不重写主方案**——保持现状
- **不做真实竞品数据采集**——文档只给模板和框架，实际数据由产品经理后续填充
